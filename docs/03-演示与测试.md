# 03 · 演示与测试

## 1. 30 秒演示脚本

1. 打开已核验的公开部署地址；若尚未完成部署，使用本地 `http://127.0.0.1:7860`。
2. 进入「顾客接待」→ 场景选择「门店零售」→ 点击示例按钮 → 点击「生成接待方案与价格核验」。
3. 重点展示三点：方案可执行、价格带核验日期、结论带有来源。
4. 追加展示「价格核验」中的人工确认项，说明系统不会把历史快照当成当前成交价。

## 2. 演示输入清单

| # | 场景 | 输入 | 期望要点 |
|---|---|---|---|
| 1 | 门店零售 | 使用示例按钮 | 方案和推荐带出处 |
| 2 | 学生学习 | 课程资料整理、软件兼容 | 未知项标为待追问或待验证 |
| 3 | 竞品对比 | 明确比较任务 | 只输出有依据的产品事实 |
| 4 | 价格核验 | 指定型号 | 展示核验日期和人工确认项 |
| 5 | 边界输入 | 不存在的型号或平台 | 拒绝编造，返回未知或 4xx |

## 3. 自动化测试

- `test_mvp.py`：健康检查、初始化数据、咨询、营销、报价、知识问答和跟进 HTTP 接口。
- `test_workflow.py`：客户洞察、推荐、价格、营销和合规的跨模块串联。
- `test_follow_up.py`：四节点计划、状态校验和 JSON 持久化。

运行全部测试：

```bash
py -3 -m unittest discover -s tests -v
```

## 4. 编译和结构检查

```bash
py -3 -m compileall -q app.py modules prepare_public_deploy.py
py -3 -m unittest discover -s tests -v
git diff --check
```

`compileall` 产生的 `__pycache__` 已被 `.gitignore` 和 `.dockerignore` 排除。
