# 鸿蒙电脑无线网络、公司网络与NAS

## 指南定位

无法连接普通或隐藏网络、个别应用不能联网、需要访问NAS或通过证书接入公司网络。

本指南把多篇官方支持来源串成一条可执行路径，但不替代原始页面。界面、支持型号和版本条件会变化；执行前打开文末官方链接核对当前页面。涉及数据删除、系统恢复、磁盘格式化、证书、安全策略或拆机时，不应仅凭本地摘要继续操作。

## 适用范围

- 来源标注系统：HarmonyOS 5.0及以上
- 来源标注产品：台式机、笔记本；笔记本、HUAWEI MatePad Edge、台式机；笔记本、台式机
- 开始前必须再次核对完整型号、当前系统版本、问题发生时间和最近变更。

## 操作前准备

- 记录SSID、认证方式、代理/VPN和证书要求
- 确认其他设备和其他网络是否正常
- 取得企业IT提供的正式配置
- 保存正在编辑的文件；可能影响数据或账号的步骤先完成独立备份和恢复验证。
- 截图记录完整错误提示，但对外分享时遮盖姓名、账号、序列号、密钥、网络名称和客户资料。
- 单位管理设备先确认操作权限；不擅自删除证书、退出管理、关闭安全软件或绕过策略。

## 分步排查

### 第1步

先区分全系统无法上网、单个应用无法上网和仅企业资源不可达

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第2步

普通/隐藏网络按官方入口添加，确认名称、加密方式和密码

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第3步

个别应用检查网络权限、代理、系统时间和服务状态

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第4步

访问NAS前确认地址、协议、账号、共享权限和同网段条件

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第5步

公司网络证书只从IT批准渠道安装，核对用途、有效期和颁发者

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第6步

用非敏感文件完成读写测试，记录网络、账号和错误提示

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

## 完成检查

- □ 互联网与企业资源分别验证
- □ 证书来源和有效期已登记
- □ NAS读写权限符合最小授权
- □ 记录本次操作、前后版本、结果和仍未解决的现象。
- □ 如果采用临时方案，写明限制、到期条件和后续责任人。

## 立即停止并转人工/官方服务

- 证书来源不明或浏览器出现安全告警
- 要求关闭安全控制才能连接
- 共享目录包含未获授权的敏感数据
- 出现数据丢失风险、物理损坏、异常发热/异味、反复蓝屏或无法安全回退时。
- 连续完成两轮低风险排查仍无法稳定复现或恢复时，不继续尝试来源不明的工具和命令。
