# Windows投屏、多屏与跨设备协同

## 指南定位

无线投屏卡顿、外接显示无画面、多屏协同或跨设备剪贴板/传输失败。

本指南把多篇官方支持来源串成一条可执行路径，但不替代原始页面。界面、支持型号和版本条件会变化；执行前打开文末官方链接核对当前页面。涉及数据删除、系统恢复、磁盘格式化、证书、安全策略或拆机时，不应仅凭本地摘要继续操作。

## 适用范围

- 来源标注系统：Windows 10,Windows 11
- 来源标注产品：HUAWEI MateStation X、笔记本、HUAWEI MateStation X 2023 i9/16GB/1T /SSD/集显、HUAWEI MateStation X 2023 i9/16GB/ 512GB /SSD /集显；台式机、笔记本；笔记本、台式机
- 开始前必须再次核对完整型号、当前系统版本、问题发生时间和最近变更。

## 操作前准备

- 记录电脑、手机/平板、显示器的完整型号和系统版本
- 确认账号、WLAN、蓝牙、线缆和转接器
- 准备非敏感样例文件与有线备用方案
- 保存正在编辑的文件；可能影响数据或账号的步骤先完成独立备份和恢复验证。
- 截图记录完整错误提示，但对外分享时遮盖姓名、账号、序列号、密钥、网络名称和客户资料。
- 单位管理设备先确认操作权限；不擅自删除证书、退出管理、关闭安全软件或绕过策略。

## 分步排查

### 第1步

先区分有线显示、无线投屏、多屏协同、文件传输和剪贴板，它们不是同一功能

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第2步

按官方支持列表核对设备与版本，不默认同品牌设备全部兼容

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第3步

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第4步

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

### 第6步

用样例文件测试传输完整性；企业资料遵守数据策略

完成后立即在相同任务、相同网络或同一外设上复测，并记录‘无变化 / 部分恢复 / 已恢复 / 出现新问题’。若结果变化，先保留当前状态，不要连续叠加更多修改。

## 完成检查

- □ 连接方式和目标功能被明确记录
- □ 重连、休眠唤醒和一次长时播放均通过
- □ 传输文件大小与可打开性完成核对
- □ 记录本次操作、前后版本、结果和仍未解决的现象。
- □ 如果采用临时方案，写明限制、到期条件和后续责任人。

## 立即停止并转人工/官方服务

- 转接器异常发热或接口松动
- 客户网络或数据策略禁止协同传输
- 显示异常伴随硬件损伤
- 出现数据丢失风险、物理损坏、异常发热/异味、反复蓝屏或无法安全回退时。
- 连续完成两轮低风险排查仍无法稳定复现或恢复时，不继续尝试来源不明的工具和命令。
