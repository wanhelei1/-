# 华为擎云商用目录说明

> 文档用途：说明商用产品发现、事实补抓、项目验证和审核方法  
> 目录范围：华为擎云商用电脑及与其直接相关的公开资料  
> 事实时点：本库公开索引抓取日期为 2026-10-17；使用前须复核当前官方页面

## 一、这个目录解决什么问题

本目录是“商用产品索引”与“项目级验证材料”之间的入口。它不把消费商城页面直接改写成企业方案，也不把一个系列的公开卖点当作具体 SKU、批次或客户环境事实。使用者应先从 [扩展产品索引.csv](../07-扩展产品目录/扩展产品索引.csv) 找到产品名称、分类、官方 URL 和本地发现卡，再回到华为擎云官方页面补齐规格、支持、服务与版本信息；涉及真实项目时，还要由客户技术、安全、采购和业务人员完成环境验证。

截至 2026-10-17，P1/07 索引中“商用鸿蒙电脑、笔记本与台式机”包含序号 11—24 共 14 个发现条目，覆盖企业版折叠电脑、商用鸿蒙电脑、自主创新商用笔记本和商用台式机。这个数量只描述当时本地索引的覆盖，不表示当前官网仍有相同产品数量、供货状态或产品层级。

本目录允许保存两类材料：一类是从公开官方页面获得、可对外复核的产品事实；另一类是经客户授权形成的项目适配记录。第二类材料不得进入公开共享区，命名建议使用“客户类型—项目代号—完整 SKU—验证日期”，并按组织要求控制权限。

## 二、如何理解 P1/07 中的字段

| 字段 | 可以说明什么 | 不能直接说明什么 |
|---|---|---|
| 序号 | 本地索引中的稳定定位号 | 产品发布时间、优先级或当前热度 |
| 目录 | 本地知识库的归类方式 | 官方销售组织、采购目录或合同分类 |
| 产品名称 | 抓取时官方页面使用的名称 | 未写出的配置、后缀、批次可以互相继承 |
| 分类 | 方便检索的产品形态概括 | 满足某行业、某认证或某客户规范 |
| 官网摘要 | 页面公开定位的简要提炼 | 完整规格、测试条件或项目兼容结论 |
| 官方 URL | 回到原始页面的入口 | 页面永久有效或内容以后不变化 |
| 本地条目 | 发现卡和补抓任务的位置 | 已完成完整事实建档 |

“企业版”“行业版”“优享版”等后缀属于产品身份的一部分。带后缀款式不能自动继承基础款的处理器、系统、内存、存储、接口、屏幕、服务或适配信息；基础款也不能反向继承后缀款卖点。若页面只给系列级信息，应记录“系列事实”，不要填进具体 SKU 字段。

可参考本地发现卡：[HUAWEI MateBook Fold 企业版](../07-扩展产品目录/商用鸿蒙电脑、笔记本与台式机/11-HUAWEI MateBook Fold 企业版.md)、[华为擎云 HM740](../07-扩展产品目录/商用鸿蒙电脑、笔记本与台式机/12-华为擎云 HM740.md)、[华为擎云 L540z](../07-扩展产品目录/商用鸿蒙电脑、笔记本与台式机/15-华为擎云 L540z.md)和[华为擎云 W585y 行业版](../07-扩展产品目录/商用鸿蒙电脑、笔记本与台式机/23-华为擎云 W585y 行业版.md)。这些卡用于发现和检索，卡内也明确要求继续核验规格页与项目环境。

对应官方入口示例包括：[HUAWEI MateBook Fold 企业版](https://qingyun.huawei.com/harmonyos-computer/matebook-fold-enterprise/)、[华为擎云 HM740](https://qingyun.huawei.com/harmonyos-computer/qingyun-hm740/)、[华为擎云 L540z](https://qingyun.huawei.com/laptops/qingyun-l540z/)和[华为擎云 W585y 行业版](https://qingyun.huawei.com/desktops/qingyun-w585y-industry/)。链接用于回到原页，页面状态与内容仍需按使用日期复核。

## 三、商用事实的四层证据

### 1. 产品身份层

至少记录完整产品名、后缀、型号或 SKU 标识、产品形态、官方 URL、页面标题和抓取日期。名称相似但后缀不同，先按独立对象处理；只有官方页面明确给出共用规格时，才允许建立关联。

### 2. 公开规格层

处理器、操作系统、内存、存储、屏幕、接口、无线连接、尺寸重量、供电与包装清单，分别引用具体规格页或正式资料。正文、脚注和测试条件要一同保存；“最高、至高、可选、约、典型值”等限定词不能删除。

### 3. 商用能力与服务层

部署、管理、安全、隐私、服务、维修与生命周期信息必须来自适用于该产品和地区的官方商用资料。一个页面提到企业能力，不等于所有 SKU、系统版本和采购方式都包含；合同、服务级别和交期以获授权文件为准。

### 4. 客户环境验证层

镜像、必装软件、浏览器插件、VPN、网络准入、证书、加密、打印机、读卡器、扫描设备与集中管理必须在客户目标环境做 POC。公开规格只能说明候选条件，不能代替客户技术人员签字。

## 四、标准取证流程

1. **从索引定位**：按产品名称、后缀或类别检索 P1/07，确认不是把同系列款式混在一起。
2. **打开官方原页**：核对域名、页面标题、产品名称和页面是否仍在线；记录访问日期。
3. **寻找规格与支持入口**：产品页、规格页、支持页、商用服务页分别建证据，不用营销摘要代替规格。
4. **绑定对象**：把每条事实绑定到完整名称、型号/SKU、系统版本、地区和页面章节；无法绑定时标记“系列级”。
5. **保存限定条件**：数字旁的测试环境、可选条件、典型值和脚注与字段一起存放。
6. **建立冲突表**：官方页面、PDF、支持页或本地卡不一致时，保存双方 URL、抓取日期与差异，不擅自挑选更有利的值。
7. **形成补抓任务**：缺失字段写“待补”，注明需要哪类页面、由谁核对、缺失会阻断什么结论。
8. **设计项目试点**：按岗位任务验证应用、账号、网络、外设、更新、回退和服务台，不只检查能否开机。
9. **审核发布**：审核人逐条回开来源，确认内容没有跨型号继承、没有把 POC 结果写成官方通用能力。

## 五、动态信息边界

价格、折扣、补贴、赠品、库存、供货地区、交期、套餐、服务报价、合同条款和项目政策均为动态或授权信息，不进入长期产品事实。即使官方页面当日可见，也必须记录日期、地区、渠道和适用对象；再次使用时重新查询。

“在官网产品目录中出现”只能说明抓取时存在入口，不能写成“当前在售”“现货”“可立即交付”。产品页下线也不自动等于产品停产；需要官方公告、渠道或项目负责人确认。客户采购配置可能与公开零售配置不同，不能用商城同名款补全商用 SKU。

## 七、检索与回答示例

### 示例 A：查“有哪些商用鸿蒙电脑”

先在 P1/07 的“目录”列筛选“商用鸿蒙电脑、笔记本与台式机”，再按“分类”筛选。输出可以列出索引中发现的名称和官方入口，但必须写“截至 2026-10-17 的本地索引”，不能据此声称当前全部在售或完成供货。

### 示例 B：问“HM740 是否适配某公司 VPN”

索引和发现卡只能确认产品入口及公开摘要。应先补 VPN 名称、版本、系统要求、证书与网络策略，再查看 VPN 厂商文档，并在客户环境试点。合格回答是“已确认事实—待验证项—试点方法”，不是直接回答“兼容”。

### 示例 C：问“L540z 与 L540z 优享版能否共用配置”

先按两个独立产品对象打开各自官方页和本地卡，逐字段对照；相同字段也要分别留源。只有名称相似不是继承依据。项目镜像、驱动和服务仍需按实际批次验证。

### 示例 D：为商用台式机写方案

从任务和环境出发，先确认业务应用、显示与外设、网络、安全和运维，再筛选候选；产品卖点只作为证据的一部分。方案不得添加未公开参数，也不得把价格、库存或交期写成稳定优势。

## 八、审核规则

- **身份审核**：标题、后缀、型号/SKU、系统和来源指向同一对象。
- **来源审核**：每个数字和兼容结论可回到官方原文或客户签字的受控记录。
- **限定词审核**：约、最高、典型值、可选和测试条件完整保留。
- **继承审核**：无跨款式、跨系统、跨年份、跨地区和跨渠道补值。
- **项目审核**：公开事实与客户 POC 分栏；真实客户名称、配置、策略和结果未经授权不得公开。
- **动态审核**：价格、库存、交期、服务与政策带日期且不进入长期事实。
- **冲突审核**：来源不一致时状态为“待审核”，不得选择性引用。
- **更新触发**：官网改版、产品更名、系统升级、新 SKU、项目复测或来源失效时重新审核。

审核结论使用“通过 / 有条件通过 / 退回补证 / 不适用”。“有条件通过”必须写清限制与复核日期；没有完整来源链的字段应留空，而不是用经验补齐。
