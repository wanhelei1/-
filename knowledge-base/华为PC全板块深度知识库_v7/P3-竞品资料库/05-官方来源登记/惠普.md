# 惠普（HP）官方来源登记与取证规则

> 本登记对应 P3/07 在 2026-10-17 收录的 18 个 HP 产品/系列。HP 中国官网常以“产品组合页”同时介绍多个变体，系列事实与具体型号事实必须分层保存。

## 官方入口组合

- **家用本**：[家用笔记本组合](https://www.hp.com/cn-zh/laptops/home-laptops.html)与[星Book/OmniBook 家族页](https://www.hp.com/cn-zh/laptops/home-laptops/omnibook.html)。
- **商用本**：[EliteBook 产品组合](https://www.hp.com/cn-zh/laptops/business/elitebooks.html)、[EliteBook X 系列页](https://www.hp.com/cn-zh/laptops/business/elitebooks/x-series.html)和[ProBook 产品组合](https://www.hp.com/cn-zh/laptops/business/probooks.html)。
- **移动工作站**：[ZBook 组合页](https://www.hp.com/cn-zh/workstations/mobile-workstation-pc.html)，并用 ZBook Studio、Fury 的专属产品页复核对应系列。
- **游戏本**：使用 P3/07 中 HYPERX/暗影精灵条目的 HP 中国官网产品页；页面明确的“即将面市”状态必须原样保留。
- **本地回查**：`P3-竞品资料库/07-品牌官网当前产品事实/惠普/`。组合页只能证明页面所述系列范围，不能自动证明某个可购买 SKU。

## 产品线识别主键

主键按产品线分别建立：

- EliteBook：`系列层级 + X/Ultra/8/6 + 形态 + G代际 + 平台后缀 + 尺寸`；例如 `EliteBook X Flip G2i 14` 与 `EliteBook X G2i 14` 分开。
- ZBook：`ZBook + 子系列（8/X/Ultra/Studio/Fury）+ G代际/平台后缀 + 尺寸`。
- 家用/游戏：`中文系列全名 + Pro/AI PC/MAX 等层级 + 年份/平台 + 尺寸（页面有则记录）`。

`G2i/G2a/G2q`、`G1i/G1a` 与 `G11` 都是主键的一部分；不能只保留“EliteBook X”或“ZBook”。

## 最容易混淆的字段

- **组合页与单机**：同一 EliteBook X 页面列 G2i、G2a、G2q 和 Flip；平台、形态、续航与屏幕选项不得跨行合并。
- **后缀含义**：P3/07 分别记录英特尔、AMD、Snapdragon 变体；引用处理器平台时仍要绑定完整后缀，不能只写 G2。
- **起始/最高/最长/可选**：重量、内存、存储、屏幕与续航均可能是边界值；它们不是全系列统一参数。
- **代际并不统一**：ZBook Studio G11 与 ZBook G1 系列并存，不能按数字大小推断同一发布时间或配置等级。
- **命名与 URL**：HYPERX/HyperX 暗影精灵条目的 URL 仍含 `omen`；应以 HP 页面完整标题和本库条目为准，不凭 URL 改品牌名。

## 动态信息规则

- “即将面市”、在售、可配置、价格、库存、交付和促销必须按查询日复核；特别是“即将面市”不得自动改写为已上市。
- 组合页更新可能同时影响多个条目。更新时逐一记录完整主键和变化字段，不把新页面上限回填给旧代际。
- 续航或性能数字只有在测试条件仍可见时才能用于成稿；条件缺失则只保留定位，不做跨品牌量化比较。

## 与华为对比时的取证顺序

1. 先把需求分为家用、商务、移动工作站或游戏，再选完整 HP 主键；不同场景不横向凑表。
2. 查 P3/07 对应条目，确认来源是组合页还是专属页；组合页需定位到确切变体和限定语。
3. 在华为 P1 固定具体型号、系统与 SKU，并确认是否真与该 HP 对象同尺寸、同形态、同任务。
4. 企业场景先核软件/管理/安全与服务证据，创作工作站先核专业软件和显卡类别，家用本再比较屏幕、性能平台、内存存储、接口、重量与电池。
5. 对“最高/最长/起始”只做同测试条件或同配置级别的对照；价格与售后另取双方当日官方页面，证据不足即标“待核验”。
