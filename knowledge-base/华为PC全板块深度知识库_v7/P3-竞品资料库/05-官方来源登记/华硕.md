# 华硕官方来源登记与取证规则

> 基线来自 P3/07 与研究底稿在 2026-10-17 对华硕中国官网的核验。华硕中文营销名可能相近，取证必须保留机型代码。

## 官方入口组合

- **发现产品线**：[华硕中国笔记本目录](https://www.asus.com.cn/laptops/)用于确认 ProArt、灵耀、a豆、无畏、天选等产品入口；[官方商城笔记本目录](https://www.asus.com.cn/store/goods/list?tagId=98)用于观察销售陈列。
- **确认产品身份**：进入具体系列页，保存中文完整名、英文 URL 路径和括号内机型代码，例如 `UX8407`、`S5450AA`。
- **确认配置范围**：优先读取同一机型的 `/techspec/` 规格页。规格页列出的多个处理器、显卡或屏幕选项属于“可选范围”，不是一台机器同时具备。
- **回查本库**：使用 `P3-竞品资料库/07-品牌官网当前产品事实/华硕/` 的条目与 URL；只有目录过滤页的对象，精确参数比较前必须补到对应的官方产品/规格证据。

## 产品线识别主键

主键写成：`中文产品线 + 完整营销名 + 标称年份/平台 + 机型代码`。代码优先于简称去重。

示例：`灵耀 + 灵耀14 双屏 2026 + UX8407`、`无畏 + 无畏 Pro14 酷睿版 2026 + S5450AA`、`天选 + 天选7 Pro 酷睿版 2026 + FX608`。`灵耀14 Air` 与 `灵耀14 双屏`、`无畏16SE` 与 `无畏 Pro14` 不能只按“灵耀14/无畏”合并。

## 最容易混淆的字段

- **中文名与全球系列名**：URL 中可能出现 `zenbook`、`vivobook`、`tuf-gaming`，正文却使用灵耀、无畏、天选；必须用机型代码桥接，不能仅按 URL 词根猜中文型号。
- **产品页与规格页**：卖点页用于定位，`techspec` 用于配置范围。把两页最高值组合后，可能得到不存在的 SKU。
- **“最高/可选/约/薄至”**：算力、内存、亮度、刷新率、重量和厚度常带范围或条件，引用时保留原限定词及对应版本。
- **筛选目录的证据强度**：本库无畏16SE 当前来源是官方系列筛选入口；它可证明目录陈列和摘要，不足以替代专属规格页回答全部参数。
- **形态差异**：双屏、传统翻盖、电竞本和创作本不能因屏幕尺寸接近直接设为同类。

## 动态信息规则

- 商城价格、库存、优惠、赠品和交付状态只作带时间的快照；发布前重新核验商城页。
- 规格页新增或删除选项时，记录机型代码、地区站点、抓取时间及所引用配置行；旧事实不自动迁移到同系列新代码。
- “2026”“酷睿版”“锐龙版”等身份字段原样保留。未在页面明确的上市状态、默认配置和中国区可售组合一律不推断。

## 与华为对比时的取证顺序

1. 先按任务筛选形态，再锁定华硕机型代码；双屏、电竞、创作和轻薄办公分别建组。
2. 从 P3/07 取定位和官方 URL，到具体产品页确认身份，再到 `techspec` 只选择一个真实配置口径。
3. 在华为 P1 锁定对应具体型号、系统和版本，读取参数事实及限制条件。
4. 按软件/系统、形态、屏幕、处理平台、显卡、内存存储、接口、电池与重量逐项对齐；不得把华硕多个可选上限与华为单一 SKU 比较。
5. 动态价格和服务最后单列，并以双方当日官方证据为准；没有同条件测试或售后条款时不作泛化结论。
