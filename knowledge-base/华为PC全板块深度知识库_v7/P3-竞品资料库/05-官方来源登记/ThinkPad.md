# ThinkPad 官方来源登记与取证规则

> 本登记以 P3/07 的 2026-10-17 官网快照为基线。它说明如何识别和复核 ThinkPad，不把快照日期之后的在售状态、价格或配置视为已确认。

## 官方入口组合

1. **产品发现**：[ThinkPad / ThinkBook 官方商城](https://thinkpad.lenovo.com.cn/index.html)与[联想笔记本目录](https://www.lenovo.com.cn/wiki/notebook/)用于确认官网当前如何陈列系列。
2. **型号落点**：以 `item.lenovo.com.cn/product/{产品ID}.html` 的单品页确认完整商品名和页面对应的销售配置。本库已核验的两个落点是 [X1 Carbon 商品 1053713](https://item.lenovo.com.cn/product/1053713.html)与 [X14 商品 1054265](https://item.lenovo.com.cn/product/1054265.html)。
3. **本地证据**：先查 `P3-竞品资料库/07-品牌官网当前产品事实/ThinkPad/`，再回到该条记录中的官方 URL 复核；服务与保修问题不能由商品页卖点代答。

目录页只证明“被官网陈列”，商品页才用于证明该商品；系列声誉、媒体评测或经销商参数均不能替代二者。

## 产品线识别主键

主键写成：`ThinkPad + 系列/子系列 + 完整代际 + 标称年份 + 明示配置 + 联想产品ID`。

- `X1 Carbon G13 2025 + Ultra 5 225H / 32GB / 1TB + 1053713` 与 `X14 2026 + Ultra 5 + 1054265` 是两个独立对象。
- `G13`、`2025/2026`、处理器、内存和存储都不能从名称中省略后再合并。
- ThinkBook 虽可出现在同一商城体系中，本库路由到“联想”登记；不得因 URL 同属联想而并入 ThinkPad 产品线。

## 最容易混淆的字段

- **系列能力与单一 SKU**：Carbon、键盘或商务安全等系列表达，不能自动证明每个 X1 或 X14 SKU 的屏幕、接口与配置。
- **代际、营销年份与处理器代号**：三者是不同字段；不得用“2026 款”替代 G 代际或 CPU 全名。
- **同页可选项与页面默认项**：页面出现“可选/最高”时，不得拼成一个实际可售配置；精确结论要绑定产品 ID 和当时选中的配置。
- **ThinkPad 与 ThinkBook**：名称相近但属于不同产品线登记；跨线比较前先完成品牌/系列归档。

## 动态信息规则

- 价格、优惠、国补、赠品、库存、发货时间和可选配置均按查询当日重新打开商品页，记录时间、产品 ID 与所选配置；P3/07 不固化这些字段。
- 页面改名、产品 ID 跳转、配置下架或目录撤出时，保留旧快照但标记“历史证据”，不静默覆盖。
- “新款”“当前在售”等措辞必须带核验日期；没有当日页面证据时改写为“P3/07 于 2026-10-17 收录”。

## 与华为对比时的取证顺序

1. 先固定用户任务，再写全 ThinkPad 对象的系列、代际、年份、配置和产品 ID。
2. 查 P3/07 对应条目确认定位与原始 URL；随后打开该商品页复核当天的具体 SKU。
3. 在华为 P1 选择同尺寸、同系统约束、同使用定位的具体型号，并核对其“产品事实/卖点与限制”，不能拿系列最高值代替 SKU。
4. 按系统与软件、屏幕与形态、重量与移动频率、处理器/内存/存储、接口、安全与服务逐字段对齐；每项分别保留“可选、最高、约、起始”等限定语。
5. 价格和服务单独引用当天官方商城或官方支持证据；缺少同口径信息时写“待核验”，不做胜负结论。
