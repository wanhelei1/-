# 联想消费与 ThinkBook 产品官方来源登记

> 本文覆盖 P3/07 的 YOGA、小新、ThinkBook 与拯救者；ThinkPad 另见同目录 `ThinkPad.md`，不得因同属联想商城而混用产品线事实。基线日期为 2026-10-17。

## 官方入口组合

- **品牌与产品发现**：[联想消费产品站](https://consumer.lenovo.com.cn/)和[联想商城笔记本目录](https://www.lenovo.com.cn/wiki/notebook/)用于定位 YOGA、小新、拯救者等系列。
- **ThinkBook 路由**：[ThinkPad / ThinkBook 官方商城](https://thinkpad.lenovo.com.cn/index.html)用于系列发现；具体记录仍回到官方商品页。
- **单品证据**：`item.lenovo.com.cn/product/{产品ID}.html` 与 `tk.lenovo.com.cn/product/{产品ID}.html` 是本库已核验的商品落点；保存产品 ID，不按两个域名推断不同品牌。
- **本地回查**：`P3-竞品资料库/07-品牌官网当前产品事实/联想/`，条目中的 URL 是后续复核起点。

## 产品线识别主键

主键写成：`产品线 + 完整商品名 + 标称年份 + 尺寸/平台变体 + 型号补充码 + 联想产品ID`。

- `ThinkBook 14+` 与 `ThinkBook 16+` 的加号属于正式系列名，不能省略；16+ 条目还需保留 `04CD`。
- 小新条目保留 `小新 Pro 16 IPH11`；YOGA 保留 `Air 14 Ultra Aura 2026`；拯救者保留 `Y9000P 2026`。
- 产品 ID 是同名或相似营销名的最终去重键；域名 `item` 与 `tk` 不是型号字段。

## 最容易混淆的字段

- **联想与 ThinkPad**：集团/商城来源相同不代表产品线相同；ThinkPad X 系列参数不得套给 ThinkBook。
- **14+/16+ 与普通 14/16**：加号是系列身份，不是数学符号；目录清洗时不能删除。
- **中文长名、短名与补充码**：`Pro16`、`Pro 16 IPH11`、`04CD`、`Aura` 都用于防止同名合并。
- **商品页配置与系列宣传**：CPU、GPU、屏幕、内存、存储和电池要绑定产品 ID；“可选/最高”不能跨 SKU 拼装。
- **定位差异**：轻薄、全能商务、大屏创作和电竞属于不同任务组，不能只按屏幕尺寸直接排名。

## 动态信息规则

- 商品页价格、优惠、赠品、库存、交付和配置选项只在抓取日有效；使用时记录产品 ID、配置与时间。
- 页面标题增删“新款/AI/酷睿”等营销词时，先核对产品 ID 与硬件配置，再决定是更名还是新对象。
- 页面下架、跳转或域名变化时保留旧条目为历史证据；不得把新 ID 的事实覆盖旧 ID。

## 与华为对比时的取证顺序

1. 按用户任务先选 YOGA、小新、ThinkBook 或拯救者，并写全产品 ID；若对象是 ThinkPad，转到独立登记。
2. 查 P3/07 对应条目确认定位和抓取日期，再打开单品页锁定当天的具体销售配置。
3. 在华为 P1 选同尺寸、同负载与同系统约束的具体 MateBook；Windows 与鸿蒙版本分别处理。
4. 先对软件/系统与显卡负载分组，再比较屏幕、处理器、内存存储、接口、电池和重量；每项都绑定双方 SKU。
5. 价格、活动与售后从双方当日官方来源另行取证；缺少同类官方字段时写“待核验”，不以系列口号下结论。
