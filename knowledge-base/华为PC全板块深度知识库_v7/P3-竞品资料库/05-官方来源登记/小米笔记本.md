1. **当前阵容入口**：小米官网笔记本导航会随产品页同步展示；研究基线使用 [REDMI Book 16 2026 产品页](https://www.mi.com/prod/redmi-book-16-2026)检查当时的导航组合。

3. **官方选购页**：`mi.com/shop/buy/detail?product_id={ID}` 用于绑定具体商品记录，例如 [REDMI Book Pro 14 2026（24035）](https://www.mi.com/shop/buy/detail?product_id=24035)、[REDMI Book Pro 16 2026（24037）](https://www.mi.com/shop/buy/detail?product_id=24037) 与 REDMI Book 14 锐龙版 2025。
4. **本地入口**：`P3-竞品资料库/07-品牌官网当前产品事实/小米与REDMI/`；回答前从条目进入原官方 URL，不以搜索摘要代替页面。

## 产品线识别主键

主键写成：`品牌（Xiaomi/REDMI）+ Book/Book Pro + 屏幕尺寸 + 标称年份 + 平台变体 + product_id 或产品slug`。

- `REDMI Book Pro 14 2026`、`REDMI Book 14 2026` 与 `REDMI Book 14 锐龙版 2025` 是三个对象。
- `Xiaomi Book Pro 14` 不能因同为 14 英寸 Pro 而并入 REDMI Book Pro。
- 页面没有公开 `product_id` 时保存完整 `/prod/` 路径；两者都没有时才使用“待补主键”。

## 最容易混淆的字段

- **品牌与系列**：Xiaomi 和 REDMI 是第一层主键；`Pro` 是系列层级，不等同于处理器或某一固定配置。
- **尺寸与年份**：14/16 英寸、2025/2026 必须进入名称；不能用相同商品主图或相似页面标题去重。
- **平台变体**：“锐龙版”是身份字段；处理器、屏幕、内存和电池不能从同名酷睿或下一年份版本借用。
- **产品页与选购页**：`/prod/` 可用于卖点和产品身份，`product_id` 页面用于销售记录；两者信息冲突时保存冲突，不自行拼接。
- **跨端能力**：小米澎湃智联、Xiaomi HyperConnect、AI 办公或跨生态文件互传只按对应页面原文和使用条件引用，不能扩写为所有设备、所有系统均支持。

## 动态信息规则

- 导航排序、在售状态、选购项、价格、补贴、赠品、库存和到货时间会变化，使用时重新抓取并写日期；“官网首位”仅能作为带日期的陈列事实。
- `product_id` 页面失效不代表产品事实从未存在；保留 P3/07 快照并标记页面状态，新的商品 ID 不自动视为同一配置。
- 未经当日页面确认，不写“当前主销、最低价、全系标配”；生态功能升级也要重新核对支持机型和系统条件。

## 与华为对比时的取证顺序

1. 先确认 Xiaomi 还是 REDMI，再锁定 Pro 层级、尺寸、年份、平台变体和 URL 主键。
2. 从 P3/07 取已核实定位；打开 `/prod/` 核对产品身份，再用对应 `product_id` 页确认当天销售配置（如有）。
3. 在华为 P1 选择同尺寸、同任务和相同系统约束的具体 MateBook 版本，避免把鸿蒙版与 Windows 版混为一项。
4. 先核对软件与跨设备条件，再比较屏幕、处理器平台、内存存储、接口、电池、重量；每个数字都绑定各自版本。
5. 价格、活动与服务另取双方当天官方证据；无法建立同口径时只陈述差异，不推断体验或优劣。
