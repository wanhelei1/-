# 戴尔（Dell / Alienware）官方来源登记与取证规则

> P3/07 的 2026-10-17 基线收录 Dell、Dell Pro、XPS、Dell Pro Max 与 Alienware。戴尔页面高度配置化，型号代码比营销简称更适合作为取证主键。

## 官方入口组合

1. **目录层**：[戴尔中国站](https://www.dell.com/zh-cn)及[笔记本当前产品列表](https://www.dell.com/zh-cn/shop/dell-laptops/scr/laptops?showMessage=2)用于发现产品与判断页面陈列。
2. **产品层**：优先使用 `/spd/` 的专属产品页；保存页面标题、型号代码及 URL 中的产品路径。
3. **配置层**：若 URL 或页面出现 `bto...`、`xcto...` 等配置路径，结论必须绑定当次选项，不能把默认配置当作整个型号的固定配置。
4. **本地层**：`P3-竞品资料库/07-品牌官网当前产品事实/戴尔/`。仅以列表页为来源的 Dell 15 与 Dell Pro Max 18 Plus，可用于当前阵容和定位识别；精确配置比较前要补专属官方证据。

## 产品线识别主键

主键写成：`品牌/产品线 + 完整营销名 + 屏幕尺寸/层级 + 型号代码 + 配置路径（如有）`。

- Dell Pro：`PA13250/PA14250` 对应 Premium 层级，`PC14250/PC16250` 是另一组对象，`MB18250` 属于 Pro Max 18 Plus。
- XPS：`DX13260`、`DA14260`、`DA16260` 分别锁定 2026 的 13/14/16 英寸对象。
- Alienware：`AC16250`、`AC16251`、`AA16250`、`AA18250` 必须与 Aurora、16X Aurora、Area-51 和尺寸同时保存。

## 最容易混淆的字段

- **营销名相似、代码不同**：Dell Pro 14 与 Dell Pro 14 Premium 不能按尺寸合并；Alienware 16 Aurora、16X Aurora 与 16 Area-51 也不是同一 SKU。
- **页面配置器**：处理器、显卡、屏幕、内存、硬盘、系统与服务可能随选择变化。一次页面上出现的所有上限不代表可同时购买。
- **产品页与目录页**：目录页可支持“阵容中存在”，不能支持端口、重量或具体配置；没有专属页时把字段标为待核验。
- **起始重量与可选屏幕**：保留“起始、最高、可选”及对应配置，不与固定值混用。
- **代码中的尺寸/年份线索**：代码只作官方身份键，不自行拆码推导未在页面明确的年份或硬件。

## 动态信息规则

- 配置器价格、优惠、可选部件、服务包、库存和交付日都是动态字段；引用时保存日期、完整 URL、型号代码与已选配置。
- `/spd/` 页面跳转或默认选项变化时，不把新默认项回写成旧快照事实；需要新建核验记录。
- “当前优惠”“全部促销产品”等 URL 分类不构成长期促销或在售证明，发布前必须回到当天产品页。

## 与华为对比时的取证顺序

1. 先确认是日常本、商用本、XPS 高端轻薄、移动工作站还是游戏本，再锁定戴尔型号代码。
2. 从 P3/07 进入 `/spd/` 页面，记录完整配置路径和当次选项；列表页来源先补齐专属规格证据。
3. 在华为 P1 固定具体 MateBook 型号、操作系统与销售版本，确保尺寸、定位和负载类型相当。
4. 依次核对软件/系统、处理器与显卡类别、屏幕、内存存储、接口、重量电池；商用服务和耐用性声明单独要求双方官方支持证据。
5. 仅对双方都已锁定的单一配置作参数比较。价格、服务包、库存和交付另建当日快照；一方只有“可选/最高”时不得写成固定领先。
