# Apple MacBook 官方来源登记与取证规则

> P3/07 的 Apple 基线抓取于 2026-10-17。Apple 的 Air/Pro 页面同时承载多个尺寸和芯片组合，URL 相同不能作为去重主键。

## 官方入口组合

1. **产品家族入口**：[Mac](https://www.apple.com.cn/mac/)用于确认当前家族导航。
2. **系列页**：[MacBook Air](https://www.apple.com.cn/macbook-air/)、[MacBook Pro](https://www.apple.com.cn/macbook-pro/)与[MacBook Neo](https://www.apple.com.cn/macbook-neo/)用于定位系列、尺寸和芯片组合。
3. **交叉识别**：[Mac 机型比较](https://www.apple.com.cn/macbook-neo/compare/)用于核对并列机型名称；具体技术字段仍以对应官方产品/技术规格内容及限定词为准。
4. **本地证据**：`P3-竞品资料库/07-品牌官网当前产品事实/苹果/`。同一系列页被多条记录引用是正常现象，不代表这些记录参数相同。

## 产品线识别主键

主键写成：`MacBook 系列 + 标称尺寸 + 芯片名称`。

- Air：`MacBook Air 13 英寸（M5）` 与 `MacBook Air 15 英寸（M5）`。
- Pro：`14 英寸 + M5/M5 Pro/M5 Max` 与 `16 英寸 + M5 Pro/M5 Max`，每个组合单独建档。
- Neo：`MacBook Neo（A18 Pro）`；不得按 13 英寸外形并入 Air。

统一内存和存储容量属于配置字段，不替代上述主键；若要比较具体购买组合，再追加内存、存储和其他可选项。

## 最容易混淆的字段

- **共享 URL**：Air 两个尺寸共用系列页，Pro 五个芯片/尺寸对象共用系列页；去重时不能按 URL 合并。
- **芯片层级与尺寸**：M5、M5 Pro、M5 Max 是不同配置身份；系列页面的最高统一内存、最高存储或最长续航不自动适用于每个组合。
- **显示屏命名**：Air 的 Liquid 视网膜与 Pro 的 Liquid 视网膜 XDR 是不同页面字段，不能简写后互换。
- **“起步/最高/最长”**：内存、存储和续航必须保留限定词；精确对比还需核对官网测试条件。
- **系统与软件**：与 Windows 或 HarmonyOS 设备比较前先确认用户软件、外设和文件工作流；不得仅凭芯片名称推断兼容性。

## 动态信息规则

- Apple 会更新同一系列 URL。页面内容变化时记录抓取日期和“尺寸 + 芯片”主键，不能用新页面静默覆盖旧代际记录。
- 价格、教育优惠、折抵、交付时间、颜色和可购配置属于动态销售字段，发布前到官方选购流程重新核验；P3/07 不固化这些信息。
- 续航、性能和功能只有在对应芯片/尺寸及测试条件可确认时引用；“系列最长”不得下放为所有机型固定值。

## 与华为对比时的取证顺序

1. 先确认用户必须使用的软件、系统生态、外设和文件交换方式；不满足基础兼容条件时不进入参数排名。
2. 锁定 Apple 的“系列 + 尺寸 + 芯片”，从 P3/07 回到对应官方系列页，并核对比较页中的机型身份。
3. 在华为 P1 锁定具体 MateBook 型号、操作系统与 SKU；鸿蒙版和 Windows 版分别与目标工作流验证。
4. 再比较屏幕、内存/存储口径、接口、重量、电池和充电；Apple 的统一内存与其他平台内存只陈述官方规格，不自行换算性能等价。
5. 续航或性能必须有双方可比的测试条件；价格、服务与动态购买选项使用当天官方证据。无法同口径时明确“不可直接比较”。
