# 华硕 × 华为｜摄像头音频与会议取证工作表

> 本页的目标是获得可审计差异，而非收集尽可能多的形容词。比较失败也应留下明确的缺口和下一动作。

## 一、字段定义与完成标准

本维度验证摄像头、麦克风、扬声器、隐私控制、系统算法和会议应用的完整链路。像素、麦克风数量或 AI 名称不能独立代表会议效果，网络与房间环境必须记录。

完成状态不是表格写满，而是每格都能回答对象、来源、日期和条件；未知项有负责人，任务验证可复跑，系列口号未被当作 SKU。

1. **摄像头**：本项要求分辨率、位置、红外或物理遮挡按官网记录。华硕证据与华为证据独立登记，禁止用相邻型号替空。
2. **麦克风**：本项要求数量、阵列与拾音模式不混写。华硕证据与华为证据独立登记，禁止用相邻型号替空。
3. **扬声器与音频**：本项要求单元、布局、接口和应用输出分别核验。华硕证据与华为证据独立登记，禁止用相邻型号替空。
4. **隐私控制**：本项要求物理、系统与应用权限分层。华硕证据与华为证据独立登记，禁止用相邻型号替空。
5. **系统音视频能力**：本项要求版本、模式和支持应用条件。华硕证据与华为证据独立登记，禁止用相邻型号替空。
6. **会议应用**：本项要求名称、版本、账号和内部设备选择。华硕证据与华为证据独立登记，禁止用相邻型号替空。
7. **网络与环境**：本项要求带宽、延迟、噪声、光线和距离。华硕证据与华为证据独立登记，禁止用相邻型号替空。
8. **外接设备**：本项要求耳机、摄像头、采集卡和扩展坞链路。华硕证据与华为证据独立登记，禁止用相邻型号替空。

## 二、华硕 官网定位方法

**身份主键**：主键保留中文产品线、完整营销名、年份或平台和机型代码。灵耀、无畏、a豆、天选与 ProArt 形态不同；UX、S、M、FX、H 等代码不能省略。

**取证路线**：产品目录用于发现系列，具体产品页用于定位，techspec 规格页用于配置范围。中文营销名与 URL 中的 zenbook、vivobook、tuf 等词根用机型代码桥接，不凭 URL 猜型号。

**品牌端高风险点**：华硕规格页经常并列多个处理器、显卡或屏幕选项；把所有最高值拼成一台机器会制造不存在的 SKU。筛选目录只能支持陈列与摘要，不能替代专属规格页。

执行时先读 `P3-竞品资料库/05-官方来源登记/华硕.md`，再进入 `P3-竞品资料库/07-品牌官网当前产品事实/华硕` 选择与用户任务相符的具体产品卡。事实卡只保留其核验日已确认摘要；需要当前配置时必须回到卡内官方 URL。P3/08 案例只示范如何组织证据和 POC，不可把案例中的另一产品事实移入本表。

## 四、不可直接比较的口径

1. **暂停项**：像素数不等于会议画质。若业务坚持比较，先补双方对象、来源和测试方法。
2. **暂停项**：麦克风数量不等于拾音效果。若业务坚持比较，先补双方对象、来源和测试方法。
3. **暂停项**：AI 降噪名称不能跨平台等价。若业务坚持比较，先补双方对象、来源和测试方法。
4. **暂停项**：不同会议应用压缩不可直接比较。若业务坚持比较，先补双方对象、来源和测试方法。
5. **暂停项**：网络波动不能归因于整机。若业务坚持比较，先补双方对象、来源和测试方法。
6. **暂停项**：系统默认设备与应用选择可能不同。若业务坚持比较，先补双方对象、来源和测试方法。

品牌页面证据等级不同并不是产品差异。先把系列、SKU 与实测分层；仍无同级材料时，只发布缺口和下一动作。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 华硕 完整对象：主键保留中文产品线、完整营销名、年份或平台和机型代码。灵耀、无畏、a豆、天选与 ProArt 形态不同；UX、S、M、FX、H 等代码不能省略。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；产品目录用于发现系列，具体产品页用于定位，techspec 规格页用于配置范围。中文营销名与 URL 中的 zenbook、vivobook、tuf 等词根用机型代码桥接，不凭 URL 猜型号。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

在同一会议应用和账号下，固定网络、座位、光线与噪声，执行入会、发言、共享、录制允许的测试片段和外接耳机切换。由远端两名观察者独立记录可懂度与失败；本地保存设备选择、权限和异常，不生成无依据音质排名。

任务执行者须交付可复跑材料：两侧配置、软件驱动、样本校验、网络外设、操作记录、失败日志和签字。未执行绝不能写成不支持。

## 八、结论句式

- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’

结论中删除冠军、碾压、无敌和唯一推荐。任何效率、兼容或续航判断都必须带对象、条件与本轮范围。

## 九、更新与合规

1. 给旧表加失效或历史状态，不静默覆盖。
2. 一方只有系列页时降低结论强度。
3. 销售条件按地区渠道和时点复核。
4. POC观察与官方规格分栏保存。
5. 页面未提及继续写待补。
6. 采购决定另走组织审批。
7. 测试素材先授权和脱敏。
8. 审稿人检查对象、日期与限制。

## 十一、品牌 × 维度桌面演练

角色演练包含取证人、业务用户和审计人。业务用户提出 摄像头音频与会议 的模糊要求；取证人先用 **摄像头** 把需求具体化，再从 华硕 与华为入口分别记录 **麦克风**，最后把 **扬声器与音频** 放进任务脚本。审计人隐藏一个关键限定或换掉 SKU，取证人必须发现并暂停旧结论。合格交付应能由第三人复跑，且明确哪些句子来自官网、哪些来自本轮观察、哪些仍是空白。若只能复述卖点，说明工作表尚未执行。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
