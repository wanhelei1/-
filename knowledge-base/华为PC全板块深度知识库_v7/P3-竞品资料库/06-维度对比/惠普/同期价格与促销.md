# 惠普 × 华为｜同期价格与促销取证工作表

> 本模板允许空填，但不允许猜填。只有来源、对象、日期、限定和任务同时完整，字段才可进入对外结论。

## 一、字段定义与完成标准

本维度只建立同一时间、地区、渠道和完整 SKU 的购买条件快照。价格不是稳定产品参数；券、补贴、折抵、分期、赠品、套装和库存必须拆开，过期快照仅用于追溯。

本表可以有空白，但不能有猜测。双方身份、八项证据、引用时间、限制和任务记录齐全后，才允许形成带范围的差异句。

1. **完整 SKU**：围绕用户任务，系统、平台、内存、存储、颜色与套装写全。双方均保留最高、可选、约等词，空格交由补证负责人。
2. **官方标示价**：围绕用户任务，记录页面原词与时间，不作长期事实。双方均保留最高、可选、约等词，空格交由补证负责人。
3. **活动后条件**：围绕用户任务，券、会员、支付、地区与名额逐项。双方均保留最高、可选、约等词，空格交由补证负责人。
4. **补贴**：围绕用户任务，国家或地方、资格、核销和有效期。双方均保留最高、可选、约等词，空格交由补证负责人。
5. **折抵或以旧换新**：围绕用户任务，估值与成交价分开。双方均保留最高、可选、约等词，空格交由补证负责人。
6. **赠品与套装**：围绕用户任务，型号、数量、价值表述和退货影响。双方均保留最高、可选、约等词，空格交由补证负责人。
7. **库存与交付**：围绕用户任务，地区、仓库、下单时点和预计状态。双方均保留最高、可选、约等词，空格交由补证负责人。
8. **报价有效性**：围绕用户任务，截图、URL、配置和复核节点齐全。双方均保留最高、可选、约等词，空格交由补证负责人。

## 二、惠普 官网定位方法

**身份主键**：按家用、EliteBook、ProBook、ZBook 与游戏产品线建主键；X/Ultra/8/6、Flip、G 代际、i/a/q 平台后缀和尺寸均保留。组合页中的相邻变体不能合并。

**取证路线**：先选家用、商用、工作站或游戏入口，再判断来源是组合页还是专属页。组合页只支持对应行或系列范围；Studio、Fury 等可回到专属页时优先补专属证据。

**品牌端高风险点**：HP 页面常把 G2i、G2a、G2q 与 Flip 并列，重量、屏幕、续航和平台不得跨行拼接；‘即将面市’也必须保留，不能自动更新为已上市。

执行时先读 `P3-竞品资料库/05-官方来源登记/惠普.md`，再进入 `P3-竞品资料库/07-品牌官网当前产品事实/惠普` 选择与用户任务相符的具体产品卡。事实卡只保留其核验日已确认摘要；需要当前配置时必须回到卡内官方 URL。P3/08 案例只示范如何组织证据和 POC，不可把案例中的另一产品事实移入本表。

## 三、华为侧对应证据

先从 `P1-产品参数库/00-全库横向索引/全型号总览.md` 选择具体产品，再固定鸿蒙或 Windows 路线与销售配置。维度入口为 `P4-价格政策库（机密）/对外报价合规检查.md`。该专题由受控价格目录提供；仅限获授权人员按当前记录使用，产品身份仍从 P1 固定。

华为侧同样遵守“系列、具体型号、销售 SKU、动态销售条件分层”。卖点与限制可帮助解释适用场景，但数值仍回到产品事实或型号检索卡。缺少对应字段时写“华为侧待补证”，不得用其他 MateBook 或商城另一配置替代。

## 四、不可直接比较的口径

1. **审计提醒**：原价、到手价与补贴后价不能混写。允许写‘口径不同’，不允许把未知解释成落后。
2. **审计提醒**：不同渠道券和赠品不能跨用。允许写‘口径不同’，不允许把未知解释成落后。
3. **审计提醒**：教育、企业与个人条件不同。允许写‘口径不同’，不允许把未知解释成落后。
4. **审计提醒**：分期月供不等于总成本。允许写‘口径不同’，不允许把未知解释成落后。
5. **审计提醒**：有货与可按期交付不是一回事。允许写‘口径不同’，不允许把未知解释成落后。
6. **审计提醒**：历史最低、全网最低和保价不得无证据使用。允许写‘口径不同’，不允许把未知解释成落后。

如果同一单位或测试条件仍无法建立，停止横向数值句；可以解释为什么不能比，不能借此暗示某一方较弱。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 惠普 完整对象：按家用、EliteBook、ProBook、ZBook 与游戏产品线建主键；X/Ultra/8/6、Flip、G 代际、i/a/q 平台后缀和尺寸均保留。组合页中的相邻变体不能合并。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；先选家用、商用、工作站或游戏入口，再判断来源是组合页还是专属页。组合页只支持对应行或系列范围；Studio、Fury 等可回到专属页时优先补专属证据。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

执行双人报价复现：甲按既定地区、渠道和完整配置生成当日快照，乙仅凭记录重新定位同一对象并核对活动条件、库存和有效期。任何不可复现项转为待确认。工作表不预填金额，对外前由获授权人员在下单节点再次查询。

测试不以口头‘正常’结束；需要原始提示、过程留痕、输出文件及第二人复核。绕行被接受时写条件通过，不能隐藏绕行。

## 八、结论句式

- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’
- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’

不要把参数差异改成价值高低，也不要把一次成功写成永久能力。对外句必须同时呈现日期和限制。

## 九、更新与合规

1. 每张表写创建、复核与下次检查日期。
2. 跨版本内容不得合并成一个SKU。
3. 活动数据到期即退出当前结论。
4. 主观感受需双人记录且仍属观察。
5. 缺失字段有责任人而非猜值。
6. 参数差异不直接换成价值判断。
7. 组织数据不得用于未经授权演示。
8. 二审逐项核对链接与结论句。

## 十一、品牌 × 维度桌面演练

一名研究者仅拿到 惠普 的系列级页面，另一名拿到华为具体型号卡，业务方要求当天输出“同期价格与促销谁更好”。第一轮先用 **完整 SKU** 与 **官方标示价** 判断两侧证据等级；第二轮为 **活动后条件** 写补证责任人和原始页面；第三轮按本表 POC 建立相同任务，不允许用系列声誉补空；第四轮只交付事实句、缺口句和下一步。观察员逐项检查产品 ID 或代际、限定词、日期、失败日志和结论范围。若研究者把页面未提供写成不支持，或在对象未对齐时给赢家，本轮直接重做。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
