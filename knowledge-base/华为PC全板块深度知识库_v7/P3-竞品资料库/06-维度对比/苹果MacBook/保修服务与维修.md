# 苹果MacBook × 华为｜保修服务与维修取证工作表

> 这是一份执行型取证表：品牌规则决定去哪里找，维度规则决定找什么，POC 决定怎样验证，结论始终保留范围。

## 一、字段定义与完成标准

本维度核对当前地区、具体型号与购买条件下的标准保修、付费服务、维修入口、数据责任和升级方式。产品卖点页不能替代官方服务条款，口头咨询也必须留受理记录。

表格验收包含身份、字段、条件、来源、日期、POC 和更新状态七项；任何一项无法追踪，都停止对外使用并保留问题单。

1. **适用产品与地区**：把‘完整型号、购买地和使用地’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
2. **标准保修依据**：把‘期限、起算与凭证以当前条款为准’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
3. **覆盖部件**：把‘整机、电池、附件和易损件分开’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
4. **除外条件**：把‘意外、进液、改装等只按原条款记录’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
5. **服务方式**：把‘送修、寄修、上门或现场支持分别核验’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
6. **时效表述**：把‘响应、取件、维修完成不能混写’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
7. **数据与隐私**：把‘备份、解锁、清除和保密责任’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
8. **付费或项目服务**：把‘标准权益与另购服务包分开’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。

## 二、苹果MacBook 官网定位方法

**身份主键**：主键使用 MacBook 系列、标称尺寸和芯片名称；Air 两个尺寸、Pro 的不同尺寸与 M5/M5 Pro/M5 Max、Neo A18 Pro 分别建档。共享 URL 不能作为合并理由。

**取证路线**：Mac 家族页发现阵容，Air、Pro、Neo 系列页定位产品，再用机型比较页交叉核对尺寸与芯片组合。具体配置仍回到相应官方页面和限定词。

**品牌端高风险点**：系列页面的最高统一内存、最高存储或最长续航不能自动下放到每个芯片和尺寸；统一内存也不能与其他平台内存自行换算性能等价。

执行时先读 `P3-竞品资料库/05-官方来源登记/苹果MacBook.md`，再进入 `P3-竞品资料库/07-品牌官网当前产品事实/苹果` 选择与用户任务相符的具体产品卡。事实卡只保留其核验日已确认摘要；需要当前配置时必须回到卡内官方 URL。P3/08 案例只示范如何组织证据和 POC，不可把案例中的另一产品事实移入本表。

## 三、华为侧对应证据

先从 `P1-产品参数库/00-全库横向索引/全型号总览.md` 选择具体产品，再固定鸿蒙或 Windows 路线与销售配置。维度入口为 `P7-常见问题库/02-售后政策/官方售后入口.md`。该专题由常见问题库的官方售后入口提供；具体权益仍按型号、地区与服务时点复核，产品身份从 P1 固定。

华为侧同样遵守“系列、具体型号、销售 SKU、动态销售条件分层”。卖点与限制可帮助解释适用场景，但数值仍回到产品事实或型号检索卡。缺少对应字段时写“华为侧待补证”，不得用其他 MateBook 或商城另一配置替代。

## 四、不可直接比较的口径

1. **发布限制**：不同地区保修条款不能互换。缺少同条件材料时，本项保持空白并给出补证动作。
2. **发布限制**：标准保修与付费服务包不能合并。缺少同条件材料时，本项保持空白并给出补证动作。
3. **发布限制**：响应时间不等于修复时间。缺少同条件材料时，本项保持空白并给出补证动作。
4. **发布限制**：系列宣传不能证明当前序列号权益。缺少同条件材料时，本项保持空白并给出补证动作。
5. **发布限制**：备件价格和库存属于动态信息。缺少同条件材料时，本项保持空白并给出补证动作。
6. **发布限制**：法规权利与厂商商业政策分别说明。缺少同条件材料时，本项保持空白并给出补证动作。

官网沉默不构成否定事实，营销命名也不构成性能事实。两类内容都不能越过证据闸门进入胜负表达。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 苹果MacBook 完整对象：主键使用 MacBook 系列、标称尺寸和芯片名称；Air 两个尺寸、Pro 的不同尺寸与 M5/M5 Pro/M5 Max、Neo A18 Pro 分别建档。共享 URL 不能作为合并理由。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；Mac 家族页发现阵容，Air、Pro、Neo 系列页定位产品，再用机型比较页交叉核对尺寸与芯片组合。具体配置仍回到相应官方页面和限定词。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

用一个模拟故障走完整服务发现：输入双方完整型号、地区和购买日期，查官方权益与服务入口，记录是否需要序列号、备份提醒、受理方式、预计节点和升级渠道。不得提交真实维修或泄露设备标识；结果只作为当日流程快照。

POC 只提供场景证据。材料包括对象、版本、授权样本、外设网络、步骤日志、异常和复核；不得产生整机总分。

## 八、结论句式

- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’
- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’

本表的合规结果可以是不形成推荐。没有同口径证据时，暂停发布优于生成看似完整的胜负表。

## 九、更新与合规

1. 新页面不覆盖旧日期快照，二者并列归档。
2. 所有限定、单位和适用对象完整引用。
3. 金额、优惠和库存不在通用模板预填。
4. 不引用跑分、销量或市场份额判产品。
5. 页面沉默不能作为负面证据。
6. 采购结论不由单维度模板自动生成。
7. 截图与录屏按组织安全规则保存。
8. 最终稿审查身份、来源、范围和待办。

## 十一、品牌 × 维度桌面演练

演练从一张未完成表开始：苹果MacBook 侧只有 P3/07 摘要，华为侧只有型号名称。学员需在二十分钟内为 **适用产品与地区** 找到正确入口，为 **标准保修依据** 标注证据等级，为 **覆盖部件** 设计 POC；找不到的信息写清原因，不追求填满。复核员交换双方证据后盲查原页，并故意改变一个配置或版本，观察结论是否随之收窄。最终答案不得出现总分，只允许确认事实、不可比口径、任务结果和补证排期。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
