# 苹果MacBook × 华为｜同期价格与促销取证工作表

> 使用者应把华为与竞品看成两个独立证据链；一侧资料更丰富，不能成为替另一侧补空的理由。

## 一、字段定义与完成标准

本维度只建立同一时间、地区、渠道和完整 SKU 的购买条件快照。价格不是稳定产品参数；券、补贴、折抵、分期、赠品、套装和库存必须拆开，过期快照仅用于追溯。

表格验收包含身份、字段、条件、来源、日期、POC 和更新状态七项；任何一项无法追踪，都停止对外使用并保留问题单。

1. **完整 SKU**：把‘系统、平台、内存、存储、颜色与套装写全’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
2. **官方标示价**：把‘记录页面原词与时间，不作长期事实’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
3. **活动后条件**：把‘券、会员、支付、地区与名额逐项’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
4. **补贴**：把‘国家或地方、资格、核销和有效期’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
5. **折抵或以旧换新**：把‘估值与成交价分开’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
6. **赠品与套装**：把‘型号、数量、价值表述和退货影响’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
7. **库存与交付**：把‘地区、仓库、下单时点和预计状态’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。
8. **报价有效性**：把‘截图、URL、配置和复核节点齐全’转成两侧同口径字段；网页没有说明时写缺口，不凭产品定位推断。

## 二、苹果MacBook 官网定位方法

**身份主键**：主键使用 MacBook 系列、标称尺寸和芯片名称；Air 两个尺寸、Pro 的不同尺寸与 M5/M5 Pro/M5 Max、Neo A18 Pro 分别建档。共享 URL 不能作为合并理由。

**取证路线**：Mac 家族页发现阵容，Air、Pro、Neo 系列页定位产品，再用机型比较页交叉核对尺寸与芯片组合。具体配置仍回到相应官方页面和限定词。

**品牌端高风险点**：系列页面的最高统一内存、最高存储或最长续航不能自动下放到每个芯片和尺寸；统一内存也不能与其他平台内存自行换算性能等价。

执行时先读 `P3-竞品资料库/05-官方来源登记/苹果MacBook.md`，再进入 `P3-竞品资料库/07-品牌官网当前产品事实/苹果` 选择与用户任务相符的具体产品卡。事实卡只保留其核验日已确认摘要；需要当前配置时必须回到卡内官方 URL。P3/08 案例只示范如何组织证据和 POC，不可把案例中的另一产品事实移入本表。

## 三、华为侧对应证据

先从 `P1-产品参数库/00-全库横向索引/全型号总览.md` 选择具体产品，再固定鸿蒙或 Windows 路线与销售配置。维度入口为 `P4-价格政策库（机密）/对外报价合规检查.md`。该专题由受控价格目录提供；仅限获授权人员按当前记录使用，产品身份仍从 P1 固定。

华为侧同样遵守“系列、具体型号、销售 SKU、动态销售条件分层”。卖点与限制可帮助解释适用场景，但数值仍回到产品事实或型号检索卡。缺少对应字段时写“华为侧待补证”，不得用其他 MateBook 或商城另一配置替代。

## 四、不可直接比较的口径

1. **发布限制**：原价、到手价与补贴后价不能混写。缺少同条件材料时，本项保持空白并给出补证动作。
2. **发布限制**：不同渠道券和赠品不能跨用。缺少同条件材料时，本项保持空白并给出补证动作。
3. **发布限制**：教育、企业与个人条件不同。缺少同条件材料时，本项保持空白并给出补证动作。
4. **发布限制**：分期月供不等于总成本。缺少同条件材料时，本项保持空白并给出补证动作。
5. **发布限制**：有货与可按期交付不是一回事。缺少同条件材料时，本项保持空白并给出补证动作。
6. **发布限制**：历史最低、全网最低和保价不得无证据使用。缺少同条件材料时，本项保持空白并给出补证动作。

官网沉默不构成否定事实，营销命名也不构成性能事实。两类内容都不能越过证据闸门进入胜负表达。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 苹果MacBook 完整对象：主键使用 MacBook 系列、标称尺寸和芯片名称；Air 两个尺寸、Pro 的不同尺寸与 M5/M5 Pro/M5 Max、Neo A18 Pro 分别建档。共享 URL 不能作为合并理由。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；Mac 家族页发现阵容，Air、Pro、Neo 系列页定位产品，再用机型比较页交叉核对尺寸与芯片组合。具体配置仍回到相应官方页面和限定词。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

执行双人报价复现：甲按既定地区、渠道和完整配置生成当日快照，乙仅凭记录重新定位同一对象并核对活动条件、库存和有效期。任何不可复现项转为待确认。工作表不预填金额，对外前由获授权人员在下单节点再次查询。

POC 只提供场景证据。材料包括对象、版本、授权样本、外设网络、步骤日志、异常和复核；不得产生整机总分。

## 八、结论句式

- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’

本表的合规结果可以是不形成推荐。没有同口径证据时，暂停发布优于生成看似完整的胜负表。

## 九、更新与合规

1. 新页面不覆盖旧日期快照，二者并列归档。
2. 所有限定、单位和适用对象完整引用。
3. 金额、优惠和库存不在通用模板预填。
4. 不引用跑分、销量或市场份额判产品。
5. 页面沉默不能作为负面证据。
6. 采购结论不由单维度模板自动生成。
7. 截图与录屏按组织安全规则保存。
8. 最终稿审查身份、来源、范围和待办。

## 十一、品牌 × 维度桌面演练

角色演练包含取证人、业务用户和审计人。业务用户提出 同期价格与促销 的模糊要求；取证人先用 **完整 SKU** 把需求具体化，再从 苹果MacBook 与华为入口分别记录 **官方标示价**，最后把 **活动后条件** 放进任务脚本。审计人隐藏一个关键限定或换掉 SKU，取证人必须发现并暂停旧结论。合格交付应能由第三人复跑，且明确哪些句子来自官网、哪些来自本轮观察、哪些仍是空白。若只能复述卖点，说明工作表尚未执行。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
