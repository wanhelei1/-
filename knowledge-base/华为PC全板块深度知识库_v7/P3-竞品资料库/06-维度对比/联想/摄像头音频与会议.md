# 联想 × 华为｜摄像头音频与会议取证工作表

> 使用者应把华为与竞品看成两个独立证据链；一侧资料更丰富，不能成为替另一侧补空的理由。

## 一、字段定义与完成标准

本维度验证摄像头、麦克风、扬声器、隐私控制、系统算法和会议应用的完整链路。像素、麦克风数量或 AI 名称不能独立代表会议效果，网络与房间环境必须记录。

完成标准以可复核为准：陌生同事无需口头提示即可找到双方页面、识别空缺、执行脚本并得出同一范围的结论。

1. **摄像头**：审核者将检查是否做到分辨率、位置、红外或物理遮挡按官网记录。事实、条件、链接和时间缺一项，本行不得进入结论。
2. **麦克风**：审核者将检查是否做到数量、阵列与拾音模式不混写。事实、条件、链接和时间缺一项，本行不得进入结论。
3. **扬声器与音频**：审核者将检查是否做到单元、布局、接口和应用输出分别核验。事实、条件、链接和时间缺一项，本行不得进入结论。
4. **隐私控制**：审核者将检查是否做到物理、系统与应用权限分层。事实、条件、链接和时间缺一项，本行不得进入结论。
5. **系统音视频能力**：审核者将检查是否做到版本、模式和支持应用条件。事实、条件、链接和时间缺一项，本行不得进入结论。
6. **会议应用**：审核者将检查是否做到名称、版本、账号和内部设备选择。事实、条件、链接和时间缺一项，本行不得进入结论。
7. **网络与环境**：审核者将检查是否做到带宽、延迟、噪声、光线和距离。事实、条件、链接和时间缺一项，本行不得进入结论。
8. **外接设备**：审核者将检查是否做到耳机、摄像头、采集卡和扩展坞链路。事实、条件、链接和时间缺一项，本行不得进入结论。

## 四、不可直接比较的口径

1. **比较阻断**：像素数不等于会议画质。不要用平均、折算或经验把两种资料强行对齐。
2. **比较阻断**：麦克风数量不等于拾音效果。不要用平均、折算或经验把两种资料强行对齐。
3. **比较阻断**：AI 降噪名称不能跨平台等价。不要用平均、折算或经验把两种资料强行对齐。
4. **比较阻断**：不同会议应用压缩不可直接比较。不要用平均、折算或经验把两种资料强行对齐。
5. **比较阻断**：网络波动不能归因于整机。不要用平均、折算或经验把两种资料强行对齐。
6. **比较阻断**：系统默认设备与应用选择可能不同。不要用平均、折算或经验把两种资料强行对齐。

出现口径冲突时保留两份原文和时间戳，不自行择利采用；冲突解决之前，用户只能看到中性的待核验说明。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 联想 完整对象：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

在同一会议应用和账号下，固定网络、座位、光线与噪声，执行入会、发言、共享、录制允许的测试片段和外接耳机切换。由远端两名观察者独立记录可懂度与失败；本地保存设备选择、权限和异常，不生成无依据音质排名。

每轮都要能回答谁、用哪台、在何环境、做何步骤、得到什么、怎样恢复。无法回答时状态保持未执行。

## 八、结论句式

- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’
- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’

任何‘都、绝对、必然、最’都需要可核验范围；无法给范围就删去，不用营销语气掩盖证据空白。

## 九、更新与合规

1. 版本日志说明谁因何证据改了哪一行。
2. 系列范围不能下放为全系标配。
3. 动态字段在发布与下单两次复核。
4. 测试结果只属于所列样机和环境。
5. 空格保留到原始证据取得为止。
6. 推荐必须回到用户约束与取舍。
7. 素材、账号和网络均使用授权环境。
8. 复核者抽三条事实一分钟反查。

## 十一、品牌 × 维度桌面演练

一名研究者仅拿到 联想 的系列级页面，另一名拿到华为具体型号卡，业务方要求当天输出“摄像头音频与会议谁更好”。第一轮先用 **摄像头** 与 **麦克风** 判断两侧证据等级；第二轮为 **扬声器与音频** 写补证责任人和原始页面；第三轮按本表 POC 建立相同任务，不允许用系列声誉补空；第四轮只交付事实句、缺口句和下一步。观察员逐项检查产品 ID 或代际、限定词、日期、失败日志和结论范围。若研究者把页面未提供写成不支持，或在对象未对齐时给赢家，本轮直接重做。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
