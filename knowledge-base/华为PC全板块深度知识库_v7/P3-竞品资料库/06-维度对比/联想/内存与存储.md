# 联想 × 华为｜内存与存储取证工作表

> 本页的目标是获得可审计差异，而非收集尽可能多的形容词。比较失败也应留下明确的缺口和下一动作。

## 一、字段定义与完成标准

本维度区分安装容量、类型、架构、可用空间、扩展方式和真实文件流程。容量大不自动代表任务更快；统一内存、板载内存、插槽内存和显存也不能自行折算。

完成标准以可复核为准：陌生同事无需口头提示即可找到双方页面、识别空缺、执行脚本并得出同一范围的结论。

1. **内存容量**：审核者将检查是否做到绑定当前 SKU，系列最高另列。事实、条件、链接和时间缺一项，本行不得进入结论。
2. **内存类型与架构**：审核者将检查是否做到按官网原词记录，不推算等价性能。事实、条件、链接和时间缺一项，本行不得进入结论。
3. **通道或封装**：审核者将检查是否做到未明示时不凭拆机图补写。事实、条件、链接和时间缺一项，本行不得进入结论。
4. **升级与插槽**：审核者将检查是否做到可更换、板载、可选范围分别记录。事实、条件、链接和时间缺一项，本行不得进入结论。
5. **存储标称容量**：审核者将检查是否做到区分起步、可选与当前配置。事实、条件、链接和时间缺一项，本行不得进入结论。
6. **存储类型与接口**：审核者将检查是否做到仅记录官网明确的协议或介质。事实、条件、链接和时间缺一项，本行不得进入结论。
7. **扩展与更换条件**：审核者将检查是否做到考虑保修、拆装与组织政策。事实、条件、链接和时间缺一项，本行不得进入结论。
8. **备份与恢复**：审核者将检查是否做到记录迁移、恢复分区和数据处置边界。事实、条件、链接和时间缺一项，本行不得进入结论。

## 四、不可直接比较的口径

1. **比较阻断**：标称容量与系统可用容量不是同一口径。不要用平均、折算或经验把两种资料强行对齐。
2. **比较阻断**：统一内存和传统内存不自行换算。不要用平均、折算或经验把两种资料强行对齐。
3. **比较阻断**：双插槽或双盘位不等于已安装两块。不要用平均、折算或经验把两种资料强行对齐。
4. **比较阻断**：最高容量不是购买配置。不要用平均、折算或经验把两种资料强行对齐。
5. **比较阻断**：顺序读写数字不代表全部工作流。不要用平均、折算或经验把两种资料强行对齐。
6. **比较阻断**：可扩展也不等于用户应自行拆机。不要用平均、折算或经验把两种资料强行对齐。

出现口径冲突时保留两份原文和时间戳，不自行择利采用；冲突解决之前，用户只能看到中性的待核验说明。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 联想 完整对象：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

选取用户常见的多应用组合与脱敏大文件，记录冷启动、打开、编辑、保存、导出和空间变化。验证应用是否因内存或磁盘不足失败，并检查外接存储、备份与恢复。只描述本次工作流是否闭环，不由单一占用率宣布优劣。

每轮都要能回答谁、用哪台、在何环境、做何步骤、得到什么、怎样恢复。无法回答时状态保持未执行。

## 八、结论句式

- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’
- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’

任何‘都、绝对、必然、最’都需要可核验范围；无法给范围就删去，不用营销语气掩盖证据空白。

## 九、更新与合规

1. 版本日志说明谁因何证据改了哪一行。
2. 系列范围不能下放为全系标配。
3. 动态字段在发布与下单两次复核。
4. 测试结果只属于所列样机和环境。
5. 空格保留到原始证据取得为止。
6. 推荐必须回到用户约束与取舍。
7. 素材、账号和网络均使用授权环境。
8. 复核者抽三条事实一分钟反查。

## 十一、品牌 × 维度桌面演练

一名研究者仅拿到 联想 的系列级页面，另一名拿到华为具体型号卡，业务方要求当天输出“内存与存储谁更好”。第一轮先用 **内存容量** 与 **内存类型与架构** 判断两侧证据等级；第二轮为 **通道或封装** 写补证责任人和原始页面；第三轮按本表 POC 建立相同任务，不允许用系列声誉补空；第四轮只交付事实句、缺口句和下一步。观察员逐项检查产品 ID 或代际、限定词、日期、失败日志和结论范围。若研究者把页面未提供写成不支持，或在对象未对齐时给赢家，本轮直接重做。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
