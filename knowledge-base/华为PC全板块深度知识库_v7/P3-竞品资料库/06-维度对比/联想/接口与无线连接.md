# 联想 × 华为｜接口与无线连接取证工作表

> 本模板允许空填，但不允许猜填。只有来源、对象、日期、限定和任务同时完整，字段才可进入对外结论。

## 一、字段定义与完成标准

本维度验证物理接口、协议、视频、供电、无线标准和完整外设链路。接口外形相同不等于数据速率、显示输出或充电方向相同；理论无线规格也不等于现场吞吐与稳定。

完成标准以可复核为准：陌生同事无需口头提示即可找到双方页面、识别空缺、执行脚本并得出同一范围的结论。

1. **接口数量与位置**：审核者将检查是否做到按左右侧或机身位置逐个记录。事实、条件、链接和时间缺一项，本行不得进入结论。
2. **USB或雷电能力**：审核者将检查是否做到形态、协议、速率、视频和供电分栏。事实、条件、链接和时间缺一项，本行不得进入结论。
3. **显示输出**：审核者将检查是否做到记录直连或转接、数量与官方条件。事实、条件、链接和时间缺一项，本行不得进入结论。
4. **读卡与音频**：审核者将检查是否做到确认规格、形态和当前配置。事实、条件、链接和时间缺一项，本行不得进入结论。
5. **充电输入输出**：审核者将检查是否做到分清电脑受电、反向供电与协议。事实、条件、链接和时间缺一项，本行不得进入结论。
6. **Wi-Fi**：审核者将检查是否做到记录标准、频段及组织网络条件。事实、条件、链接和时间缺一项，本行不得进入结论。
7. **蓝牙**：审核者将检查是否做到记录版本和目标外设功能。事实、条件、链接和时间缺一项，本行不得进入结论。
8. **扩展坞链路**：审核者将检查是否做到电脑、线缆、坞、显示器和驱动共同锁定。事实、条件、链接和时间缺一项，本行不得进入结论。

## 二、联想 官网定位方法

**身份主键**：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。

**取证路线**：消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。

**品牌端高风险点**：联想与 ThinkPad 虽共享部分商城体系，产品线事实仍分开；商品页配置与系列宣传也分开。页面增删 AI、新款等词时，先看产品 ID 与硬件是否变化。

执行时先读 `P3-竞品资料库/05-官方来源登记/联想.md`，再进入 `P3-竞品资料库/07-品牌官网当前产品事实/联想` 选择与用户任务相符的具体产品卡。事实卡只保留其核验日已确认摘要；需要当前配置时必须回到卡内官方 URL。P3/08 案例只示范如何组织证据和 POC，不可把案例中的另一产品事实移入本表。

## 四、不可直接比较的口径

1. **比较阻断**：USB-C 外形不能证明视频或充电。不要用平均、折算或经验把两种资料强行对齐。
2. **比较阻断**：端口数量不能替代协议能力。不要用平均、折算或经验把两种资料强行对齐。
3. **比较阻断**：理论无线速率不等于真实网络。不要用平均、折算或经验把两种资料强行对齐。
4. **比较阻断**：不同路由、驱动和干扰条件不可直接排名。不要用平均、折算或经验把两种资料强行对齐。
5. **比较阻断**：扩展坞成功一次不代表全型号兼容。不要用平均、折算或经验把两种资料强行对齐。
6. **比较阻断**：可选端口不写成全系标配。不要用平均、折算或经验把两种资料强行对齐。

出现口径冲突时保留两份原文和时间戳，不自行择利采用；冲突解决之前，用户只能看到中性的待核验说明。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 联想 完整对象：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

用用户目标显示器、扩展坞、移动硬盘、读卡器、网卡、耳机与充电设备搭建完整链路。逐件单测再组合，记录端口、线缆、驱动、输入源、睡眠唤醒和故障提示；无线测试固定路由与位置，并保留组织网络限制。

每轮都要能回答谁、用哪台、在何环境、做何步骤、得到什么、怎样恢复。无法回答时状态保持未执行。

## 八、结论句式

- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’
- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’

任何‘都、绝对、必然、最’都需要可核验范围；无法给范围就删去，不用营销语气掩盖证据空白。

## 九、更新与合规

1. 版本日志说明谁因何证据改了哪一行。
2. 系列范围不能下放为全系标配。
3. 动态字段在发布与下单两次复核。
4. 测试结果只属于所列样机和环境。
5. 空格保留到原始证据取得为止。
6. 推荐必须回到用户约束与取舍。
7. 素材、账号和网络均使用授权环境。
8. 复核者抽三条事实一分钟反查。

## 十一、品牌 × 维度桌面演练

演练从一张未完成表开始：联想 侧只有 P3/07 摘要，华为侧只有型号名称。学员需在二十分钟内为 **接口数量与位置** 找到正确入口，为 **USB或雷电能力** 标注证据等级，为 **显示输出** 设计 POC；找不到的信息写清原因，不追求填满。复核员交换双方证据后盲查原页，并故意改变一个配置或版本，观察结论是否随之收窄。最终答案不得出现总分，只允许确认事实、不可比口径、任务结果和补证排期。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
