# 联想 × 华为｜电池续航与充电取证工作表

> 每次使用都新建副本并写日期。旧表可以追溯，不能在官网、配置或任务变化后继续称为当前事实。

## 一、字段定义与完成标准

本维度同时记录电池容量、官网续航测试、充电器、充电协议和目标离电任务。实验室最长时长不是用户承诺；容量相近也不能推出系统、屏幕和负载下续航相同。

完成标准以可复核为准：陌生同事无需口头提示即可找到双方页面、识别空缺、执行脚本并得出同一范围的结论。

1. **电池容量**：审核者将检查是否做到区分额定、典型及配置差异。事实、条件、链接和时间缺一项，本行不得进入结论。
2. **官网续航值**：审核者将检查是否做到保存测试项目、版本和所有条件。事实、条件、链接和时间缺一项，本行不得进入结论。
3. **充电器**：审核者将检查是否做到记录功率、重量、线缆与是否随附。事实、条件、链接和时间缺一项，本行不得进入结论。
4. **充电协议**：审核者将检查是否做到确认设备、端口和电源组合。事实、条件、链接和时间缺一项，本行不得进入结论。
5. **快充表述**：审核者将检查是否做到保留起始电量、关机或使用状态和时间。事实、条件、链接和时间缺一项，本行不得进入结论。
6. **离电任务**：审核者将检查是否做到应用、亮度、网络、外设和模式固定。事实、条件、链接和时间缺一项，本行不得进入结论。
7. **电池健康**：审核者将检查是否做到样机循环、状态和异常另记。事实、条件、链接和时间缺一项，本行不得进入结论。
8. **低电策略**：审核者将检查是否做到记录性能变化、休眠和任务恢复。事实、条件、链接和时间缺一项，本行不得进入结论。

## 二、联想 官网定位方法

**身份主键**：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。

**取证路线**：消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。

**品牌端高风险点**：联想与 ThinkPad 虽共享部分商城体系，产品线事实仍分开；商品页配置与系列宣传也分开。页面增删 AI、新款等词时，先看产品 ID 与硬件是否变化。

执行时先读 `P3-竞品资料库/05-官方来源登记/联想.md`，再进入 `P3-竞品资料库/07-品牌官网当前产品事实/联想` 选择与用户任务相符的具体产品卡。事实卡只保留其核验日已确认摘要；需要当前配置时必须回到卡内官方 URL。P3/08 案例只示范如何组织证据和 POC，不可把案例中的另一产品事实移入本表。

## 四、不可直接比较的口径

1. **比较阻断**：容量与续航时长不能直接换算。不要用平均、折算或经验把两种资料强行对齐。
2. **比较阻断**：不同测试视频、网页或办公脚本不可混比。不要用平均、折算或经验把两种资料强行对齐。
3. **比较阻断**：最长值不等于每个 SKU。不要用平均、折算或经验把两种资料强行对齐。
4. **比较阻断**：快充功率不等于固定充电时间。不要用平均、折算或经验把两种资料强行对齐。
5. **比较阻断**：第三方充电器条件不能代替官方组合。不要用平均、折算或经验把两种资料强行对齐。
6. **比较阻断**：新机样机结果不外推长期电池状态。不要用平均、折算或经验把两种资料强行对齐。

出现口径冲突时保留两份原文和时间戳，不自行择利采用；冲突解决之前，用户只能看到中性的待核验说明。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 联想 完整对象：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

定义一段真实移动任务：文档、网页、会议和文件处理的时间比例固定，记录视觉等效亮度、网络、音量、外设、模式、起止电量和休眠。交叉执行两轮；充电测试固定电源、线缆和使用状态，只报告该轮曲线及异常。

每轮都要能回答谁、用哪台、在何环境、做何步骤、得到什么、怎样恢复。无法回答时状态保持未执行。

## 八、结论句式

- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’
- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’

任何‘都、绝对、必然、最’都需要可核验范围；无法给范围就删去，不用营销语气掩盖证据空白。

## 九、更新与合规

1. 版本日志说明谁因何证据改了哪一行。
2. 系列范围不能下放为全系标配。
3. 动态字段在发布与下单两次复核。
4. 测试结果只属于所列样机和环境。
5. 空格保留到原始证据取得为止。
6. 推荐必须回到用户约束与取舍。
7. 素材、账号和网络均使用授权环境。
8. 复核者抽三条事实一分钟反查。

## 十一、品牌 × 维度桌面演练

角色演练包含取证人、业务用户和审计人。业务用户提出 电池续航与充电 的模糊要求；取证人先用 **电池容量** 把需求具体化，再从 联想 与华为入口分别记录 **官网续航值**，最后把 **充电器** 放进任务脚本。审计人隐藏一个关键限定或换掉 SKU，取证人必须发现并暂停旧结论。合格交付应能由第三人复跑，且明确哪些句子来自官网、哪些来自本轮观察、哪些仍是空白。若只能复述卖点，说明工作表尚未执行。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
