# 联想 × 华为｜操作系统与软件兼容取证工作表

> 本页的目标是获得可审计差异，而非收集尽可能多的形容词。比较失败也应留下明确的缺口和下一动作。

## 一、字段定义与完成标准

本维度先确认系统路线、处理器架构和用户不可中断的软件工作流，再讨论系统体验。可下载、可安装、可启动、核心功能可用、性能满足与厂商支持是不同层级。

完成标准以可复核为准：陌生同事无需口头提示即可找到双方页面、识别空缺、执行脚本并得出同一范围的结论。

1. **预装系统与版本**：审核者将检查是否做到绑定当前 SKU、地区和核验日。事实、条件、链接和时间缺一项，本行不得进入结论。
2. **处理器架构**：审核者将检查是否做到用于软件与驱动支持核验。事实、条件、链接和时间缺一项，本行不得进入结论。
3. **应用名称与版本**：审核者将检查是否做到禁止用软件类别替代准确版本。事实、条件、链接和时间缺一项，本行不得进入结论。
4. **插件、宏与字体**：审核者将检查是否做到逐项确认许可和依赖。事实、条件、链接和时间缺一项，本行不得进入结论。
5. **文件格式**：审核者将检查是否做到打开、编辑、保存、导出分别验证。事实、条件、链接和时间缺一项，本行不得进入结论。
6. **外设驱动**：审核者将检查是否做到打印、加密狗、采集或专业设备。事实、条件、链接和时间缺一项，本行不得进入结论。
7. **虚拟化或兼容层**：审核者将检查是否做到不等同原生支持，记录限制。事实、条件、链接和时间缺一项，本行不得进入结论。
8. **企业账号与网络**：审核者将检查是否做到VPN、证书、安全软件和管理策略。事实、条件、链接和时间缺一项，本行不得进入结论。

## 四、不可直接比较的口径

1. **比较阻断**：网页可用不等于客户端可用。不要用平均、折算或经验把两种资料强行对齐。
2. **比较阻断**：能安装不等于核心流程完整。不要用平均、折算或经验把两种资料强行对齐。
3. **比较阻断**：兼容层不等于原生或厂商支持。不要用平均、折算或经验把两种资料强行对齐。
4. **比较阻断**：同名应用跨系统功能可能不同。不要用平均、折算或经验把两种资料强行对齐。
5. **比较阻断**：一次打开文件不代表保存导出无损。不要用平均、折算或经验把两种资料强行对齐。
6. **比较阻断**：个人环境成功不代替企业验证。不要用平均、折算或经验把两种资料强行对齐。

出现口径冲突时保留两份原文和时间戳，不自行择利采用；冲突解决之前，用户只能看到中性的待核验说明。

## 五、取证步骤

1. 建立用户任务、成功标准和不可接受结果，禁止先选品牌再反推场景。
2. 按品牌登记锁定 联想 完整对象：产品线、完整商品名、年份、尺寸或平台变体、补充码和产品 ID 共同去重。ThinkBook 名称中的加号、04CD，小新 IPH11 与 YOGA Aura 等都不能清洗掉。
3. 从 P3/07 事实卡进入官网，依据本维度八个字段逐项摘录；消费站和笔记本目录发现 YOGA、小新、拯救者；ThinkBook 可从 ThinkPad/ThinkBook 商城发现，随后都回到 item 或 tk 的具体商品页并保存产品 ID。
4. 在 P1 固定华为具体型号、系统路线和 SKU；同一字段找不到时保留空白。
5. 做口径审查：单位、配置、最高/可选/起始/约、测试环境、地区和日期逐项对齐。
6. 执行 POC，只记录本轮输入、步骤、结果、异常和恢复；不把第三方跑分或个人体验放入事实栏。
7. 两人交叉复核 URL、本地路径和结论范围；动态信息在发布或下单节点再次查询。

## 七、POC 任务

由用户提供准确软件、插件、字体、许可和脱敏样本；双方完成取得、安装、登录、打开、编辑、保存、导出、打印或连接外设。记录错误和替代路径；只有业务负责人接受替代，才标条件通过。关键流程失败则停止参数比较。

每轮都要能回答谁、用哪台、在何环境、做何步骤、得到什么、怎样恢复。无法回答时状态保持未执行。

## 八、结论句式

- 缺口句：‘【字段】一侧仅有系列级资料或未提供，因此暂不比较，补证责任人为【角色】。’
- 更新句：‘原结论基于【日期】快照；页面或配置变化后已暂停复用，等待重新核验。’
- 事实句：‘在【日期】核验的【完整 SKU】官方资料中，双方分别确认到【字段】，适用范围为【条件】。’
- 差异句：‘双方在【字段】上的公开口径为【A】与【B】；该差异是否影响【任务】仍需按【脚本】验证。’
- POC句：‘在【样机/版本/环境】下，【任务】结果为通过、条件通过或不通过；结论仅覆盖本轮。’

任何‘都、绝对、必然、最’都需要可核验范围；无法给范围就删去，不用营销语气掩盖证据空白。

## 九、更新与合规

1. 版本日志说明谁因何证据改了哪一行。
2. 系列范围不能下放为全系标配。
3. 动态字段在发布与下单两次复核。
4. 测试结果只属于所列样机和环境。
5. 空格保留到原始证据取得为止。
6. 推荐必须回到用户约束与取舍。
7. 素材、账号和网络均使用授权环境。
8. 复核者抽三条事实一分钟反查。

## 十一、品牌 × 维度桌面演练

本轮采用反例法。研究者先围绕 联想 与华为的 操作系统与软件兼容 写一个预期结论，再分别从 **预装系统与版本**、**处理器架构**、**应用名称与版本** 设计会使结论失效的配置、版本或环境变化。若反例成立，原句必须改成带条件的本轮观察；若没有证据排除反例，字段保持待补。观察员不评价文案是否有说服力，只看来源能否反查、任务能否复现、未知是否诚实。最终不得用价格、品牌或单项数值替代用户约束。

演练记录附在工作表副本中，不回填为品牌事实；只有重新取得官网证据或完成锁定条件下的 POC，字段状态才可改变。
