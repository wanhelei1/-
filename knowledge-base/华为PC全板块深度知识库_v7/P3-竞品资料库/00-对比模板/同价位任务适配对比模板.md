# 同价位任务适配对比模板

## 模板用途

本模板用于回答“在某个预算和任务条件下，两个具体销售配置各需验证什么”，不是按价格区间自动生成排名。“同价位”必须对应同一地区、可比销售渠道、接近的核验时点与完整销售配置。促销券、换新补贴、赠品和库存状态必须另行记录，不得固化成产品事实。

## 一、需求基线

| 需求项 | 用户回答 | 需转换的验证任务 |
|---|---|---|
| 预算与核验日期 |  | 记录地区、渠道、到手价构成，区分标价与临时优惠 |
| 必须运行的软件 |  | 确认软件版本、插件、外设、授权和操作系统支持 |
| 主要工作文件 |  | 准备去隐私的样例项目，实测打开、编辑、导出与共享 |
| 移动频率与携带物 |  | 将整机、适配器、转接器和保护装备一起纳入携带验证 |
| 外接设备 |  | 列明显示器、存储、投影、鼠标、网卡、扩展坞及协议 |
| 会议与协同 |  | 设计摄像、收音、扬声、共享、投屏和文件流转测试 |
| 可接受的折中 |  | 区分“不可缺少”“可以补足”和“无关紧要” |

## 二、对象身份卡

- 华为产品全称：____；具体 SKU/配置：____；系统版本：____；官方页：____。
- 竞品全称：____；具体 SKU/配置：____；系统版本：____；官方页：____。
- 比价地区：____；销售渠道：____；核验日期和时间：____。
- 价格构成：商品____；必需适配器/转接器____；可选服务____；临时优惠____。

## 三、事实与任务对比表

| 维度 | 华为具体型号/配置 | 竞品具体型号/配置 | 双方来源与日期 | 需执行的验证 | 结论边界 |
|---|---|---|---|---|---|
| 系统与软件 |  |  |  | 安装或打开必须软件，验证文件和插件 | 区分原生、替代方案、虚拟化/远程方案 |
| 屏幕 |  |  |  | 用真实工作页面验证显示范围、缩放和环境反光 | 保留尺寸、比例、亮度等实验条件 |
| 处理器与图形能力 |  |  |  | 运行同一去隐私项目并记录任务是否完成 | 不用单一跑分代替业务任务 |
| 内存与存储 |  |  |  | 按并行应用、项目文件和留存周期计算 | 区分容量、可用容量、扩展与外置方案 |
| 重量与携带 |  |  |  | 主机加必须配件试携带 | 官方重量的配置和测量条件需保留 |
| 电池与供电 |  |  |  | 按亮度、网络、负载和省电策略设计测试 | 官方宣称与个人环境结果分开 |
| 接口与外设 |  |  |  | 用实际线材、显示器、存储和网络设备验证 | 接口外形不等于完整协议能力 |
| 协同与会议 |  |  |  | 按用户现有账号、设备、应用和网络做端到端测试 | “有功能”不等于用户环境已满足条件 |
| 维护与服务 |  |  |  | 查明所在城市的保修、送修和数据处理路径 | 区分厂商政策与渠道附加承诺 |
| 价格与可获得性 |  |  |  | 当日复核销售页、配置、库存和附加成本 | 动态信息，不进入长期稳定结论 |

## 四、证据等级

- A 级：品牌官网的具体产品规格页、服务政策原文或官方手册，可支撑对应事实。
- B 级：品牌官方发布、官方商城或认证文档，但需注意 SKU、地区与时点。
- C 级：权威媒体或平台公开内容，可用于发现问题和设计验证，不代替产品参数证据。
- D 级：用户评论、论坛、搜索摘要或无法回溯内容，只能作为待验证线索。

## 五、输出格式

不先写“哪台更好”，先写三段：

1. **已确认事实**：只列出两个具体销售配置和双方可回溯来源支持的差异。
2. **对用户任务的影响**：说明某个差异为什么可能影响某项任务，并给出实测方法。
3. **待核验与取舍**：列出仍缺的证据、用户愿意接受的折中，以及购买当日需重新确认的动态信息。

可使用以下句式：“在____任务中，已确认的差异是____。这个差异可能影响____，建议用____方法现场验证。由于____尚未确认，当前不生成整机胜负结论。”

## 六、异常处理

- 找不到同期完整配置：停止价格对比，将缺失字段标为“待核验”。
- 同名型号有多个 SKU：拆成多行，不合并内存、屏幕、系统或接口信息。
- 官方页面之间冲突：保留双方页面和核验日期，按地区、配置、时间差异排查，未解决前不下结论。
- 软件宣称与实测不一致：分别记录官方支持边界和当次环境，不将单次结果扩大到所有用户。

## 七、发布前审核

- [ ] 两个对象均已精确到型号、SKU、系统、地区和渠道。
- [ ] 每个参数的限定词、测试条件和来源日期均被保留。
- [ ] 价格、优惠、赠品、库存和服务已标为动态信息。
- [ ] 对比结论回到用户任务，没有用一个参数推导整机优劣。
- [ ] 缺失字段明确标为“待核验”，没有用推测补空。
