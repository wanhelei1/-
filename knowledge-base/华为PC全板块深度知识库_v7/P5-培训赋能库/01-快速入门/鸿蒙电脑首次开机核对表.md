# 鸿蒙电脑首次开机核对表

## 一、使用说明

本表用于门店交机、单位领用或个人首次启用鸿蒙电脑时的流程核对。不同机型、系统版本、地区、账号状态和组织策略可能使页面名称或可用功能不同，实际操作以设备界面、随附说明及当前官方支持页面为准。服务人员只在用户明确授权范围内协助，不代用户设置、记录或传播密码、验证码和恢复信息。

首次开机的目标不是把所有功能一次打开，而是让设备对象正确、账号可控、系统可用、数据有边界、关键任务得到验证、用户知道后续入口。任何需要抹除数据、绕过组织策略、使用未知来源安装包或修改安全设置的做法，不属于本核对表。

## 二、开机前：先不按电源键

- [ ] **核对对象**：记录完整销售名称、包装或设备上的型号信息、系统路线、颜色与配置。仅记录工作需要的字段，公开截图须遮挡设备标识。
- [ ] **外观与附件**：在光线充足处检查外壳、屏幕、接口和随附物是否有明显异常；附件范围以该产品当前包装清单为准，不凭其他型号经验补充。
- [ ] **供电条件**：使用随设备提供或官方认可、满足该设备要求的供电设备；线缆和接口无明显损伤。不要因接口外形相同就默认兼容。
- [ ] **使用者与所有权**：确认是个人设备、单位资产还是演示设备。单位设备先问是否有统一账号、网络、应用、加密和终端管理要求。
- [ ] **数据来源**：若要迁移旧设备，先确认备份、迁移范围、敏感数据、应用授权和旧设备是否仍可访问。迁移不是备份。
- [ ] **网络准备**：个人网络或获授权的组织网络可用。公共网络不用于输入敏感信息；企业证书、代理和网络准入由组织 IT 处理。

**停止条件**：包装或设备明显受损、疑似进液或电池变形、供电异常、资产归属不清、用户无法确认数据授权时，停止初始化并联系销售、组织管理员或官方服务。

## 三、首次引导：用户本人做关键决定

### 1. 地区、语言与辅助功能

- [ ] 由用户确认语言、地区、键盘或输入方式。
- [ ] 如有无障碍需求，查看当前系统提供的辅助入口；不替用户假设偏好。
- [ ] 记录后续是否需要更换输入法、显示比例或字体，但不要在未完成基本初始化时大量改动。

### 2. 网络与许可页面

- [ ] 连接用户授权的网络；不询问、抄录或拍摄网络密码。
- [ ] 请用户阅读隐私声明、服务协议和可选授权，说明“必需”和“可选”应以当前页面为准。
- [ ] 对诊断、个性化、位置或云服务等选项，不替用户默认同意；无法解释时打开官方说明或请用户稍后决定。

### 3. 账号与安全

- [ ] 用户自行登录或创建所需账号，自行输入密码和验证码。
- [ ] 设置锁屏凭据时确认用户理解保存方式；服务人员不记录明文密码。
- [ ] 若系统显示恢复、找回或密钥相关信息，让用户按页面提示保存在安全位置，不拍入普通服务记录。
- [ ] 单位账号、设备管理或安全策略由授权管理员执行；门店人员不绕过策略完成个人化设置。

**证据记录**：只记录“账号流程已完成/用户选择稍后完成”“锁屏已设置/未设置及原因”，不记录账号完整标识和凭据。

## 四、进入桌面后的基础核对

### 1. 设备与系统状态

- [ ] 在系统信息入口核对设备名称、型号、系统版本和存储状态，与交付对象一致。
- [ ] 检查日期、时区和时间是否合理；时间错误可能影响登录、证书和更新。
- [ ] 查看系统更新入口，仅安装当前官方或组织批准的更新。更新前接电、保存工作，过程中不强制关机。
- [ ] 更新后记录版本和结果；“已是最新”只表示当次检查结果，不是永久状态。

### 2. 显示、声音与输入

- [ ] 检查屏幕显示是否有明显异常，调整亮度到用户舒适范围；不作医疗效果承诺。
- [ ] 测试键盘、触控板或指向设备的基本输入；手势与快捷功能以当前系统帮助为准。
- [ ] 播放无版权风险的测试音频，确认扬声器；使用系统测试确认麦克风与摄像头前，先告知用户并关闭无关应用。
- [ ] 检查隐私权限是否符合用户选择，不为演示方便永久开放不必要权限。

### 3. 存储与文件位置

- [ ] 向用户展示本地文件、下载、回收或删除位置以及当前可见的云端入口，但不擅自开启同步。
- [ ] 创建一个无敏感内容的测试文件，确认保存、重命名、移动和删除流程。
- [ ] 解释同步、迁移和备份不是同一件事；重要资料至少保留用户认可的备份方案。

## 五、应用与兼容性核验

先做应用清单，再安装。清单至少含：应用准确名称、版本、用途、登录方式、许可证、插件、文件格式、外设和网络条件。安装来源应为系统当前认可的应用分发入口、软件厂商官方渠道或组织批准渠道。

兼容性分五层记录：能否取得安装包；能否安装；能否启动登录；关键工作流能否完成；软件厂商或组织是否支持。前一层通过不代表后一层通过。

**验证示例**：用户依赖一款专业应用。不要回答“鸿蒙电脑能不能装所有同类软件”，而是用用户的准确版本和脱敏样本完成：打开文件、编辑关键对象、保存、导出、连接必要外设。每步记录结果和异常。无法验证时把该应用标为“待验证”，为用户保留原设备或其他工作路径，不以口头保证替代测试。

本地参考：`P7-常见问题库/01-售前FAQ/软件与兼容FAQ.md`、`P7-常见问题库/06-高频问答/04-专业软件能否安装.md`。

## 六、协同与外设：按需求逐项开通

- [ ] 先问用户要完成的是文件互传、跨设备输入、屏幕协作、耳机切换还是其他具体任务。
- [ ] 核对电脑、手机、平板或外设的准确型号、系统版本、账号、网络与蓝牙等前提；以当前官方说明为准。
- [ ] 每次只验证一个功能，使用脱敏文件；记录连接步骤、成功标准和失败提示。
- [ ] 涉及账号、相册、剪贴板、通知或文件权限时，由用户决定授权范围，演示后可按需要关闭。
- [ ] 打印机、扩展坞、显示器和专业外设必须在目标链路验证。接口外形相同不代表信号能力、供电和驱动一定满足。

合格表述：“在当前这组设备、版本和账号条件下，我们完成了这项操作。”不合格表述：“所有设备都能无缝连接”“以后一定一直可用”。

## 七、资料迁移

1. 列出需要迁移的文件夹、邮件或浏览器资料、应用数据和组织文件，标记敏感级别。
2. 确认源设备可用，完成独立备份，并检查备份能否打开。
3. 使用当前官方提供、适合目标系统的迁移方式；过程中接电，避免网络中断。
4. 迁移后以数量抽查加关键文件逐一打开的方式验收；不要只看“任务完成”。
5. 应用需重新安装或登录的，单独列清单；加密文件、授权应用和组织数据由其管理员确认。
6. 未得到用户明确确认前，不删除、恢复或处置旧设备数据。

迁移异常时记录文件类型、路径层级、大小范围、错误提示和已完成范围；文件名含敏感信息时进行脱敏。

## 八、交付验收

由用户亲自完成一个真实但不敏感的闭环任务，例如登录所需应用、打开样本、编辑、保存、导出或投屏。服务人员按以下项目复述：设备与系统；账号和安全选择；更新状态；已安装应用；已验证外设；迁移完成范围；未完成与风险；官方服务入口。

```text
设备对象：____  系统版本：____  核对日期：____
账号：用户自行完成/稍后完成（不记录凭据）
更新：检查结果____  是否需重启____
关键应用：已验证____；待验证____；不适用____
外设/协同：测试组合____；结果____；条件____
迁移：范围____；抽查结果____；旧机保留状态____
未决事项：____  负责人：____  预计确认节点：____
服务入口已告知：是/否
```

## 九、常见错误与纠正

代用户记密码：立即停止并删除不当记录，由用户重设。为了演示同意全部权限：恢复最小必要权限并说明用途。未备份就迁移：先完成可验证备份。把成功演示泛化：补写设备、版本、账号和网络条件。遇到专业软件就凭名称判断：取得准确版本与真实工作流。用另一个 Windows 或鸿蒙型号的经验套用：回到当前设备信息和官方页面。

## 十、培训考核

学员在 30 分钟内完成一台模拟设备的流程说明，不要求实际登录真实账号。评分 100：开机前风险 15；隐私与账号 20；系统基础 15；应用兼容 15；协同外设 10；迁移 10；验收与记录 15。总分至少 85，且隐私账号不少于 17 分。

未授权代操作、记录凭据、跳过备份进行高风险迁移、承诺未经验证兼容性或绕过组织策略，均为阻断项，须使用新案例整轮重考。
