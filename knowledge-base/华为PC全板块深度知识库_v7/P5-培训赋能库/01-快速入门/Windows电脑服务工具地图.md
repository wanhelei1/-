# Windows 电脑服务工具地图

## 一、用途与边界

本地图帮助服务顾问在 Windows 华为电脑上选择正确入口、记录证据并决定何时停止自助操作。它不是“一键修复清单”，也不表示所有机型、系统版本都显示相同菜单。界面名称、可用功能和服务权益应以目标电脑当前版本、产品手册及华为消费者业务官网支持页面为准。

开始任何操作前先做四项确认：完整型号；Windows 版本及更新状态；问题首次出现时间和触发动作；用户是否有未备份的重要数据。涉及恢复、重置、分区、固件、拆机、账号解锁或可能改变数据的操作，不得仅依据本地图继续，应先备份并转到相应官方指导或人工服务。

## 三、六步安全排查流程

### 1. 用一句话定义问题

不要记录“电脑有问题”，而要记录：“在某网络下启动某版本应用后，点击登录出现某提示；其他网页可打开；首次发生于某次变更之后。”一句话应包括对象、动作、现象、范围和时间。

### 2. 先判断是否应停止

出现进液、明显烧焦气味、异常高温伴随关机、外壳或电池疑似变形、反复无法启动、重要数据可能丢失、账号安全事件、组织敏感数据泄露风险时，停止普通自助排查，断开不必要操作并联系官方或组织负责人。不要拆机、反复强制开关机或尝试来路不明的修复程序。

### 3. 建立可复现条件

确认问题发生在哪个账户、网络、应用、外设和文件上；记录是否每次发生；用不含敏感数据的样本复现。一次只改变一个变量，例如换一条已知正常线缆，而不是同时更新驱动、换扩展坞并重装应用。

### 4. 从低风险、可逆步骤开始

先保存文件、重新打开应用、核对设置和权限、断开再连接外设，再进入系统或官方工具查看状态。每做一步记录“动作—结果—是否恢复”。重启可以是步骤，但重启前须保存工作；不能把重启后暂时正常直接写成根因已找到。

### 5. 用交叉测试缩小范围

在获授权且数据安全的前提下，使用已知正常的网络、外设、线缆或测试账户。例：同一耳机在其他设备正常，而此电脑的其他耳机也无法输入，可进一步查电脑端权限和音频入口；这仍是定位线索，不是最终硬件结论。

### 6. 形成交接包

交接内容包括：完整型号、系统版本、问题描述、首次发生时间、近期变更、复现频率、已做步骤及结果、错误码或截图、数据风险、联系方式及允许联系时段。截图先遮挡姓名、邮箱、设备标识、文件名和组织信息。

## 四、三个操作示例

### 示例 A：会议应用听不到麦克风

先确认是所有应用还是单一应用；检查物理静音状态；在 Windows 隐私设置确认麦克风权限；在系统声音输入中选择并测试设备；再到会议应用内部核对输入设备。若系统测试正常而单一应用异常，记录应用版本与权限；若所有入口均无输入，再运行当前可用的官方检测并转服务。不得在未测试前断言“麦克风坏了”。

### 示例 B：扩展坞连接显示器无画面

记录电脑完整型号、扩展坞、线缆、显示器型号及连接链路；确认显示器输入源；检查 Windows 显示设置和投影模式；用已知正常的短链路分别替换线缆、扩展坞或显示器。任何结论都写清测试组合。接口外形一致不能证明视频输出能力，最终支持范围查目标型号官方规格及配件说明。

### 示例 C：更新后某应用异常

记录 Windows 更新信息、应用版本、异常提示和首次时间；确认其他应用与网络是否正常；保存数据后复现；查看应用官方支持信息以及组织兼容要求。不要为了回退而直接卸载安全更新，也不要承诺回退一定解决。企业电脑先交由 IT 判断更新策略。

## 六、学员练习与判分

练习一：用户说“蓝牙鼠标老断”。写出八个澄清问题、三步低风险排查和转交条件。练习二：用户说“电脑越来越慢”。区分存储、后台任务、单应用、更新和恶意软件等线索，但不得在证据不足时判定原因。练习三：为外接显示异常填写完整服务记录。

每题 20 分：问题定义 4、工具选择 4、步骤安全 4、证据记录 4、边界和升级 4。三题总分至少 48，且“步骤安全”不得低于 10。低于门槛者用新案例重做；若擅自建议删除数据、安装未知工具、绕过组织策略或拆机，直接判定不通过。

官方入口：https://consumer.huawei.com/cn/support/laptops/ 。网页内容会更新，实际服务时记录访问日期并以当时页面为准。
