# HarmonyOS 电脑能力学习卡

## 一、学习目标与边界

学完本卡，应能从当前官方 HarmonyOS 电脑页面定位能力说明；区分系统级描述、特定型号支持、版本或账号条件和第三方应用能力；针对用户任务设计验证；在对外说明时不把一次演示泛化到所有设备。

本卡不罗列可能随系统升级变化的完整功能清单，也不保证任何具体应用或外设可用。演示前必须核对电脑完整型号、系统版本、配套设备、账号、网络和目标应用。事实以当前官方页面、设备内帮助、应用开发者说明和知识库具体条目为准。

## 二、用“五层模型”理解能力

### 第 1 层：系统基础

关注桌面与窗口、文件管理、输入输出、网络、账号、安全、更新和辅助功能等基础任务。学习时不要只记功能名称，要能回答入口在哪里、用户需要什么权限、操作结果保存到哪里、失败时怎样退出。

### 第 2 层：设备硬件与系统结合

摄像头、麦克风、扬声器、触控、键盘、触控板、接口等体验取决于具体硬件和当前系统。系统页面出现某类能力，不代表每个型号配置一致；必须回到 P1 的具体型号资料。

### 第 3 层：应用与内容

应用是否可取得、可安装、可登录、可打开既有文件、可完成核心流程、可获得厂商支持，是六个不同问题。不能把“应用商店可找到”写成“所有工作流兼容”。专业应用要用准确版本、插件、文件和外设验证。

### 第 4 层：跨设备与服务

跨设备能力通常涉及多台设备、各自系统版本、账号、网络或蓝牙、权限和距离等条件。用户问“能不能协同”时，必须先问源设备、目标设备和具体动作：传文件、显示画面、继续编辑、共享输入还是使用音频设备。

### 第 5 层：组织环境

企业或学校还可能有身份认证、网络准入、代理证书、终端管理、安全软件、打印和业务系统要求。个人环境的成功演示不能代替组织验证；敏感步骤由授权管理员执行。

## 四、四类任务怎么学

### 1. 文件与内容流转

先问用户要移动的是单个文件、文件夹、剪贴内容还是应用内项目；数据是否敏感；是否需要保留原目录、权限和版本。学习者要能找到文件入口、确认保存位置、用脱敏文件测试发送与接收、检查完成后的文件能否打开。

边界：传输成功不等于云端已备份；不同应用对文件格式支持不同；组织资料不能为演示上传到未经批准的服务。对外表述需写明测试设备与版本。

### 2. 多设备协作

将“协同”拆成具体动作，逐项核对配套设备和条件。演示时只打开必要权限；使用测试内容；结束后说明连接如何断开、权限如何管理和文件落在哪里。

边界：不要说“所有华为设备自动连接”或“无需任何设置”。官方页面如使用“部分、支持、需升级”等限定，应完整保留。遇到连接失败，先记录设备、版本、账号、网络和提示，不通过反复授权或关闭安全设置强行完成。

### 3. 智能能力与内容生成

先明确输入数据、输出用途和人工复核要求。对摘要、改写、搜索或生成结果，检查事实、来源、隐私和版权；重要业务结论不得只依赖生成内容。不得上传用户未授权的合同、客户名单、账号信息或组织机密。

边界：系统或应用提供智能入口，不表示输出永远准确；功能可用范围可能受版本、地区、账号和网络影响。对外传播时将功能事实与主观体验分开。

### 4. 安全、隐私与账号

学习者应知道权限、锁屏、账号、找回或恢复、应用授权和系统更新的入口，但关键凭据由用户本人管理。进行摄像头、麦克风、剪贴板或跨设备演示前先告知并取得同意。

边界：不代记密码和验证码，不截图恢复信息，不绕过组织安全策略。出现账号异常、敏感数据风险或无法确认的授权页面时，停止并转官方支持或组织管理员。

## 五、兼容性核验流程

1. **定义不可中断任务**：软件名称、准确版本、核心流程、插件、文件格式、外设、账号和网络。
2. **查公开支持**：查看应用开发者官方说明、HarmonyOS 电脑当前官方信息及本地 `P7-常见问题库/01-售前FAQ/软件与兼容FAQ.md`。
3. **划分状态**：官方已明确、目标环境已验证、待验证、不满足、不适用。不得只写“兼容/不兼容”。
4. **准备样本**：使用经过授权或脱敏的代表性文件，不用真实客户敏感数据。
5. **验证闭环**：取得应用、安装或打开、登录、导入、编辑、保存、导出、连接外设。只测与工作有关的步骤。
6. **记录结果**：写设备、版本、日期、步骤、成功标准、异常和替代方案。
7. **保留退出路径**：关键工作流未通过时，不推动用户放弃原设备或数据；安排进一步测试或选择其他路线。

示例：用户依赖某 Windows 专业软件。错误回答是“系统支持很多应用，应该能用”。正确推进是取得软件全名、版本、插件与文件格式，查看开发者支持范围；若没有明确支持，则在目标电脑做 PoC，或保留 Windows 工作路径。一次启动成功只能证明该次启动，不能证明全部功能和厂商支持。

## 六、五分钟演示法

### 演示前

用一句话确认用户目标；核对所有设备版本、账号和网络；关闭无关通知；准备脱敏文件；设置成功标准和失败停止点。

### 演示中

先展示输入，再执行三到五个关键动作，最后展示可观察结果。旁白说明必要条件，不用“无缝、秒开、永不出错”等绝对化表达。若失败，保留现场，不连续改变多个变量。

### 演示后

让用户复做关键一步；说明结果保存位置、权限管理和退出方式；记录测试组合与结论。合格表述：“在当前电脑、配套设备、系统版本和账号网络条件下完成了该任务。”

## 七、常见问法与回答骨架

**“我有华为手机和平板，能做什么？”** 先问准确型号、系统版本、账号状态和用户想完成的动作。根据当前官方资料列出与任务相关的候选能力，再逐项核验条件。不从设备品牌直接推出全部功能。

**“原来的 Windows 软件还能用吗？”** 先取得软件与工作流，查应用开发者和当前平台支持，必要时样机验证。可以回答“已明确、已验证、待验证或不满足”，不使用模糊的“应该可以”。

**“资料会不会自动到其他设备？”** 先区分本地保存、同步、传输和备份；查看用户开启的服务、账号与权限。未经用户选择，不假设数据自动流转。

**“系统升级后功能会一直一样吗？”** 功能和界面可能随版本变化。记录当前版本与访问日期，升级前查官方说明，重要工作流留有备份和验证计划。

## 八、练习、答案与判分

### 练习 1

用户已有手机和平板，要求“协同办公”。列出至少八个澄清字段。

**答案要点**：电脑、手机、平板完整型号；三者系统版本；账号；网络与蓝牙；希望完成的具体动作；文件敏感性；目标应用；组织策略。只问“是不是同品牌”不得分。

### 练习 2

用户依赖指定 Windows 专业软件，如何判断是否适合转换系统路线？

**答案要点**：列不可中断任务；查软件开发者支持；核对版本、插件、格式、外设与许可；目标设备 PoC；记录状态；关键流程未通过时保留原路径或备选。

### 练习 3

演示文件互传成功后，能否宣传“所有文件都能随时无缝互传”？

**答案**：不能。一次演示只支持当前设备、版本、账号、网络、权限、文件类型与大小条件；还要考虑格式、组织安全和功能更新。应使用限定表述。

### 练习 4

用户关注隐私，演示中应做什么？

**答案要点**：告知权限用途；由用户本人操作账号凭据；使用脱敏文件；只开必要权限；说明数据落点与关闭方式；不保存密码、验证码和恢复信息。

评分 100：对象与条件 20；官方证据 20；任务拆解 15；演示可复现 15；兼容边界 15；隐私安全 15。总分至少 85，且兼容边界、隐私安全均不低于 12。无条件兼容承诺、收集用户凭据、把一次演示泛化或把营销描述当具体机型事实，均为阻断项。
