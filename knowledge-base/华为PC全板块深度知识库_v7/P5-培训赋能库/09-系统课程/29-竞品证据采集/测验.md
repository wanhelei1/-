# 竞品证据采集｜测验

## 题目

1. 竞品对比为什么必须落到具体SKU？
2. 证据最低记录哪些元数据？
3. “最高”“可选”为什么要保留？
4. 价格怎样比较才公平？
5. 来源冲突怎么办？

## 参考答案与解析

### 第1题

**答案：** 同系列内部的处理器、屏幕、内存、重量和价格可能不同，系列印象无法支持精确比较。

**解析：** 这道题考查能否把“竞品对比为什么必须落到具体SKU？”放回具体任务、版本与证据条件中。只写一个肯定或否定结论得不到满分；还需说明结论适用对象、不能推断的部分，以及应到哪里继续核验。

### 第2题

**答案：** 品牌、完整产品名、配置、地区、页面标题、URL、抓取日期、原文限定词和页面快照。

**解析：** 这道题考查能否把“证据最低记录哪些元数据？”放回具体任务、版本与证据条件中。只写一个肯定或否定结论得不到满分；还需说明结论适用对象、不能推断的部分，以及应到哪里继续核验。

### 第3题

**答案：** 这些词说明参数不是所有配置的固定事实，删掉会造成错误泛化。

**解析：** 这道题考查能否把““最高”“可选”为什么要保留？”放回具体任务、版本与证据条件中。只写一个肯定或否定结论得不到满分；还需说明结论适用对象、不能推断的部分，以及应到哪里继续核验。

### 第4题

**答案：** 仅比较同一时间窗口、地区、税费与配置清楚的公开价格，并标注活动和库存条件。

**解析：** 这道题考查能否把“价格怎样比较才公平？”放回具体任务、版本与证据条件中。只写一个肯定或否定结论得不到满分；还需说明结论适用对象、不能推断的部分，以及应到哪里继续核验。

### 第5题

## 综合应用题

情境：销售希望制作一张华为与三款竞品的对比表，但现有资料来自不同年份的媒体文章。

任务：重建证据表，决定哪些字段可用、需重查或必须留空，并写一条客观结论。

### 综合题参考作答

- 先固定地区、日期和具体配置。
- 回到双方品牌官网。
- 动态价格单独标注。
- 事实与对用户任务的影响分栏。

作答还应附一条证据路径、一项待核验信息和一个可验收的下一步。若资料不足，应主动缩小结论，不得把未证实内容补成完整答案。

## 常见失分原因

- 只背“竞品证据采集”的定义，没有把它转成用户任务和决策条件。
- 引用系列宣传、第三方体验或搜索摘要，却没有核对具体型号、配置、版本和日期。
- 写出参数后直接得出“更好”“一定适合”，没有解释取舍和不适用场景。
- 发现证据不足仍继续猜测，或只说“以实际为准”而不给核验动作。

## 评分与补学路径

- 基础题每题2分：结论正确1分，能说出条件、限制或证据路径1分，共10分。
- 综合应用题5分：需求拆解、证据、边界、方案和下一步各1分。
- 总分15分；12分及以上通过。9—11分回看对应核心知识并重答错题；低于9分先重做情景演练，再用另一型号或场景完成一次迁移练习。
