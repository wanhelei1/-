# 华为 PC 全板块深度知识库 v7

更新日期：2026-10-17

本库面向华为 PC 产业场景中的自研智能体，用于产品检索、需求访谈、竞品取证、售前话术、安装排障、培训和多平台图文创作。它不是把网页摘要堆在一起，而是把产品事实、官方支持、业务场景、平台写作方法和发布审核分层管理。

## 本版规模

- 00 与 P1—P8 全部板块齐全，另有待审核、历史归档、全库导航、公开来源总表和 SHA256 清单。
- 10 个重点华为 PC 型号，含产品事实、卖点与限制、60 份型号检索深度卡、80 份角色话术。
- 55 个华为扩展产品、商用设备、显示器、打印机、耗材与配件条目。
- 141 条官方公开价格与价格状态记录，覆盖全部 55 个扩展产品，并生成 65 份逐产品价格卡；其中 74 条带官方页面金额，商用品无统一公开金额时明确标注“官方询价”。
- 59 份竞品品牌官网产品补证卡、84 份品牌×维度取证工作表、21 份已填充的任务对比案例。
- 80 份完整软文成稿，覆盖 10 个型号与 8 类平台；每份包含选题、正文、图片方案、事实脚注和发布检查。
- 113 份华为官方传播案例研究，以及 13 类平台×5 份、共 65 份公开案例研究；另有 13 份平台写作指南。
- 79 份华为官方支持深度卡、50 份高频问答和 18 份综合排障指南。
- 40 个课程主题，每个主题包含讲义、情景演练和测验，共 120 份。
- 30 类行业与岗位场景，每类包含画像、问题清单、方案模板、验收清单和完整参考案例，共 150 份。
- 112 张经哈希去重、文件名与索引对齐的图片素材。
- 426 个去重后的公开来源 URL，统一登记于 `公开来源总表.csv`。

精确总文件数、字符量、板块分布和自动检查结果，以 [全库统计与校验报告](全库统计与校验报告.md) 为准。

## 板块结构

| 板块 | 内容 | 使用边界 |
|---|---|---|
| 00 建库规范 | 分类、命名、元数据、术语、审核、版本、智能体规则、来源底稿 | 先读规则，再调用业务内容 |
| P1 产品参数 | 重点型号、扩展产品、检索卡、图片索引、官方公开价格快照 | 区分系列、SKU、系统、屏幕版本、价格口径和日期 |
| P2 卖点话术 | 按角色、型号和场景的证据话术 | 只改写已确认事实，不新增参数 |
| P3 竞品资料 | 官网事实卡、来源规则、取证工作表与已填充案例 | 同期、同配置、同任务比较，不作绝对排名 |
| P4 价格政策 | 受控字段、权限、审批、异常与演练模板 | 公开包不含真实内部价格、返点、库存或政策 |
| P5 培训赋能 | 学习路径、速查、讲义、演练、测验和判分 | 答案必须包含证据与边界 |
| P6 营销素材 | 平台指南、任务卡、完整成稿、官方与多平台案例研究 | 案例用于学结构，不复制原文、图片或版式 |
| P7 常见问题 | 官方支持卡、FAQ、综合排障与升级路径 | 先确认适用设备和系统；高风险情形停止试错 |
| P8 客户场景 | 通用场景与 30 类行业/岗位深度包 | 完整案例为虚构教学情境，不是真实客户成果 |

更细的检索路径见 [全库导航](全库导航.md)。

## 来源使用原则

1. 产品参数优先使用华为官方产品页、规格页、商用官网与官方商城页，且绑定具体型号、配置和日期。
2. 安装、系统、迁移和排障优先使用华为官方支持文章；第三方应用或外设问题还要查对应厂商文档。
3. 华为官方新闻、活动、解决方案和商城页可用于研究标题、信息顺序、证据和 CTA，不代替当前 SKU 规格。
4. 第三方或社区案例只用于发现选题、平台节奏和用户问题，其参数、价格、排名、体验和评论不进入 P1 事实库。
5. 价格、促销、库存、赠品、交期和政策属于动态信息，使用时重新核验，不把历史页面当成当前承诺。

## 建议的智能体调用顺序

1. 识别平台、受众、场景、目标型号和交付格式；关键信息缺失时先追问。
2. 从 P1 或 P7 取得产品与支持事实；涉及价格时先读 `P1-产品参数库/08-官方公开价格快照`，不从软文案例推断参数或金额。
3. 从 P8 取得业务问题、试点和验收方法，从 P2 取得角色化表达。
4. 从 P6 选择相同平台的指南、完整成稿和案例研究，重新组织原创内容。
5. 价格必须同时输出具体配置、价格类型、核验时间、条件和官方 URL；页面价、参考价、券后预估价、搭配购价与企业询价不得混写。
6. 对每张图输出文件名、来源、插入位置和图注；图片不得超出索引证明产品事实。
7. 输出前检查型号、配置、系统、日期、来源、动态信息、版权和客户授权。

## 导入 ima

先解压，再按板块分批上传，保留中文目录与图片文件名。建议依次导入治理规则、事实底座、场景与话术、培训、营销内容、竞品资料；P4 只在确认权限后上传。完整操作、同账号共享库调用、验收与安全要求见 [导入 ima 说明](导入ima说明.md)。

## 质量和安全

全库交付前检查空文件、空目录、UTF-8、JSON/CSV、本地链接、图片签名、图片索引覆盖、图片哈希、文档完全重复、板块内高相似文档、目录编号、索引路径、敏感凭证片段和禁用表达。详细结果见校验报告，文件级校验值见 `全库文件清单_SHA256.csv`。

本库不应保存 API 密钥、客户端密钥、登录信息、真实客户数据、合同、未授权内部政策或可识别的业务截图。
