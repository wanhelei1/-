# 售后与促销表述红线

- 不将限时服务活动写成永久权益。
- 不省略地区、机型、时间、保修状态和人为损坏等条件。
- 不使用“终身免费、全部覆盖、无条件退换、绝对兼容”。
- 不引用用户评价作为官方性能事实。
- 不把商城标价、国补、赠品、分期和库存写进长期知识。
- 涉及维修费用时只给官方查询入口，不自行报价。

## 六类高风险信息

### 1. 服务权益

保修期限、上门、寄修、到店、备用机、数据服务和延保都可能受地区、产品、购买时间、故障性质与活动规则影响。内容中必须写明信息日期和官方查询入口；没有对应政策原文时，只能引导查询，不能根据以往经验承诺。

### 2. 故障与维修

“可修复”“免费维修”“当天完成”“不会丢数据”都需要具体条件。涉及进液、跌落、异常发热、异响、无法开机或数据风险时，应先提示停止可能扩大损坏的操作并备份可访问数据，再转官方检测。营销人员不能远程判断硬件故障，也不能代替服务工程师报价。

### 3. 兼容性

软件、驱动、打印机、扩展坞、显示器和企业安全策略必须绑定系统、应用及外设版本。可写“建议携带目标软件或外设验证”，不可写“全部兼容”“任何设备都能接”。一次连接成功只能证明当时的组合，不代表所有批次和更新后的环境。

### 4. 促销与交易

价格、优惠券、国家或地方补贴、以旧换新、赠品、分期、库存和交期均为动态信息。正文如果确有必要使用，应同时写清渠道、地区、时间、适用 SKU、参与条件和核验入口；活动结束后从常青内容中删除，而不是只改标题日期。

### 5. 用户评价与案例

真实评价也只代表特定用户和环境，不能转写成官方性能承诺。客户名称、人物、截图、业务数据和测试数字需要授权；教学演练、虚构人物与参考案例必须明确标注，不能包装成真实成交或交付成果。

### 6. 比较与绝对化

不用“唯一、第一、全面领先、零风险、终身、绝对安全”等无法由当前证据支持的表达。竞品比较应固定日期、配置、任务和证据；官网未写的字段只记为“未在当前页面确认”，不能写成“不具备”。

## 表述改写示例

| 高风险写法 | 问题 | 建议写法 |
|---|---|---|
| 全国都可免费上门 | 忽略地区、机型、保修和故障条件 | 服务方式与费用以设备保修状态和华为官方服务页面/检测结果为准 |
| 任何打印机都兼容 | 无系统、驱动和型号边界 | 请按目标系统、打印机型号与驱动版本核对厂商说明，并用真实设备验证 |
| 现在买一定最便宜 | 无法证明且价格动态变化 | 当前成交信息请在发布当日进入指定渠道核验，本文不固化价格 |
| 用很多年也不会卡 | 虚构长期体验与结果 | 根据常用应用、文件规模和更新周期选择配置，并保留升级或换机预案 |
| 客户用了效率翻倍 | 缺测试方法、样本与授权 | 如需描述效率变化，需提供同任务、同环境的前后记录及客户授权 |
| 售后无忧 | 含义不清，容易被理解为无条件承诺 | 列出官方服务入口、适用条件、需备份事项和升级路径 |

## 发布审核流程

1. 标出全文所有价格、数字、比较、服务、兼容和结果性句子。
2. 为每句绑定来源、型号或政策、日期与适用条件；缺一项则删除或改成待核验问题。
3. 单独检查标题、封面和图片文字，因为它们最容易省略正文中的限制条件。
4. 事实复核与内容审核由不同角色完成；复核人只确认有证据，不替代业务授权。
5. 发布后保存版本；活动到期、来源变化或用户指出冲突时停止继续分发并更新。

## 最终自检

- [ ] 没有把限时活动写成长期权益。
- [ ] 服务、维修、兼容和费用均保留适用条件。
- [ ] 图片、标题和口播没有比正文作出更强承诺。
- [ ] 用户评价、案例和数字有来源、环境与授权。
- [ ] 动态信息有日期、渠道和失效处理。
- [ ] 读者知道去哪里核验、出现异常如何升级。
