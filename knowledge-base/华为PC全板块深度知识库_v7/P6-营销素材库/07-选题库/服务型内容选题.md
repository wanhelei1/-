# 服务型内容选题

- 新电脑到手后先做的六项设置
- 换电脑前怎样整理和备份资料
- 蓝牙鼠标、耳机和音箱连接检查表
- 触控板常用手势入门
- 如何科学使用和保养笔记本电池
- 单个应用无法联网时如何定位问题
- 什么情况下适合寄修、预约到店或远程服务
- 保修期、备件价格和维修进度在哪里查

每篇内容需链接官方支持页；活动价格和服务范围标注抓取日期。

## 选题卡一｜新电脑到手后的基础设置

- 用户问题：开机后先登录什么、更新什么、备份什么，怎样避免之后找不到数据或恢复入口。
- 内容结构：适用系统说明 → 账号与隐私 → 系统/驱动更新 → 网络与外设 → 备份和恢复 → 核验清单。
- 证据：P7 对应系统的官方支持文章；不同系统不可共用菜单路径。
- 图片：只使用目标系统当前界面截图，并遮盖账号、序列号和文件名。
- CTA：让读者保存一份自己的“设备—账号—备份—服务入口”记录，不引导无关成交。

## 选题卡二｜换机前的数据整理与迁移

- 用户问题：旧电脑里有哪些资料必须带走，软件授权和浏览器数据怎么处理。
- 内容结构：数据盘点 → 备份 → 迁移方式选择 → 抽样核对 → 旧机退出账号与清理。
- 必问：源/目标系统、数据量、特殊文件、软件许可、加密、云盘、企业政策。
- 风险：迁移工具成功不等于全部文件完整；必须用数量、容量和关键文件抽查。
- CTA：先完成备份与抽样恢复，再开始批量迁移。

## 选题卡三｜蓝牙与常用外设连接

- 用户问题：鼠标、耳机或音箱搜不到、连上无声、休眠后断开。
- 内容结构：确认系统与设备型号 → 电量/配对状态 → 删除旧配对 → 重新连接 → 输出设备与权限 → 失败升级。
- 证据：P7 官方支持条目加外设厂商官方说明；不得从一个设备推断全部兼容。
- 视觉：连接前、设备列表、正确输出与失败提示四个画面即可，不暴露附近设备名称。

## 选题卡四｜输入与触控板入门

- 用户问题：快捷键、触控板或手势与旧设备不同。
- 内容结构：适用机型 → 基础动作 → 可调整设置 → 常见误触 → 无法使用时的排查入口。
- 边界：手势、热键、背光和触屏会随机型、系统、驱动或电脑管家版本变化。
- 互动：邀请读者说出最常用的三个动作，再从实际任务选择设置，而不是列完所有功能。

## 选题卡五｜电池、充电与散热

- 用户问题：续航与宣传不同、充电慢、发热或风扇声变化。
- 内容结构：先解释影响变量 → 查看电量与电源设置 → 区分充电器/线缆/负载 → 记录异常 → 升级处理。
- 禁止：自行承诺固定续航；把室温、亮度、网络和应用不同的结果直接比较；指导拆机或危险操作。
- CTA：用同一任务、同一亮度和同一网络做可复现记录，异常发热或损坏迹象转官方检测。

## 选题卡六｜单个应用无法联网

- 用户问题：浏览器能上网，但某个应用无法登录或加载。
- 内容结构：判断全局/单应用 → 查看日期时间、权限、代理/VPN和企业策略 → 换批准网络复测 → 查应用厂商状态 → 保存错误信息。
- 边界：不能为了演示关闭企业安全策略；涉及账号风控和许可证时由平台或管理员处理。

## 选题卡七｜如何选择服务方式

- 用户问题：适合自助、远程支持、预约到店还是寄修。
- 判断维度：设备能否开机、数据风险、是否有人为损坏迹象、所在地区、保修状态、业务中断程度。
- 输出：每种方式的准备事项、数据备份、携带材料和官方入口，不承诺具体费用与完成时间。

## 选题卡八｜查询保修、备件与进度

- 用户问题：哪里看保修状态、备件价格或维修进度。
- 内容结构：确认设备与地区 → 打开官方查询入口 → 解释查询结果的范围 → 需要检测时转服务中心。
- 隐私：截图隐藏序列号、手机号、地址和订单信息。

## 写作与复核模板

每篇服务型内容交付时填写：标题、目标用户、适用设备/系统、用户现象、开始前确认、操作步骤、验证标准、失败分支、数据与安全提醒、官方来源、核验日期、图片清单和升级入口。步骤不足以支持结论时，不用形容词补齐；改成“需打开官方原文核对”或“请联系官方支持”。
