# 完整软文成稿库总索引

> 本目录的成稿用于自研智能体理解平台差异、事实脚注、图片调用和合规自检，不是无需复核即可发布的广告。发布前必须按目标 SKU、官方页面、图片授权和动态信息重新核验。

## 使用方法

1. 先从 P1 读取目标型号的产品事实、卖点与限制、图片索引。
2. 再打开本目录同型号、同平台的完整成稿，并配合 `P6-营销素材库/02-平台模板`。
3. 根据本次受众、场景和目标重新写作，不复制虚构人物或把参考稿描述成实测。
4. 输出图片名称、来源、插入位置和说明；价格、库存、赠品与活动必须当日另行核验。

## 选择规则

- 公众号、新闻稿与知乎需要完整论证和来源；小红书、朋友圈与门店长图要重新设计信息层级，不能机械截短长文。
- 短视频与直播要把事实转成可见动作，并保留系统、版本、账号、网络和外设条件。
- 同系列多个 SKU 的最高参数不可拼成一台产品；图片只能从目标型号索引中选取。
- 如目标型号不在本目录，使用平台模板重新创建，不能拿相近型号替换产品事实。
