# 华为商城电脑专区素材使用说明

本目录收录华为商城电脑专区公开展示的产品图、功能图、场景图和服务说明图。文件名按画面语义重新命名，原始 URL 保存在“图片索引.csv”。

商城素材可能同时服务多个型号。未能从页面结构确认具体型号的图片只用于通用场景表达，不得据图推导处理器、内存、存储、续航或兼容性参数。涉及促销、价格、赠品和补贴的画面不作为长期营销事实使用。

## 素材类型

1. **产品主视觉**：用于封面、产品识别和版式起点，只能证明画面中可见的外观。
2. **功能说明图**：用于解释屏幕、接口、协同或系统功能；必须同时核对图旁脚注、适用型号与版本。
3. **场景图**：用于表达办公、学习、创作或移动语境，不承担参数证明，也不代表真实用户证言。
4. **服务与交易图**：可能含价格、优惠、赠品、补贴、物流或服务活动，具有明显时效；默认不进入常青软文。
5. **跨型号专区图**：商城专区可能把多个系列放在同一画面，若无法确定具体型号，只能标为通用专区素材。

## 入库前核对

- 保存原始图片 URL、所在页面 URL、抓取日期、文件格式和像素尺寸。
- 记录画面中的产品名称、可见文字、人物、场景和可能的版本线索。
- 若页面标题与画面型号不一致，先进入待审核，不根据文件名或外观猜测。
- 对重复下载的素材按文件哈希去重；不同裁切、尺寸或带字版本保留用途说明。
- 文件扩展名必须与真实图片格式一致，避免上传后无法解析。

## 文件名与索引

文件名采用“来源/产品—可见画面—用途—序号”思路，形容词只描述画面，例如“轻薄机身侧面”“多窗口办公场景”，不用“顶级”“最强”“绝对护眼”。`图片索引.csv`至少登记文件名、产品、画面说明、来源 URL、页面 URL、尺寸、抓取日期、建议用途和限制。改名后必须同步索引和所有 Markdown 引用。

## 对外使用流程

1. 从目标文章的事实与镜头需求出发选图，不先选漂亮图片再补结论。
2. 打开索引与原页面，确认产品、版本和当前可用状态。
3. 为图片写“名称—来源—插入位置—图片说明—不能证明什么”。
4. 核对品牌、人物肖像、第三方软件界面与字体等权利状态；无法确认授权范围时不发布。
5. 发布前检查裁切是否删除了关键脚注，字幕是否把画面扩大成无条件功能承诺。

## 常见误用

- 用系列合照证明某个 SKU 的接口、颜色或配件。
- 看到电池图标就推断续航时长，看到多窗口就推断所有应用兼容。
- 把渲染图称为实拍，把情景人物称为真实客户。
- 沿用已经结束的价格、补贴或赠品画面。
- 从商城图片下载地址反推产品参数，未回到对应规格页。

## 上传 ima 后的检查

随机检索五张图，确认能够返回中文文件名、目标产品、画面内容、来源与限制；再让智能体为一篇软文配图，检查它是否只从目标型号索引中选择。若平台无法直接显示某格式，保留原文件并生成经授权的兼容副本，同时在索引中记录两者关系。
