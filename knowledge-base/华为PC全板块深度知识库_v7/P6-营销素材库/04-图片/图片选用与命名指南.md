# 图片选用与命名指南

## 命名格式

`hwpc_型号英文短名_画面形容词与用途_序号.扩展名`

例如：`hwpc_matebook-d-16-2024_大屏护眼显示_03.jpg`。形容词应描述可见画面或官方表达，不加入“顶级、碾压、最强”等无法证明的判断。

## 选图顺序

1. 主视觉：封面或产品总览。
2. 配色与机身：外观、材质和便携场景。
3. 屏幕与键盘：办公、创作或学习任务。
4. 性能与散热：仅配合官方明确说明。
5. 协同与系统：核对系统版本和功能开放条件。

## 引用规则

知识库图片保留官网原始 URL、产品页面 URL、尺寸和用途。对外发布前核验品牌使用规范与授权范围。

## 命名字段详解

- `hwpc`：本库华为 PC 公开素材前缀，便于与竞品或教学示意图区分。
- `型号英文短名`：来自产品页面，不自行创造容易与其他型号混淆的缩写。
- `画面形容词与用途`：描述肉眼可见的主体、角度、动作或版式用途。
- `序号`：同一型号同类画面的稳定编号；更新图片时不覆盖旧文件，而是新增版本并记录日期。
- `扩展名`：必须与文件真实签名一致，不能只改后缀。

允许的画面词包括“正面主视觉、侧面接口、键盘细节、屏幕内容示意、移动办公场景、连接步骤、版本提示”。避免“高端、旗舰感、性能爆炸、极致、全能”等主观判断；若“护眼、专业色彩”等是官方表述，也应在正文中附条件和来源，文件名本身不作为证明。

## 选图决策树

1. 文章要证明的是产品外观、具体参数、操作步骤还是氛围？
2. 若是参数，图片中是否直接包含该事实与脚注，且与目标 SKU 相符？否则改用规格来源。
3. 若是步骤，画面是否来自目标系统版本，账号与隐私是否脱敏？
4. 若是氛围，图注是否明确“场景示意”，避免被当成真实客户或性能测试？
5. 图片是否已登记来源、权利状态和适用范围？未登记则不进入成稿。

## 图文位置规则

- 封面图回答“这篇讲谁的什么问题”，不堆叠无法核验的数字。
- 场景图放在用户任务之后，让画面推动叙事，而不是装饰段落。
- 参数图紧邻对应事实和限定条件；脚注不可被裁掉或缩到不可读。
- 步骤图按操作顺序编号，界面变化时整组复核。
- 结尾图用于核验清单或 CTA，不重复首图制造无效篇幅。

## 图片索引必填字段

文件名、产品完整名称、画面主题、图片类型、原始图片 URL、所在页面 URL、抓取日期、像素尺寸、文件哈希、建议用途、适用型号/版本、限制、权利状态和复核人。一个字段无法确认时写“待核验”，不要留空后让智能体猜测。

## 质量检查

- [ ] 文件可打开，格式签名与后缀一致，未出现截断或透明背景异常。
- [ ] 目标型号、颜色、键盘布局、接口位置与正文一致。
- [ ] 图片中的数字、脚注和界面没有被错误裁切。
- [ ] 没有促销价格、个人信息、客户数据或未经授权的人物材料。
- [ ] 图注只描述可见内容，功能结论能回到 P1/P7 或官方页面。
- [ ] 同一素材的重复版本已经哈希核对，保留关系写入索引。

## 冲突处理

若文件名、索引、页面标题和画面内容冲突，立即停止使用并转入待审核。以当前官方页面和可见画面为核验起点，不能仅凭旧文件名判断。确认错误后新增更正记录，避免静默覆盖导致历史文章无法追溯。
