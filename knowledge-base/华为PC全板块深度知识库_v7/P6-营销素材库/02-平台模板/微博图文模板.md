# 微博创作指南

## 一、用途与边界

在节点、事件或新品窗口内传递一个清晰信息，并用话题或互动收集反馈。微博不是把长文压成一整块小字。

本模板只规定创作过程，不预先给出产品结论。产品事实从P1产品资料、P7官方支持、华为当前官网/商城和举办方提供的ima共享知识库读取；第三方测评、评论和案例只能作为问题线索或外部观察，不能改写成产品事实。所有动态信息注明核验日期。

## 二、创作前必须取得的输入

传播节点、唯一目标、完整型号、三条以内卖点、图片顺序、话题词、互动规则、价格/权益核验时间。

若用户没有给出型号、平台、受众或任务，智能体先列缺失项；在不影响方向时可以用“待确认字段”继续搭骨架，但不能擅自选配置、编价格或虚构体验。素材表至少包含：文件名、来源URL、适用型号、画面内容、允许用途、插入位置、图注。

## 三、写作流程

第一句写节点和用户问题；中间三行对应三张图或三项动作；下一行写限制/版本；最后只留一个互动或购买动作。系列产品先分型号再写共性。

每个段落都要能回答下列至少一项：用户遇到什么问题、进行了什么动作、用什么证据验证、在哪些条件下成立、下一步做什么。不能回答这些问题的形容词、口号和重复参数应删除。

## 四、成稿格式与图文节奏

正文80—300字，1—6张图。主图可脱离正文看懂，后续图按外观、任务、证据、权益排序。抽奖或优惠另附完整规则链接。

统一输出顺序：标题备选3个 → 受众与场景 → 正文/脚本 → 图片或镜头清单 → 事实来源 → 风险与待确认项 → CTA → 发布前检查。引用ima图片时不得只写“配一张电脑图”，必须指定图片名、来源、位置和用途。

## 五、正例

毕业季帖子用“答辩—入职”两段路说明便携、屏幕和会议，再邀请读者评论专业与必用软件。

正例的关键不是语气好听，而是对象、任务、证据和限制互相对应。即使移除品牌名，读者仍能看懂这段内容解决了什么问题。

## 六、反例

一条微博同时宣传六款产品、八项功能、三种优惠和两个抽奖，图片与正文无法一一对应。

反例常见原因包括：把不同型号拼成一台产品、把实验室条件删除、把第三方观点改成官方事实、用过期价格制造紧迫感、用未授权图片或把想象写成亲身体验。

## 七、平台专项规则

热搜词、节日与梗只作入口，不虚构关联；转评抽必须公开主体、时间、条件和开奖方式。

## 八、发布前检查

- [ ] 受众、平台、场景和唯一传播目标已写清。
- [ ] 产品完整名称、年份、系统、SKU与图片一致。
- [ ] 每个性能、重量、续航、亮度、适配数量或价格数字均有来源与条件。
- [ ] 区分官方事实、实验室结果、第三方测试、用户观点和原创判断。
- [ ] 第三方体验没有被写成华为PC的普遍事实。
- [ ] 图片来自ima共享知识库、本库图片索引或已授权来源，文件名与URL已登记。
- [ ] 图文、镜头或页面顺序能复现一次完整任务，不是随机素材拼贴。
- [ ] 没有绝对化承诺、贬低竞品、虚假稀缺、未经证明的对比或虚构体验。
- [ ] 价格、权益、库存、适配、售后、活动规则和二维码已由人工复核。
- [ ] 正文没有复制公开案例原文、独特表达、长段字幕或未授权画面。
- [ ] CTA与读者阶段匹配，入口可访问且责任主体清楚。
- [ ] 保留事实来源清单、核验人、核验日和待确认项，便于赛后复盘。

## 九、交付字段

最终交付应包含：`platform`、`audience`、`scene`、`target`、`model_and_sku`、`system_version`、`title_options`、`body_or_script`、`image_or_shot_list`、`evidence`、`limitations`、`cta`、`verified_at`。无法确认的字段写“待人工确认”，不能删除。
