# MateBook D 14｜微信公众号深度图文任务卡

## 传播任务

- 核心读者：预算务实、需要 Windows 常用软件和完整接口、经常通勤或上课的用户。
- 主问题：日常办公学习的 14 英寸电脑，怎样在便携、接口和屏幕版本之间做取舍？
- 文章主线：以“背包—教室/工位—会议室”三站式动线讲便携与接口，并提醒标准版和 SE 版屏幕差异。
- 语气：编辑部式、克制、可核验；先解释场景，再给事实，不使用直播腔或“种草体”。

## 内容结构

1. **标题组**：给 3 个标题，18—26 个汉字；分别采用“场景问题 / 明确选择 / 功能解释”角度，禁止三句同义改写。
2. **摘要**：48—64 字，点明产品全名、适用任务与一项必须确认的版本条件。
3. **开篇（80—120 字）**：用真实任务提出矛盾，不虚构“我用了一个月”等体验。
4. **正文一：为什么看它**：围绕“通勤尺寸里的实用接口组合”解释定位，仅选 2 项直接相关事实。
5. **正文二：任务如何完成**：用办公、学习或创作流程串起 2—3 项能力；功能必须写触发条件。
6. **正文三：怎么选版本**：列出“适合 / 需要确认 / 不应期待”，主动呈现取舍。
7. **结尾**：引导读者携带常用文件、设备或软件到店验证，不用催单式口号。

## 图文节奏

建议 6 幅图，首图后每 180—260 字出现一幅；图片顺序：

1. 约 1.39 kg 通勤携带
2. 14 英寸 16:10 文档界面
3. USB-C、双 USB-A、HDMI
4. 标准版与 SE 版 SKU 提示
5. 一张“适合谁 / 需确认什么”的信息图
6. 官方规格页或到店核验引导图

每图配 18—36 字图注，图注说明事实或条件，不重复正文标题。

## 交付格式

- 3 个标题 + 1 条摘要。
- 正文 900—1300 字，使用 3 个信息型小标题。
- 6 条图片建议，写明“画面 / 对应事实 / 图注 / 图片索引关键词”。
- 末尾附“版本核验清单”3 项和一个非促销型 CTA。

## 本型号可用事实锚点

- 约 1.39 kg、15.9 mm；14 英寸 16:10 IPS，1920 × 1200。
- 标准 13 代酷睿版标注 100% sRGB；SE 版标注 45% NTSC，不能混写。
- 处理器配置包括第 13 代酷睿 i5-13420H 与 i7-1360P；销售版本需核验。
- 16 GB 内存，512 GB / 1 TB SSD，56 Wh 额定容量电池。
- 接口含 USB-C、USB-A 3.2 Gen 1、USB-A 2.0、HDMI 与 3.5 mm 音频口。
- Windows 与 Linux V20 版在蓝牙、指纹、快捷键和特色应用上存在差异。

## 合规与校验

- 不得把标准版 100% sRGB 套到 D 14 SE 版。
- 不可根据接口数量推断所有接口速度相同。
- 不得用 D 16 的数字键盘、大屏或电池配置替代本型号事实。
- 公众号长文不得把多个 SKU 的最高参数拼成一台“顶配标准机”；引用数字后紧跟版本或条件。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
