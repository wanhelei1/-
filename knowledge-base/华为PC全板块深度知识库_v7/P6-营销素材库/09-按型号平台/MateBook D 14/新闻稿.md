# MateBook D 14｜新闻稿 + 微博快讯任务卡

## 新闻稿定位

写一篇可供品牌活动、门店开业或行业媒体资料包使用的事实型稿件。核心信息是“通勤尺寸里的实用接口组合”，受众为科技/消费媒体与渠道伙伴。语气客观、第三人称、信息密度高；不得写成使用心得或促销软文。

## 新闻稿结构

1. **标题**：产品全名 + 一项可核实定位，不超过 32 字；不要使用“重新定义、划时代、王者”。
2. **导语（100—140 字）**：回答产品是谁、面向谁、解决什么任务；日期和活动信息只在收到正式输入后填写。
3. **第一部分｜产品身份**：依据以下主线解释产品在同品牌矩阵中的位置：以“背包—教室/工位—会议室”三站式动线讲便携与接口，并提醒标准版和 SE 版屏幕差异。不引用市场份额。
4. **第二部分｜三组事实**：每组“小标题 + 官方事实 + 使用条件”，数字来源必须可追溯。
5. **第三部分｜场景与边界**：写 2 个适用场景和 2 个购买前确认项，避免单向赞美。
6. **结尾**：提供官方页面与咨询入口；价格、上市时间、渠道、赠品均留 `[待官方确认]` 占位，禁止自行补齐。

## 微博快讯版

- 140—220 字，不复制新闻稿导语。
- 结构：一句发布事实 → 两项核心信息 → 一项版本提醒 → 官方链接。
- 最多 2 个话题标签，推荐从 `#通勤笔记本 #学习办公 #MateBookD14 #实用接口` 中选；不用刷屏式九宫格文案。
- 配图 1—4 张，第一张确认型号，最后一张放“具体配置以销售 SKU 为准”。

## 交付格式

- 新闻稿标题 2 个、导语 1 段、正文 800—1200 字、4 条图注、事实来源表。
- 微博快讯 2 版：一版信息型、一版场景型；各附图片顺序和替代文本。

## 本型号可用事实锚点

- 约 1.39 kg、15.9 mm；14 英寸 16:10 IPS，1920 × 1200。
- 标准 13 代酷睿版标注 100% sRGB；SE 版标注 45% NTSC，不能混写。
- 处理器配置包括第 13 代酷睿 i5-13420H 与 i7-1360P；销售版本需核验。
- 16 GB 内存，512 GB / 1 TB SSD，56 Wh 额定容量电池。
- 接口含 USB-C、USB-A 3.2 Gen 1、USB-A 2.0、HDMI 与 3.5 mm 音频口。
- Windows 与 Linux V20 版在蓝牙、指纹、快捷键和特色应用上存在差异。

## 合规与校验

- 不得把标准版 100% sRGB 套到 D 14 SE 版。
- 不可根据接口数量推断所有接口速度相同。
- 不得用 D 16 的数字键盘、大屏或电池配置替代本型号事实。
- 新闻稿与微博不得擅自写发布会时间、在售状态、指导价、销量、奖项或“首次/唯一”；这些属于需另行核验的动态或比较性事实。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
