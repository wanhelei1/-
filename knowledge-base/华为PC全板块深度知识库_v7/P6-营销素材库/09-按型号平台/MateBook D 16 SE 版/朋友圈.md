# MateBook D 16 SE 版｜销售朋友圈任务卡

## 发布原则

朋友圈的任务不是复述产品页，而是给熟人一个值得私聊的具体理由。面向：以表格、网课、文档和基础多任务为主，优先考虑 16 英寸大屏与实用配置的用户。语气像顾问，不像群发广告；每条只讲一个场景，不连续三天复制同一套参数。

## 三条可轮换内容方向

### 1. 场景提醒型

- 开头：从“预算更务实时，大屏办公本哪些配置够用，哪些差异必须提前知道？”中提炼一句日常提醒。
- 中段：只放 1 项官方事实 + 它对应的任务。
- 结尾：邀请对方带常用文件或外设到店验证。
- 配图：文档/网课/表格场景 → 16 英寸 16:10 大屏，2 张即可。

### 2. 版本选择型

- 开头：“同名产品也可能有不同版本，今天重点帮大家分清……”
- 中段：写两组容易混淆的 SKU / 系统 / 屏幕条件，不报未经核验的价格。
- 结尾：用一个具体问题收口，如“你更需要……还是……？”
- 配图：规格差异卡 → 独立数字键盘 → 官方页二维码，共 3 张。

### 3. 到店演示型

- 开头：告诉读者今天可以现场验证什么。
- 中段：用 3 个动词概括：`展示表格分屏与数字录入，连接 HDMI 和 U 盘，再在 SKU 页面核对处理器代际、存储和操作系统`。
- 结尾：说明预约时需要带什么设备或软件名称。
- 配图：实机动作连拍 3—4 张，最后一张放 SKU 核验提示。

## 交付格式

- 每个方向各写 2 条，共 6 条；每条 90—150 字。
- 每条最多 3 个参数，且参数后紧跟版本条件。
- 每条给 2—4 张配图顺序和一句私聊承接话术。
- 表情符号不超过 3 个；不用九宫格刷屏式大字海报。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS，1920 × 1200、300 尼特、45% NTSC（均为官网标注或典型值）。
- 可选第 13 代酷睿 i5-13420H 或第 12 代酷睿 i5-12450H，须核对销售版本。
- 16 GB 内存，512 GB / 1 TB SSD；集成 Intel UHD Graphics。
- 约 1.70 kg、18 mm，56 Wh 额定容量电池。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- NFC、指纹、超级终端等相关能力须区分 Windows 与 Linux V20 版。

## 合规与校验

- 不得使用 D 16 非 SE 版的 100% sRGB、70 Wh 或 i9 配置。
- 屏幕不包装成专业色彩屏；可讲大屏视野，不虚构色彩表现。
- 价格、补贴和库存只能使用发布当日已核验信息，且单独标注时效。
- 朋友圈不得冒充顾客评价、晒虚假成交、暗示统一最低价或使用未经批准的倒计时；活动信息必须标日期、门店与适用 SKU。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
