# MateBook D 16｜新闻稿 + 微博快讯任务卡

## 新闻稿定位

写一篇可供品牌活动、门店开业或行业媒体资料包使用的事实型稿件。核心信息是“大屏、数字键盘与桌面效率”，受众为科技/消费媒体与渠道伙伴。语气客观、第三人称、信息密度高；不得写成使用心得或促销软文。

## 新闻稿结构

1. **标题**：产品全名 + 一项可核实定位，不超过 32 字；不要使用“重新定义、划时代、王者”。
2. **导语（100—140 字）**：回答产品是谁、面向谁、解决什么任务；日期和活动信息只在收到正式输入后填写。
3. **第一部分｜产品身份**：依据以下主线解释产品在同品牌矩阵中的位置：从表格录入和多窗口任务切入，依次讲 16:10 大屏、数字键盘、标压处理器与接口，不用“全能”空话。不引用市场份额。
4. **第二部分｜三组事实**：每组“小标题 + 官方事实 + 使用条件”，数字来源必须可追溯。
5. **第三部分｜场景与边界**：写 2 个适用场景和 2 个购买前确认项，避免单向赞美。
6. **结尾**：提供官方页面与咨询入口；价格、上市时间、渠道、赠品均留 `[待官方确认]` 占位，禁止自行补齐。

## 微博快讯版

- 140—220 字，不复制新闻稿导语。
- 结构：一句发布事实 → 两项核心信息 → 一项版本提醒 → 官方链接。
- 最多 2 个话题标签，推荐从 `#大屏笔记本 #表格办公 #MateBookD16 #职场效率` 中选；不用刷屏式九宫格文案。
- 配图 1—4 张，第一张确认型号，最后一张放“具体配置以销售 SKU 为准”。

## 交付格式

- 新闻稿标题 2 个、导语 1 段、正文 800—1200 字、4 条图注、事实来源表。
- 微博快讯 2 版：一版信息型、一版场景型；各附图片顺序和替代文本。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS 屏，1920 × 1200、90% 屏占比；存在 100% sRGB 与 45% NTSC 等配置，须按 SKU 核验。
- 可选第 13 代酷睿 i9-13900H（仅 Windows 版）或 i5-13420H。
- 16 GB 内存、1 TB SSD；不得据此推断所有渠道只销售单一配置。
- 56 Wh 版本约 1.68 kg，70 Wh 版本约 1.72 kg，重量与电池配置对应。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- 特色应用及指纹、快捷键等能力须区分 Windows 与 Linux V20 版本。

## 合规与校验

- 屏幕色域、电池和重量必须按具体 SKU 成组表述。
- 不得把集成显卡宣传为专业独显或游戏显卡。
- 不使用“全天续航”等无本地官方时长证据的表述。
- 新闻稿与微博不得擅自写发布会时间、在售状态、指导价、销量、奖项或“首次/唯一”；这些属于需另行核验的动态或比较性事实。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
