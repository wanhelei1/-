# MateBook D 16｜门店海报 / 长图任务卡

## 使用场景

用于店外引流、展台立牌和导购扫码长图。顾客 3 秒先看懂“这是什么”，10 秒抓住一个任务价值，30 秒找到版本核验与咨询入口。文案必须比公众号更少，比朋友圈更标准化。

## 信息层级与画面节奏

| 屏段 | 建议高度 | 文案任务 | 画面与动作 |
|---|---:|---|---|
| 1. 首屏 | 18% | 8—12 字主张：`大屏、数字键盘与桌面效率`；下方写完整产品名 | 16 英寸 16:10 工作界面，产品轮廓清楚，不叠四组参数 |
| 2. 场景 | 14% | 用 2 句说清“谁在什么任务中需要它” | 会议桌或家庭学习场景，避免纯摆拍 |
| 3. 核心事实 | 28% | 三张事实卡，每张“1 个数字/名词 + 1 句意义 + 1 行条件” | 独立数字键盘录入 与局部细节交替 |
| 4. 到店演示 | 18% | 三步：`打开长表格做数字录入，展示 16:10 页面与独立数字键盘，再接投影或 U 盘完成会议场景` | 连续动作图或编号示意，不伪造界面 |
| 5. 适合与确认 | 14% | 左列“更适合”，右列“购买前确认” | 对勾/问号，不用竞品红叉 |
| 6. 尾屏 | 8% | 官方规格页、门店咨询和 SKU 核验提示 | 二维码占位 + USB-C、USB-A、HDMI 接口 |

## 文字与设计规范

- 竖版长图建议 1080 px 宽；同时给 A3 立牌裁切安全区。
- 首屏除产品名外不超过 28 个汉字；事实卡每张不超过 45 个汉字。
- 参数脚注必须可读，不能用极浅灰隐藏条件；印刷版脚注字号不低于门店模板规定。
- 色彩与字体沿用品牌资产，不自行改 Logo、产品颜色或屏幕界面。
- 图片从 P1 图片索引选取，记录文件名；裁切不能遮挡折叠结构、接口或版本差异。

## 交付格式

- 一份逐屏文案表：层级、主文案、脚注、图片文件名、导购讲解句。
- 一份 1080 px 长图线框说明 + A3 立牌缩编版。
- 二维码只放可维护的官方页或门店批准入口，并写明链接目标。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS 屏，1920 × 1200、90% 屏占比；存在 100% sRGB 与 45% NTSC 等配置，须按 SKU 核验。
- 可选第 13 代酷睿 i9-13900H（仅 Windows 版）或 i5-13420H。
- 16 GB 内存、1 TB SSD；不得据此推断所有渠道只销售单一配置。
- 56 Wh 版本约 1.68 kg，70 Wh 版本约 1.72 kg，重量与电池配置对应。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- 特色应用及指纹、快捷键等能力须区分 Windows 与 Linux V20 版本。

## 合规与校验

- 屏幕色域、电池和重量必须按具体 SKU 成组表述。
- 不得把集成显卡宣传为专业独显或游戏显卡。
- 不使用“全天续航”等无本地官方时长证据的表述。
- 门店物料不得把“最高/可选/典型值”删除以换取版面简洁；无法放下条件时，删参数而不是删限定语。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
