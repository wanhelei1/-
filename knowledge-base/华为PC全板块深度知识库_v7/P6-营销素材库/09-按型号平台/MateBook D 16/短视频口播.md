# MateBook D 16｜抖音 / 视频号短视频口播任务卡

## 两个平台，两套成片逻辑

### A. 抖音 25—35 秒

- 目标：用一个动作证明一个购买理由，主钩子为“大屏、数字键盘与桌面效率”。
- 0—2 秒：问题钩子，不报全套参数。
- 2—8 秒：出现产品全名和“16 英寸 16:10 工作界面”。
- 8—22 秒：执行演示——打开长表格做数字录入，展示 16:10 页面与独立数字键盘，再接投影或 U 盘完成会议场景；每个镜头只承载一个事实。
- 22—29 秒：用“适合谁 / 先确认什么”做反转式收束。
- 29—35 秒：引导保存清单或到店带真实文件验证，不喊限时抢购。
- 剪辑：1.5—3 秒一镜；数字大字卡最多 3 组；字幕每行不超过 14 个汉字。

### B. 视频号 50—70 秒

- 目标：建立可信解释，面向会转发给家人或同事共同决策的人群。
- 0—6 秒：完整说出产品和适用任务。
- 6—20 秒：交代用户矛盾与型号身份。
- 20—48 秒：按“事实—演示—条件”讲 3 项，镜头保持 4—7 秒，留出看清界面的时间。
- 48—60 秒：明确版本差异与一个不适用场景。
- 60—70 秒：展示官方规格页入口和到店核验动作。
- 配乐仅做底色，口播优先；不使用高速闪切掩盖限定语。

## 必拍镜头

1. 16 英寸 16:10 工作界面。
2. 独立数字键盘录入。
3. 会议桌或家庭学习场景。
4. USB-C、USB-A、HDMI 接口。
5. SKU、系统版本或规格页核验特写。

## 交付格式

- 抖音版：时间码口播、镜头、屏幕大字、音效点，共 25—35 秒。
- 视频号版：时间码口播、B-roll、字幕、事实脚注，共 50—70 秒。
- 另交 2 个封面标题、1 条发布文案、字幕 SRT 文本和素材清单。
- 所有参数大字卡旁用小字写版本/条件；口播也必须读出关键条件，不能只藏在字幕。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS 屏，1920 × 1200、90% 屏占比；存在 100% sRGB 与 45% NTSC 等配置，须按 SKU 核验。
- 可选第 13 代酷睿 i9-13900H（仅 Windows 版）或 i5-13420H。
- 16 GB 内存、1 TB SSD；不得据此推断所有渠道只销售单一配置。
- 56 Wh 版本约 1.68 kg，70 Wh 版本约 1.72 kg，重量与电池配置对应。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- 特色应用及指纹、快捷键等能力须区分 Windows 与 Linux V20 版本。

## 合规与校验

- 屏幕色域、电池和重量必须按具体 SKU 成组表述。
- 不得把集成显卡宣传为专业独显或游戏显卡。
- 不使用“全天续航”等无本地官方时长证据的表述。
- 短视频不得用剪辑制造不存在的响应速度、折叠效果、续航或跨设备兼容；现场演示失败的功能不可用后期合成伪装。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
