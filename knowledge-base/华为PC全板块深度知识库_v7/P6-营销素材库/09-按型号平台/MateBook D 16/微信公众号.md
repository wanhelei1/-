# MateBook D 16｜微信公众号深度图文任务卡

## 传播任务

- 核心读者：经常处理表格、录入数字、分屏办公，希望获得 16 英寸视野但仍需移动电脑的用户。
- 主问题：财务表格、网课和多窗口办公，16 英寸屏幕与独立数字键盘能解决哪些真实问题？
- 文章主线：从表格录入和多窗口任务切入，依次讲 16:10 大屏、数字键盘、标压处理器与接口，不用“全能”空话。
- 语气：编辑部式、克制、可核验；先解释场景，再给事实，不使用直播腔或“种草体”。

## 内容结构

1. **标题组**：给 3 个标题，18—26 个汉字；分别采用“场景问题 / 明确选择 / 功能解释”角度，禁止三句同义改写。
2. **摘要**：48—64 字，点明产品全名、适用任务与一项必须确认的版本条件。
3. **开篇（80—120 字）**：用真实任务提出矛盾，不虚构“我用了一个月”等体验。
4. **正文一：为什么看它**：围绕“大屏、数字键盘与桌面效率”解释定位，仅选 2 项直接相关事实。
5. **正文二：任务如何完成**：用办公、学习或创作流程串起 2—3 项能力；功能必须写触发条件。
6. **正文三：怎么选版本**：列出“适合 / 需要确认 / 不应期待”，主动呈现取舍。
7. **结尾**：引导读者携带常用文件、设备或软件到店验证，不用催单式口号。

## 图文节奏

建议 6 幅图，首图后每 180—260 字出现一幅；图片顺序：

1. 16 英寸 16:10 工作界面
2. 独立数字键盘录入
3. 会议桌或家庭学习场景
4. USB-C、USB-A、HDMI 接口
5. 一张“适合谁 / 需确认什么”的信息图
6. 官方规格页或到店核验引导图

每图配 18—36 字图注，图注说明事实或条件，不重复正文标题。

## 交付格式

- 3 个标题 + 1 条摘要。
- 正文 900—1300 字，使用 3 个信息型小标题。
- 6 条图片建议，写明“画面 / 对应事实 / 图注 / 图片索引关键词”。
- 末尾附“版本核验清单”3 项和一个非促销型 CTA。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS 屏，1920 × 1200、90% 屏占比；存在 100% sRGB 与 45% NTSC 等配置，须按 SKU 核验。
- 可选第 13 代酷睿 i9-13900H（仅 Windows 版）或 i5-13420H。
- 16 GB 内存、1 TB SSD；不得据此推断所有渠道只销售单一配置。
- 56 Wh 版本约 1.68 kg，70 Wh 版本约 1.72 kg，重量与电池配置对应。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- 特色应用及指纹、快捷键等能力须区分 Windows 与 Linux V20 版本。

## 合规与校验

- 屏幕色域、电池和重量必须按具体 SKU 成组表述。
- 不得把集成显卡宣传为专业独显或游戏显卡。
- 不使用“全天续航”等无本地官方时长证据的表述。
- 公众号长文不得把多个 SKU 的最高参数拼成一台“顶配标准机”；引用数字后紧跟版本或条件。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
