# MateBook D 16｜销售朋友圈任务卡

## 发布原则

朋友圈的任务不是复述产品页，而是给熟人一个值得私聊的具体理由。面向：经常处理表格、录入数字、分屏办公，希望获得 16 英寸视野但仍需移动电脑的用户。语气像顾问，不像群发广告；每条只讲一个场景，不连续三天复制同一套参数。

## 三条可轮换内容方向

### 1. 场景提醒型

- 开头：从“财务表格、网课和多窗口办公，16 英寸屏幕与独立数字键盘能解决哪些真实问题？”中提炼一句日常提醒。
- 中段：只放 1 项官方事实 + 它对应的任务。
- 结尾：邀请对方带常用文件或外设到店验证。
- 配图：会议桌或家庭学习场景 → 16 英寸 16:10 工作界面，2 张即可。

### 2. 版本选择型

- 开头：“同名产品也可能有不同版本，今天重点帮大家分清……”
- 中段：写两组容易混淆的 SKU / 系统 / 屏幕条件，不报未经核验的价格。
- 结尾：用一个具体问题收口，如“你更需要……还是……？”
- 配图：规格差异卡 → 独立数字键盘录入 → 官方页二维码，共 3 张。

### 3. 到店演示型

- 开头：告诉读者今天可以现场验证什么。
- 中段：用 3 个动词概括：`打开长表格做数字录入，展示 16:10 页面与独立数字键盘，再接投影或 U 盘完成会议场景`。
- 结尾：说明预约时需要带什么设备或软件名称。
- 配图：实机动作连拍 3—4 张，最后一张放 SKU 核验提示。

## 交付格式

- 每个方向各写 2 条，共 6 条；每条 90—150 字。
- 每条最多 3 个参数，且参数后紧跟版本条件。
- 每条给 2—4 张配图顺序和一句私聊承接话术。
- 表情符号不超过 3 个；不用九宫格刷屏式大字海报。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS 屏，1920 × 1200、90% 屏占比；存在 100% sRGB 与 45% NTSC 等配置，须按 SKU 核验。
- 可选第 13 代酷睿 i9-13900H（仅 Windows 版）或 i5-13420H。
- 16 GB 内存、1 TB SSD；不得据此推断所有渠道只销售单一配置。
- 56 Wh 版本约 1.68 kg，70 Wh 版本约 1.72 kg，重量与电池配置对应。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- 特色应用及指纹、快捷键等能力须区分 Windows 与 Linux V20 版本。

## 合规与校验

- 屏幕色域、电池和重量必须按具体 SKU 成组表述。
- 不得把集成显卡宣传为专业独显或游戏显卡。
- 不使用“全天续航”等无本地官方时长证据的表述。
- 朋友圈不得冒充顾客评价、晒虚假成交、暗示统一最低价或使用未经批准的倒计时；活动信息必须标日期、门店与适用 SKU。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
