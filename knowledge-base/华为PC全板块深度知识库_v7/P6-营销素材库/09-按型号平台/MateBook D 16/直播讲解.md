# MateBook D 16｜直播讲解任务卡

## 直播目标

用 6—8 分钟完成“识别型号—看真实任务—确认版本—回答疑问”。目标观众：经常处理表格、录入数字、分屏办公，希望获得 16 英寸视野但仍需移动电脑的用户。主播语气自然、耐心、有演示意识，不以高声重复参数制造热闹。

## 必备话术模块

- 开场不是“家人们冲”，而是：“如果你主要做……，先看这三件事。”
- 每个数字按“配置—条件—用途”说完整，禁止只读最大值。
- 版本追问句：“您看的具体是哪个系统、屏幕和存储版本？我按 SKU 帮您核对。”
- 软件追问句：“请告诉我软件全名与版本，兼容性不在直播间凭印象承诺。”
- 收尾句强调可验证动作，不制造倒计时或稀缺焦虑。

## 交付格式

- 6—8 分钟逐分钟台本，区分主播台词、助播字幕和实机动作。
- 道具清单、3 个高频问题、3 个风险问题及标准转介答案。
- 一条置顶评论，包含完整型号、官方链接、版本提醒。

## 本型号可用事实锚点

- 16 英寸 16:10 IPS 屏，1920 × 1200、90% 屏占比；存在 100% sRGB 与 45% NTSC 等配置，须按 SKU 核验。
- 可选第 13 代酷睿 i9-13900H（仅 Windows 版）或 i5-13420H。
- 16 GB 内存、1 TB SSD；不得据此推断所有渠道只销售单一配置。
- 56 Wh 版本约 1.68 kg，70 Wh 版本约 1.72 kg，重量与电池配置对应。
- 全尺寸键盘、1.5 mm 键程并支持独立数字键盘。
- 特色应用及指纹、快捷键等能力须区分 Windows 与 Linux V20 版本。

## 合规与校验

- 屏幕色域、电池和重量必须按具体 SKU 成组表述。
- 不得把集成显卡宣传为专业独显或游戏显卡。
- 不使用“全天续航”等无本地官方时长证据的表述。
- 直播不得承诺“所有软件都能装”“所有手机都能连”“一定续航多久”，也不得临场把别的型号参数当作本机回答。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
