# MateBook 14 酷睿 Ultra｜小红书图文笔记任务卡

## 原生选题

- 人群：依赖 Windows 软件，同时重视屏幕、触控、便携和多设备协同的学生与职场用户。
- 笔记角度：`需要 Windows 软件生态时，14 英寸轻薄本该优先看处理器、屏幕还是接口？`
- 叙事方法：做一份“选购前检查清单”，不冒充真实买家、不编造长期使用感受。
- 语气：像懂产品的朋友，短句、有判断但不过度兴奋；避免“闭眼入、封神、天花板、全网最低”。

## 7 页卡片节奏

1. **封面**：10—16 字，画面用“轻薄机身主视觉”，副标题必须出现产品具体版本或系统身份。
2. **痛点页**：一句用户问题 + 两个真实任务，留白多，不先堆参数。
3. **事实页 A**：用“3:2 OLED 文档或创作画面”解释一个最能感知的事实，数字只放 1—2 个。
4. **任务页**：把“用文档/表格展示 3:2 视野，演示触控和 HDMI/USB 外设连接；协同功能仅在支持的 Windows 版本现场验证”改写成三步操作，画面标注触发条件。
5. **细节页**：用“Windows 工作台与触控”或“USB-C、USB-A、HDMI 接口细节”，回答接口、协同、键盘或形态中的一个常见疑问。
6. **版本避坑页**：列 3 个购买前必须确认的问题，直接使用本卡合规边界。
7. **结论页**：分成“更适合 / 先别急着选”，以提问引导评论，不用硬性成交话术。

## 正文结构

- 首句 30 字内复述具体矛盾，不用“姐妹们”。
- 3 段，每段 60—110 字：场景、事实、取舍。
- 结尾问题必须可回答，例如“你更在意随身重量，还是接口和屏幕版本？”
- 标签 6—9 个，其中固定可选：#Windows轻薄本 #MateBook14 #OLED屏 #移动办公；其余只加与真实场景相关的标签。

## 交付格式

- 2 个封面标题。
- 7 页卡片逐页文案，每页标题不超过 14 字、正文不超过 55 字。
- 笔记正文 350—550 字，附 6—9 个标签。
- 单列“图片索引检索词”，不得用无来源网图冒充实拍。

## 本型号可用事实锚点

- Windows 11 家庭版与 Linux V20 版并存，功能差异必须区分。
- 14.2 英寸 3:2 OLED，2880 × 1920；Windows 版最多十点触控，Linux V20 版为五点触控。
- 约 1.31 kg、14.5 mm；实际数据会因配置、工艺与测量方法不同而有差异。
- 酷睿 Ultra 7 155H 仅 Windows 版搭载，另有酷睿 Ultra 5 125H 配置。
- 16 GB / 24 GB / 32 GB 内存、1 TB SSD，70 Wh 额定容量电池。
- 超级终端、AI 概要、AI 空间、高能/省电模式等官网所列特色应用仅限 Windows 版本。

## 合规与校验

- 不得省略操作系统版本；Linux 与 Windows 的触控、蓝牙、指纹和应用能力不同。
- 不得把 Ultra 7 或 32 GB 写成全系配置。
- 不要与同名鸿蒙版的麒麟 X90、120 Hz 动态刷新或配色素材混用。
- 小红书文案不得使用虚构第一人称实测、伪造评论截图、制造库存焦虑或将官方理论/典型值写成人人都能达到。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
