# MateBook 14 酷睿 Ultra｜抖音 / 视频号短视频口播任务卡

## 两个平台，两套成片逻辑

### A. 抖音 25—35 秒

- 目标：用一个动作证明一个购买理由，主钩子为“Windows 轻薄本的 3:2 OLED 工作视野”。
- 0—2 秒：问题钩子，不报全套参数。
- 2—8 秒：出现产品全名和“轻薄机身主视觉”。
- 8—22 秒：执行演示——用文档/表格展示 3:2 视野，演示触控和 HDMI/USB 外设连接；协同功能仅在支持的 Windows 版本现场验证；每个镜头只承载一个事实。
- 22—29 秒：用“适合谁 / 先确认什么”做反转式收束。
- 29—35 秒：引导保存清单或到店带真实文件验证，不喊限时抢购。
- 剪辑：1.5—3 秒一镜；数字大字卡最多 3 组；字幕每行不超过 14 个汉字。

### B. 视频号 50—70 秒

- 目标：建立可信解释，面向会转发给家人或同事共同决策的人群。
- 0—6 秒：完整说出产品和适用任务。
- 6—20 秒：交代用户矛盾与型号身份。
- 20—48 秒：按“事实—演示—条件”讲 3 项，镜头保持 4—7 秒，留出看清界面的时间。
- 48—60 秒：明确版本差异与一个不适用场景。
- 60—70 秒：展示官方规格页入口和到店核验动作。
- 配乐仅做底色，口播优先；不使用高速闪切掩盖限定语。

## 必拍镜头

1. 轻薄机身主视觉。
2. 3:2 OLED 文档或创作画面。
3. Windows 工作台与触控。
4. USB-C、USB-A、HDMI 接口细节。
5. SKU、系统版本或规格页核验特写。

## 交付格式

- 抖音版：时间码口播、镜头、屏幕大字、音效点，共 25—35 秒。
- 视频号版：时间码口播、B-roll、字幕、事实脚注，共 50—70 秒。
- 另交 2 个封面标题、1 条发布文案、字幕 SRT 文本和素材清单。
- 所有参数大字卡旁用小字写版本/条件；口播也必须读出关键条件，不能只藏在字幕。

## 本型号可用事实锚点

- Windows 11 家庭版与 Linux V20 版并存，功能差异必须区分。
- 14.2 英寸 3:2 OLED，2880 × 1920；Windows 版最多十点触控，Linux V20 版为五点触控。
- 约 1.31 kg、14.5 mm；实际数据会因配置、工艺与测量方法不同而有差异。
- 酷睿 Ultra 7 155H 仅 Windows 版搭载，另有酷睿 Ultra 5 125H 配置。
- 16 GB / 24 GB / 32 GB 内存、1 TB SSD，70 Wh 额定容量电池。
- 超级终端、AI 概要、AI 空间、高能/省电模式等官网所列特色应用仅限 Windows 版本。

## 合规与校验

- 不得省略操作系统版本；Linux 与 Windows 的触控、蓝牙、指纹和应用能力不同。
- 不得把 Ultra 7 或 32 GB 写成全系配置。
- 不要与同名鸿蒙版的麒麟 X90、120 Hz 动态刷新或配色素材混用。
- 短视频不得用剪辑制造不存在的响应速度、折叠效果、续航或跨设备兼容；现场演示失败的功能不可用后期合成伪装。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
