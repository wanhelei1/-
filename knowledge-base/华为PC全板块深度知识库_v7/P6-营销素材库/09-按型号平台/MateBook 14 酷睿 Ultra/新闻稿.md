# MateBook 14 酷睿 Ultra｜新闻稿 + 微博快讯任务卡

## 新闻稿定位

写一篇可供品牌活动、门店开业或行业媒体资料包使用的事实型稿件。核心信息是“Windows 轻薄本的 3:2 OLED 工作视野”，受众为科技/消费媒体与渠道伙伴。语气客观、第三人称、信息密度高；不得写成使用心得或促销软文。

## 新闻稿结构

1. **标题**：产品全名 + 一项可核实定位，不超过 32 字；不要使用“重新定义、划时代、王者”。
2. **导语（100—140 字）**：回答产品是谁、面向谁、解决什么任务；日期和活动信息只在收到正式输入后填写。
3. **第一部分｜产品身份**：依据以下主线解释产品在同品牌矩阵中的位置：围绕 Windows 工作流展开：先确认软件，再看 3:2 OLED 触控、酷睿 Ultra 平台和常用接口。不引用市场份额。
4. **第二部分｜三组事实**：每组“小标题 + 官方事实 + 使用条件”，数字来源必须可追溯。
5. **第三部分｜场景与边界**：写 2 个适用场景和 2 个购买前确认项，避免单向赞美。
6. **结尾**：提供官方页面与咨询入口；价格、上市时间、渠道、赠品均留 `[待官方确认]` 占位，禁止自行补齐。

## 本型号可用事实锚点

- Windows 11 家庭版与 Linux V20 版并存，功能差异必须区分。
- 14.2 英寸 3:2 OLED，2880 × 1920；Windows 版最多十点触控，Linux V20 版为五点触控。
- 约 1.31 kg、14.5 mm；实际数据会因配置、工艺与测量方法不同而有差异。
- 酷睿 Ultra 7 155H 仅 Windows 版搭载，另有酷睿 Ultra 5 125H 配置。
- 16 GB / 24 GB / 32 GB 内存、1 TB SSD，70 Wh 额定容量电池。
- 超级终端、AI 概要、AI 空间、高能/省电模式等官网所列特色应用仅限 Windows 版本。

## 合规与校验

- 不得省略操作系统版本；Linux 与 Windows 的触控、蓝牙、指纹和应用能力不同。
- 不得把 Ultra 7 或 32 GB 写成全系配置。
- 不要与同名鸿蒙版的麒麟 X90、120 Hz 动态刷新或配色素材混用。
- 新闻稿与微博不得擅自写发布会时间、在售状态、指导价、销量、奖项或“首次/唯一”；这些属于需另行核验的动态或比较性事实。
