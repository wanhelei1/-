## 内容结构

1. **标题组**：给 3 个标题，18—26 个汉字；分别采用“场景问题 / 明确选择 / 功能解释”角度，禁止三句同义改写。
2. **摘要**：48—64 字，点明产品全名、适用任务与一项必须确认的版本条件。
3. **开篇（80—120 字）**：用真实任务提出矛盾，不虚构“我用了一个月”等体验。
4. **正文一：为什么看它**：围绕“Windows 轻薄本的 3:2 OLED 工作视野”解释定位，仅选 2 项直接相关事实。
5. **正文二：任务如何完成**：用办公、学习或创作流程串起 2—3 项能力；功能必须写触发条件。
6. **正文三：怎么选版本**：列出“适合 / 需要确认 / 不应期待”，主动呈现取舍。
7. **结尾**：引导读者携带常用文件、设备或软件到店验证，不用催单式口号。

## 本型号可用事实锚点

- Windows 11 家庭版与 Linux V20 版并存，功能差异必须区分。
- 14.2 英寸 3:2 OLED，2880 × 1920；Windows 版最多十点触控，Linux V20 版为五点触控。
- 约 1.31 kg、14.5 mm；实际数据会因配置、工艺与测量方法不同而有差异。
- 酷睿 Ultra 7 155H 仅 Windows 版搭载，另有酷睿 Ultra 5 125H 配置。
- 16 GB / 24 GB / 32 GB 内存、1 TB SSD，70 Wh 额定容量电池。
- 超级终端、AI 概要、AI 空间、高能/省电模式等官网所列特色应用仅限 Windows 版本。
