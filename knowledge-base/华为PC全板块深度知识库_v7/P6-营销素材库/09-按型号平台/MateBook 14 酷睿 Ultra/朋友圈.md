# MateBook 14 酷睿 Ultra｜销售朋友圈任务卡

## 发布原则

朋友圈的任务不是复述产品页，而是给熟人一个值得私聊的具体理由。面向：依赖 Windows 软件，同时重视屏幕、触控、便携和多设备协同的学生与职场用户。语气像顾问，不像群发广告；每条只讲一个场景，不连续三天复制同一套参数。

## 三条可轮换内容方向

### 1. 场景提醒型

- 开头：从“需要 Windows 软件生态时，14 英寸轻薄本该优先看处理器、屏幕还是接口？”中提炼一句日常提醒。
- 中段：只放 1 项官方事实 + 它对应的任务。
- 结尾：邀请对方带常用文件或外设到店验证。
- 配图：Windows 工作台与触控 → 轻薄机身主视觉，2 张即可。

### 2. 版本选择型

- 开头：“同名产品也可能有不同版本，今天重点帮大家分清……”
- 中段：写两组容易混淆的 SKU / 系统 / 屏幕条件，不报未经核验的价格。
- 结尾：用一个具体问题收口，如“你更需要……还是……？”
- 配图：规格差异卡 → 3:2 OLED 文档或创作画面 → 官方页二维码，共 3 张。

### 3. 到店演示型

- 开头：告诉读者今天可以现场验证什么。
- 中段：用 3 个动词概括：`用文档/表格展示 3:2 视野，演示触控和 HDMI/USB 外设连接；协同功能仅在支持的 Windows 版本现场验证`。
- 结尾：说明预约时需要带什么设备或软件名称。
- 配图：实机动作连拍 3—4 张，最后一张放 SKU 核验提示。

## 交付格式

- 每个方向各写 2 条，共 6 条；每条 90—150 字。
- 每条最多 3 个参数，且参数后紧跟版本条件。
- 每条给 2—4 张配图顺序和一句私聊承接话术。
- 表情符号不超过 3 个；不用九宫格刷屏式大字海报。

## 本型号可用事实锚点

- Windows 11 家庭版与 Linux V20 版并存，功能差异必须区分。
- 14.2 英寸 3:2 OLED，2880 × 1920；Windows 版最多十点触控，Linux V20 版为五点触控。
- 约 1.31 kg、14.5 mm；实际数据会因配置、工艺与测量方法不同而有差异。
- 酷睿 Ultra 7 155H 仅 Windows 版搭载，另有酷睿 Ultra 5 125H 配置。
- 16 GB / 24 GB / 32 GB 内存、1 TB SSD，70 Wh 额定容量电池。
- 超级终端、AI 概要、AI 空间、高能/省电模式等官网所列特色应用仅限 Windows 版本。

## 合规与校验

- 不得省略操作系统版本；Linux 与 Windows 的触控、蓝牙、指纹和应用能力不同。
- 不得把 Ultra 7 或 32 GB 写成全系配置。
- 不要与同名鸿蒙版的麒麟 X90、120 Hz 动态刷新或配色素材混用。
- 朋友圈不得冒充顾客评价、晒虚假成交、暗示统一最低价或使用未经批准的倒计时；活动信息必须标日期、门店与适用 SKU。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
