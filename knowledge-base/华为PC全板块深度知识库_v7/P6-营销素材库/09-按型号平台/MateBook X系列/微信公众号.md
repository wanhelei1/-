# MateBook X系列｜微信公众号深度图文任务卡

## 传播任务

- 核心读者：对重量、旗舰屏幕、外观质感与 Windows 专业软件兼容都有高要求的移动商务人群。
- 主问题：旗舰轻薄本的溢价，应该用重量、屏幕、接口和工作流中的哪些事实来判断？
- 文章主线：以“每次出门都能感知的价值”为主线：980 g、3:2 OLED 与 Windows 工作流，避免泛讲整个 X 系列。
- 语气：编辑部式、克制、可核验；先解释场景，再给事实，不使用直播腔或“种草体”。

## 内容结构

1. **标题组**：给 3 个标题，18—26 个汉字；分别采用“场景问题 / 明确选择 / 功能解释”角度，禁止三句同义改写。
2. **摘要**：48—64 字，点明产品全名、适用任务与一项必须确认的版本条件。
3. **开篇（80—120 字）**：用真实任务提出矛盾，不虚构“我用了一个月”等体验。
4. **正文一：为什么看它**：围绕“980 克旗舰 Windows 工作台”解释定位，仅选 2 项直接相关事实。
5. **正文二：任务如何完成**：用办公、学习或创作流程串起 2—3 项能力；功能必须写触发条件。
6. **正文三：怎么选版本**：列出“适合 / 需要确认 / 不应期待”，主动呈现取舍。
7. **结尾**：引导读者携带常用文件、设备或软件到店验证，不用催单式口号。

## 图文节奏

建议 6 幅图，首图后每 180—260 字出现一幅；图片顺序：

1. 微绒典藏版外观与材质近景
2. 约 980 g 单手移动
3. 14.2 英寸 3:2 OLED
4. 雷电 4、USB-C 与隐私开关
5. 一张“适合谁 / 需确认什么”的信息图
6. 官方规格页或到店核验引导图

每图配 18—36 字图注，图注说明事实或条件，不重复正文标题。

## 交付格式

- 3 个标题 + 1 条摘要。
- 正文 900—1300 字，使用 3 个信息型小标题。
- 6 条图片建议，写明“画面 / 对应事实 / 图注 / 图片索引关键词”。
- 末尾附“版本核验清单”3 项和一个非促销型 CTA。

## 本型号可用事实锚点

- 本目录事实锚点是 HUAWEI MateBook X Pro 酷睿 Ultra 微绒典藏版，不代表所有 MateBook X 型号。
- 约 980 g、13.5 mm；14.2 英寸 3:2 OLED，3120 × 2080。
- 最高 120 Hz；出厂最高 60 Hz，可切换，实际刷新率随应用界面变化。
- 局部峰值亮度 1000 尼特需 Windows 版开启 HDR 并配合 HDR 内容源。
- Windows 版可选酷睿 Ultra 9 185H / Ultra 7 155H，16 GB / 32 GB 内存与 1 TB / 2 TB SSD。
- Windows 版含两个雷电 4 与一个 USB-C；Linux 版接口能力、摄像头、指纹及特色应用存在差异。

## 合规与校验

- 文件夹虽称“X系列”，成稿必须写明具体事实锚点，禁止泛化到整个系列。
- 1000 尼特、120 Hz、十点触控等均须带版本或使用条件。
- 微绒材质只描述可见设计，不杜撰耐磨、抗污或触感测试结论。
- 公众号长文不得把多个 SKU 的最高参数拼成一台“顶配标准机”；引用数字后紧跟版本或条件。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
