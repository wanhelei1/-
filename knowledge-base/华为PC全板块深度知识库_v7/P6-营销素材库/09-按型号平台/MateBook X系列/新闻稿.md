# MateBook X系列｜新闻稿 + 微博快讯任务卡

## 新闻稿定位

写一篇可供品牌活动、门店开业或行业媒体资料包使用的事实型稿件。核心信息是“980 克旗舰 Windows 工作台”，受众为科技/消费媒体与渠道伙伴。语气客观、第三人称、信息密度高；不得写成使用心得或促销软文。

## 新闻稿结构

1. **标题**：产品全名 + 一项可核实定位，不超过 32 字；不要使用“重新定义、划时代、王者”。
2. **导语（100—140 字）**：回答产品是谁、面向谁、解决什么任务；日期和活动信息只在收到正式输入后填写。
3. **第一部分｜产品身份**：依据以下主线解释产品在同品牌矩阵中的位置：以“每次出门都能感知的价值”为主线：980 g、3:2 OLED 与 Windows 工作流，避免泛讲整个 X 系列。不引用市场份额。
4. **第二部分｜三组事实**：每组“小标题 + 官方事实 + 使用条件”，数字来源必须可追溯。
5. **第三部分｜场景与边界**：写 2 个适用场景和 2 个购买前确认项，避免单向赞美。
6. **结尾**：提供官方页面与咨询入口；价格、上市时间、渠道、赠品均留 `[待官方确认]` 占位，禁止自行补齐。

## 微博快讯版

- 140—220 字，不复制新闻稿导语。
- 结构：一句发布事实 → 两项核心信息 → 一项版本提醒 → 官方链接。
- 最多 2 个话题标签，推荐从 `#旗舰轻薄本 #MateBookXPro #移动办公 #Windows电脑` 中选；不用刷屏式九宫格文案。
- 配图 1—4 张，第一张确认型号，最后一张放“具体配置以销售 SKU 为准”。

## 交付格式

- 新闻稿标题 2 个、导语 1 段、正文 800—1200 字、4 条图注、事实来源表。
- 微博快讯 2 版：一版信息型、一版场景型；各附图片顺序和替代文本。

## 本型号可用事实锚点

- 本目录事实锚点是 HUAWEI MateBook X Pro 酷睿 Ultra 微绒典藏版，不代表所有 MateBook X 型号。
- 约 980 g、13.5 mm；14.2 英寸 3:2 OLED，3120 × 2080。
- 最高 120 Hz；出厂最高 60 Hz，可切换，实际刷新率随应用界面变化。
- 局部峰值亮度 1000 尼特需 Windows 版开启 HDR 并配合 HDR 内容源。
- Windows 版可选酷睿 Ultra 9 185H / Ultra 7 155H，16 GB / 32 GB 内存与 1 TB / 2 TB SSD。
- Windows 版含两个雷电 4 与一个 USB-C；Linux 版接口能力、摄像头、指纹及特色应用存在差异。

## 合规与校验

- 文件夹虽称“X系列”，成稿必须写明具体事实锚点，禁止泛化到整个系列。
- 1000 尼特、120 Hz、十点触控等均须带版本或使用条件。
- 微绒材质只描述可见设计，不杜撰耐磨、抗污或触感测试结论。
- 新闻稿与微博不得擅自写发布会时间、在售状态、指导价、销量、奖项或“首次/唯一”；这些属于需另行核验的动态或比较性事实。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
