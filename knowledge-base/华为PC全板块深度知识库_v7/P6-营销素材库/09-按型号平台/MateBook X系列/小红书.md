# MateBook X系列｜小红书图文笔记任务卡

## 原生选题

- 人群：对重量、旗舰屏幕、外观质感与 Windows 专业软件兼容都有高要求的移动商务人群。
- 笔记角度：`旗舰轻薄本的溢价，应该用重量、屏幕、接口和工作流中的哪些事实来判断？`
- 叙事方法：做一份“选购前检查清单”，不冒充真实买家、不编造长期使用感受。
- 语气：像懂产品的朋友，短句、有判断但不过度兴奋；避免“闭眼入、封神、天花板、全网最低”。

## 7 页卡片节奏

1. **封面**：10—16 字，画面用“微绒典藏版外观与材质近景”，副标题必须出现产品具体版本或系统身份。
2. **痛点页**：一句用户问题 + 两个真实任务，留白多，不先堆参数。
3. **事实页 A**：用“约 980 g 单手移动”解释一个最能感知的事实，数字只放 1—2 个。
4. **任务页**：把“一手拿机展示 980 g 级轻量，再用 HDR 内容/文档展示屏幕，最后连接雷电或 USB-C 外设并说明系统版本差异”改写成三步操作，画面标注触发条件。
5. **细节页**：用“14.2 英寸 3:2 OLED”或“雷电 4、USB-C 与隐私开关”，回答接口、协同、键盘或形态中的一个常见疑问。
6. **版本避坑页**：列 3 个购买前必须确认的问题，直接使用本卡合规边界。
7. **结论页**：分成“更适合 / 先别急着选”，以提问引导评论，不用硬性成交话术。

## 正文结构

- 首句 30 字内复述具体矛盾，不用“姐妹们”。
- 3 段，每段 60—110 字：场景、事实、取舍。
- 结尾问题必须可回答，例如“你更在意随身重量，还是接口和屏幕版本？”
- 标签 6—9 个，其中固定可选：#旗舰轻薄本 #MateBookXPro #移动办公 #Windows电脑；其余只加与真实场景相关的标签。

## 交付格式

- 2 个封面标题。
- 7 页卡片逐页文案，每页标题不超过 14 字、正文不超过 55 字。
- 笔记正文 350—550 字，附 6—9 个标签。
- 单列“图片索引检索词”，不得用无来源网图冒充实拍。

## 本型号可用事实锚点

- 本目录事实锚点是 HUAWEI MateBook X Pro 酷睿 Ultra 微绒典藏版，不代表所有 MateBook X 型号。
- 约 980 g、13.5 mm；14.2 英寸 3:2 OLED，3120 × 2080。
- 最高 120 Hz；出厂最高 60 Hz，可切换，实际刷新率随应用界面变化。
- 局部峰值亮度 1000 尼特需 Windows 版开启 HDR 并配合 HDR 内容源。
- Windows 版可选酷睿 Ultra 9 185H / Ultra 7 155H，16 GB / 32 GB 内存与 1 TB / 2 TB SSD。
- Windows 版含两个雷电 4 与一个 USB-C；Linux 版接口能力、摄像头、指纹及特色应用存在差异。

## 合规与校验

- 文件夹虽称“X系列”，成稿必须写明具体事实锚点，禁止泛化到整个系列。
- 1000 尼特、120 Hz、十点触控等均须带版本或使用条件。
- 微绒材质只描述可见设计，不杜撰耐磨、抗污或触感测试结论。
- 小红书文案不得使用虚构第一人称实测、伪造评论截图、制造库存焦虑或将官方理论/典型值写成人人都能达到。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
