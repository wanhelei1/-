# MateBook X系列｜抖音 / 视频号短视频口播任务卡

## 两个平台，两套成片逻辑

### A. 抖音 25—35 秒

- 目标：用一个动作证明一个购买理由，主钩子为“980 克旗舰 Windows 工作台”。
- 0—2 秒：问题钩子，不报全套参数。
- 2—8 秒：出现产品全名和“微绒典藏版外观与材质近景”。
- 8—22 秒：执行演示——一手拿机展示 980 g 级轻量，再用 HDR 内容/文档展示屏幕，最后连接雷电或 USB-C 外设并说明系统版本差异；每个镜头只承载一个事实。
- 22—29 秒：用“适合谁 / 先确认什么”做反转式收束。
- 29—35 秒：引导保存清单或到店带真实文件验证，不喊限时抢购。
- 剪辑：1.5—3 秒一镜；数字大字卡最多 3 组；字幕每行不超过 14 个汉字。

### B. 视频号 50—70 秒

- 目标：建立可信解释，面向会转发给家人或同事共同决策的人群。
- 0—6 秒：完整说出产品和适用任务。
- 6—20 秒：交代用户矛盾与型号身份。
- 20—48 秒：按“事实—演示—条件”讲 3 项，镜头保持 4—7 秒，留出看清界面的时间。
- 48—60 秒：明确版本差异与一个不适用场景。
- 60—70 秒：展示官方规格页入口和到店核验动作。
- 配乐仅做底色，口播优先；不使用高速闪切掩盖限定语。

## 必拍镜头

1. 微绒典藏版外观与材质近景。
2. 约 980 g 单手移动。
3. 14.2 英寸 3:2 OLED。
4. 雷电 4、USB-C 与隐私开关。
5. SKU、系统版本或规格页核验特写。

## 交付格式

- 抖音版：时间码口播、镜头、屏幕大字、音效点，共 25—35 秒。
- 视频号版：时间码口播、B-roll、字幕、事实脚注，共 50—70 秒。
- 另交 2 个封面标题、1 条发布文案、字幕 SRT 文本和素材清单。
- 所有参数大字卡旁用小字写版本/条件；口播也必须读出关键条件，不能只藏在字幕。

## 本型号可用事实锚点

- 本目录事实锚点是 HUAWEI MateBook X Pro 酷睿 Ultra 微绒典藏版，不代表所有 MateBook X 型号。
- 约 980 g、13.5 mm；14.2 英寸 3:2 OLED，3120 × 2080。
- 最高 120 Hz；出厂最高 60 Hz，可切换，实际刷新率随应用界面变化。
- 局部峰值亮度 1000 尼特需 Windows 版开启 HDR 并配合 HDR 内容源。
- Windows 版可选酷睿 Ultra 9 185H / Ultra 7 155H，16 GB / 32 GB 内存与 1 TB / 2 TB SSD。
- Windows 版含两个雷电 4 与一个 USB-C；Linux 版接口能力、摄像头、指纹及特色应用存在差异。

## 合规与校验

- 文件夹虽称“X系列”，成稿必须写明具体事实锚点，禁止泛化到整个系列。
- 1000 尼特、120 Hz、十点触控等均须带版本或使用条件。
- 微绒材质只描述可见设计，不杜撰耐磨、抗污或触感测试结论。
- 短视频不得用剪辑制造不存在的响应速度、折叠效果、续航或跨设备兼容；现场演示失败的功能不可用后期合成伪装。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
