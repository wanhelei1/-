# MateBook X系列｜销售朋友圈任务卡

## 发布原则

朋友圈的任务不是复述产品页，而是给熟人一个值得私聊的具体理由。面向：对重量、旗舰屏幕、外观质感与 Windows 专业软件兼容都有高要求的移动商务人群。语气像顾问，不像群发广告；每条只讲一个场景，不连续三天复制同一套参数。

## 三条可轮换内容方向

### 1. 场景提醒型

- 开头：从“旗舰轻薄本的溢价，应该用重量、屏幕、接口和工作流中的哪些事实来判断？”中提炼一句日常提醒。
- 中段：只放 1 项官方事实 + 它对应的任务。
- 结尾：邀请对方带常用文件或外设到店验证。
- 配图：14.2 英寸 3:2 OLED → 微绒典藏版外观与材质近景，2 张即可。

### 2. 版本选择型

- 开头：“同名产品也可能有不同版本，今天重点帮大家分清……”
- 中段：写两组容易混淆的 SKU / 系统 / 屏幕条件，不报未经核验的价格。
- 结尾：用一个具体问题收口，如“你更需要……还是……？”
- 配图：规格差异卡 → 约 980 g 单手移动 → 官方页二维码，共 3 张。

### 3. 到店演示型

- 开头：告诉读者今天可以现场验证什么。
- 中段：用 3 个动词概括：`一手拿机展示 980 g 级轻量，再用 HDR 内容/文档展示屏幕，最后连接雷电或 USB-C 外设并说明系统版本差异`。
- 结尾：说明预约时需要带什么设备或软件名称。
- 配图：实机动作连拍 3—4 张，最后一张放 SKU 核验提示。

## 交付格式

- 每个方向各写 2 条，共 6 条；每条 90—150 字。
- 每条最多 3 个参数，且参数后紧跟版本条件。
- 每条给 2—4 张配图顺序和一句私聊承接话术。
- 表情符号不超过 3 个；不用九宫格刷屏式大字海报。

## 本型号可用事实锚点

- 本目录事实锚点是 HUAWEI MateBook X Pro 酷睿 Ultra 微绒典藏版，不代表所有 MateBook X 型号。
- 约 980 g、13.5 mm；14.2 英寸 3:2 OLED，3120 × 2080。
- 最高 120 Hz；出厂最高 60 Hz，可切换，实际刷新率随应用界面变化。
- 局部峰值亮度 1000 尼特需 Windows 版开启 HDR 并配合 HDR 内容源。
- Windows 版可选酷睿 Ultra 9 185H / Ultra 7 155H，16 GB / 32 GB 内存与 1 TB / 2 TB SSD。
- Windows 版含两个雷电 4 与一个 USB-C；Linux 版接口能力、摄像头、指纹及特色应用存在差异。

## 合规与校验

- 文件夹虽称“X系列”，成稿必须写明具体事实锚点，禁止泛化到整个系列。
- 1000 尼特、120 Hz、十点触控等均须带版本或使用条件。
- 微绒材质只描述可见设计，不杜撰耐磨、抗污或触感测试结论。
- 朋友圈不得冒充顾客评价、晒虚假成交、暗示统一最低价或使用未经批准的倒计时；活动信息必须标日期、门店与适用 SKU。
- 禁止绝对化、排他性、无法证明的竞品贬损、虚构用户体验，以及未核验的价格、赠品、库存、销量、续航时长和性能百分比。
- 成稿末尾保留一句：`不同销售版本配置可能不同，请以华为官方规格页及实际销售 SKU 为准。`
