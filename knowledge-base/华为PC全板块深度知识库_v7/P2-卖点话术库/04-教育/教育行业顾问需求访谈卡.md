# 教育行业顾问需求访谈

## 用途

把教学流程、平台、学科软件、管理与服务转成可执行试点。

本文件用于训练与生成，不直接替代具体型号事实。任何参数、功能、支持范围、服务和动态信息都要回到相应来源；资料不足时允许给出有限结论和验证计划，不为追求顺畅话术补造信息。

## 使用情境

教育单位计划新建一间示范教室，同时更新部分教师移动办公设备。

## 开始前准备

- 记录用户原话、任务频率、不能接受的风险和期望完成时间。
- 获取完整型号/SKU、系统与软件版本；涉及外设时记录品牌、型号、接口和连接链路。
- 打开P1事实、P7支持与必要的厂商官方页面，不用记忆或搜索摘要代替原页。
- 将价格、库存、赠品、服务权益和交期放进单独的动态字段，并标注核验人和时间。

### 3. 教室现有大屏、投影、音响和网络是什么？

### 5. 谁提供试讲课程和脱敏材料？

## 执行步骤

1. 访谈教师、信息中心和管理者，不只问采购。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
2. 选择一节代表课程与一个高风险学科软件。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
3. 把课件格式、视频、字体和外设列入材料表。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
4. 试点安排正常与失败恢复两轮。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
5. 用教师独立完成作为通过条件之一。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。

## 完整示范

**情境：** 教育单位计划新建一间示范教室，同时更新部分教师移动办公设备。

**示范处理：** 示例试点：教师使用脱敏课件登录平台、连接教室显示设备、播放音视频、批注并提交作业；信息中心记录网络、账号和版本。若无线投屏失败，按预案切换批准的有线连接，并把失败原因留作复测。

**建议收口：** ‘以上结论只对应已经确认的型号、版本和任务；未确认项已列入验证清单。你可以带常用文件、软件版本或外设完成实机核验，价格与权益则以当日授权页面或结算信息为准。’

## 正确表达与错误表达

- 正确：先给有限结论，再说明证据、适用条件和下一步。
- 正确：主动说出不适合的人群或需要先验证的门槛。
- 错误：‘肯定都能用’‘全系都是这个配置’‘任何情况都可以’。
- 错误：虚构第一人称体验、用户评价、销量、库存或无法核验的效率百分比。

### 本主题常见错误

- 只展示宣传视频，不让教师独立操作
- 演示使用与学校不同的网络和账号
- 忽略字体、插件、音视频格式和打印
- 试点通过后没有教师手册与管理员交接

## 发布或交付前检查

- □ 型号、SKU、系统路线和版本没有混用。
- □ 每个数字都能回到当前适用的官方页面，并保留限定词。
- □ 第三方案例只用于研究问题与结构，没有当成产品事实。
- □ 体验来自真实、获授权的测试，没有伪造人物或使用时长。
- □ 价格、库存、活动、交期和服务权益带有日期与责任人。
- □ 已说明限制、不适用情形、待核验项和转人工路径。
