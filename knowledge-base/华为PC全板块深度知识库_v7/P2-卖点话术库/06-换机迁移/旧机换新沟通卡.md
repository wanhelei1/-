# 旧机换新沟通

## 用途

在推荐新机前完成数据、应用、授权、外设和退出计划，避免‘文件拷完就算迁移完成’。

本文件用于训练与生成，不直接替代具体型号事实。任何参数、功能、支持范围、服务和动态信息都要回到相应来源；资料不足时允许给出有限结论和验证计划，不为追求顺畅话术补造信息。

## 使用情境

用户旧机资料分散在桌面、云盘、聊天软件和专业应用中，想当天换机并立即清空旧机。

## 开始前准备

- 记录用户原话、任务频率、不能接受的风险和期望完成时间。
- 获取完整型号/SKU、系统与软件版本；涉及外设时记录品牌、型号、接口和连接链路。
- 打开P1事实、P7支持与必要的厂商官方页面，不用记忆或搜索摘要代替原页。
- 将价格、库存、赠品、服务权益和交期放进单独的动态字段，并标注核验人和时间。

**为什么要问：** 先保护唯一副本。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 3. 哪些应用、插件和许可证必须继续使用？

**为什么要问：** 区分文件与应用迁移。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 4. 是否有加密文件、企业资料或受管账号？

**为什么要问：** 遵守安全与权限。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 5. 新机系统是否满足必用软件和外设？

**为什么要问：** 先验证再迁移。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 6. 旧机何时、由谁清除？

**为什么要问：** 在验收后安全退出。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

## 执行步骤

1. 先盘点并建立独立备份，抽查可打开。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
2. 将个人文件、应用数据、应用程序、授权和外设分五类。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
3. 按官方工具支持范围迁移，不承诺全部自动完成。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
4. 新机逐类验收数量、可打开性和真实任务。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
5. 只有验收完成并保留备份后才退出账号、清除旧机。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。

## 完整示范

**情境：** 用户旧机资料分散在桌面、云盘、聊天软件和专业应用中，想当天换机并立即清空旧机。

**示范处理：** 顾问先暂停‘当天清空旧机’，与用户列出文档、照片、邮件、浏览器、聊天、专业项目和许可证。数据克隆只处理其官方支持的范围；专业软件重新安装并打开代表项目，外设重新连接；最后由用户签字确认再处理旧机。

**建议收口：** ‘以上结论只对应已经确认的型号、版本和任务；未确认项已列入验证清单。你可以带常用文件、软件版本或外设完成实机核验，价格与权益则以当日授权页面或结算信息为准。’

## 正确表达与错误表达

- 正确：先给有限结论，再说明证据、适用条件和下一步。
- 正确：主动说出不适合的人群或需要先验证的门槛。
- 错误：‘肯定都能用’‘全系都是这个配置’‘任何情况都可以’。
- 错误：虚构第一人称体验、用户评价、销量、库存或无法核验的效率百分比。

### 本主题常见错误

- 只比较硬盘容量，不盘点实际资料
- 认为安装包或软件图标会自动迁移授权
- 把同一硬盘另一文件夹当备份
- 新机还未验收就格式化、出售或回收旧机

## 证据路径

- P7 Windows迁移至鸿蒙电脑完整流程
- 华为官方迁移/数据克隆页面
- 软件厂商授权与迁移说明
- 企业数据与旧机报废制度

## 发布或交付前检查

- □ 型号、SKU、系统路线和版本没有混用。
- □ 每个数字都能回到当前适用的官方页面，并保留限定词。
- □ 第三方案例只用于研究问题与结构，没有当成产品事实。
- □ 体验来自真实、获授权的测试，没有伪造人物或使用时长。
- □ 价格、库存、活动、交期和服务权益带有日期与责任人。
- □ 已说明限制、不适用情形、待核验项和转人工路径。
