# 服务价值表达

## 用途

把官方服务入口、适用条件和客户风险说清，不把服务包装成无条件兜底。

本文件用于训练与生成，不直接替代具体型号事实。任何参数、功能、支持范围、服务和动态信息都要回到相应来源；资料不足时允许给出有限结论和验证计划，不为追求顺畅话术补造信息。

## 使用情境

顾客担心异地出差期间设备故障，销售准备回答‘全国都能免费上门解决’。

## 开始前准备

- 记录用户原话、任务频率、不能接受的风险和期望完成时间。
- 获取完整型号/SKU、系统与软件版本；涉及外设时记录品牌、型号、接口和连接链路。
- 打开P1事实、P7支持与必要的厂商官方页面，不用记忆或搜索摘要代替原页。
- 将价格、库存、赠品、服务权益和交期放进单独的动态字段，并标注核验人和时间。

## 关键问题树

### 1. 购买渠道、地区和具体型号是什么？

**为什么要问：** 服务政策可能不同。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 2. 顾客最担心哪类故障和停工多久？

**为什么要问：** 匹配自助、远程、门店或备机方案。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 3. 是否为个人或单位设备？

**为什么要问：** 确定权限和数据处理。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 4. 当前可核验的保修与权益在哪里？

**为什么要问：** 避免口头承诺。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 5. 送修前资料怎样备份和退出账号？

**为什么要问：** 控制数据风险。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 6. 哪些情况属于人为损坏或需检测？

**为什么要问：** 不代替服务中心判定。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

## 执行步骤

1. 先解释可用服务入口，再说明实际权益需按SN/订单核验。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
2. 把自助排查、远程支持、服务店、寄修等作为不同路径。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
3. 说明服务能缩短哪一步，但不承诺所有故障即时解决。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
4. 提醒数据备份、账号退出和维修授权。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
5. 当场打不开政策页时记录问题并转官方确认。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。

## 完整示范

**情境：** 顾客担心异地出差期间设备故障，销售准备回答‘全国都能免费上门解决’。

**示范处理：** 合规说法：‘华为提供在线支持、服务店等入口；你这台设备具体适用的保修和服务方式，需要结合型号、地区、订单与当前政策核验。重要资料应先备份，硬件问题由官方检测结果判断。’

**建议收口：** ‘以上结论只对应已经确认的型号、版本和任务；未确认项已列入验证清单。你可以带常用文件、软件版本或外设完成实机核验，价格与权益则以当日授权页面或结算信息为准。’

## 正确表达与错误表达

- 正确：先给有限结论，再说明证据、适用条件和下一步。
- 正确：主动说出不适合的人群或需要先验证的门槛。
- 错误：‘肯定都能用’‘全系都是这个配置’‘任何情况都可以’。
- 错误：虚构第一人称体验、用户评价、销量、库存或无法核验的效率百分比。

### 本主题常见错误

- 承诺所有问题都能远程解决
- 把所有损坏写成免费保修
- 没有核验SN/订单就承诺上门、备用机或完成时限
- 送修前不提醒备份和账号/隐私处理

## 发布或交付前检查

- □ 型号、SKU、系统路线和版本没有混用。
- □ 每个数字都能回到当前适用的官方页面，并保留限定词。
- □ 第三方案例只用于研究问题与结构，没有当成产品事实。
- □ 体验来自真实、获授权的测试，没有伪造人物或使用时长。
- □ 价格、库存、活动、交期和服务权益带有日期与责任人。
- □ 已说明限制、不适用情形、待核验项和转人工路径。
