# 渠道培训表达

## 用途

让一线会问、会查、会演示、会承认边界，而不是背诵卖点。

本文件用于训练与生成，不直接替代具体型号事实。任何参数、功能、支持范围、服务和动态信息都要回到相应来源；资料不足时允许给出有限结论和验证计划，不为追求顺畅话术补造信息。

## 使用情境

渠道培训只有30分钟，学员需要当天用于门店与直播。

## 开始前准备

- 记录用户原话、任务频率、不能接受的风险和期望完成时间。
- 获取完整型号/SKU、系统与软件版本；涉及外设时记录品牌、型号、接口和连接链路。
- 打开P1事实、P7支持与必要的厂商官方页面，不用记忆或搜索摘要代替原页。
- 将价格、库存、赠品、服务权益和交期放进单独的动态字段，并标注核验人和时间。

## 关键问题树

### 1. 事实卡？

**为什么要问：** 本批次SKU、三项核心事实与三项限制。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 2. 问题卡？

**为什么要问：** 目标客群的六个高频问题。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 3. 演示卡？

**为什么要问：** 两项低风险、可复现任务。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 4. 异议卡？

**为什么要问：** 价格、兼容、竞品与售后。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

### 5. 升级卡？

**为什么要问：** 未知问题、动态信息和服务转接。如果这一项无法确认，不应把受它影响的参数、兼容性或推荐写成确定结论。

## 执行步骤

1. 事实卡：本批次SKU、三项核心事实与三项限制。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
2. 问题卡：目标客群的六个高频问题。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
3. 演示卡：两项低风险、可复现任务。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
4. 异议卡：价格、兼容、竞品与售后。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。
5. 升级卡：未知问题、动态信息和服务转接。完成后把结果标成‘已确认 / 待测试 / 不适用’，并附证据位置。

## 完整示范

**情境：** 渠道培训只有30分钟，学员需要当天用于门店与直播。

**示范处理：** 培训先做一次错误话术辨认，再用真实SKU和顾客问题演练。结尾不是考试参数，而是要求学员找到证据、说明条件，并把未知问题正确转交。

**建议收口：** ‘以上结论只对应已经确认的型号、版本和任务；未确认项已列入验证清单。你可以带常用文件、软件版本或外设完成实机核验，价格与权益则以当日授权页面或结算信息为准。’

## 正确表达与错误表达

- 正确：先给有限结论，再说明证据、适用条件和下一步。
- 正确：主动说出不适合的人群或需要先验证的门槛。
- 错误：‘肯定都能用’‘全系都是这个配置’‘任何情况都可以’。
- 错误：虚构第一人称体验、用户评价、销量、库存或无法核验的效率百分比。

### 本主题常见错误

- 跳过需求直接输出结论
- 引用了数字却没有型号、来源或条件
- 把一个人的体验泛化为所有用户
- 发现未知项时用模糊形容词掩盖

## 证据路径

- P1具体型号事实与限制
- P7官方支持与综合指南
- P3同期竞品官方证据（仅在需要比较时）
- P4获授权动态记录（仅在需要价格/政策时）

## 输出记录模板

- 用户/客户任务：
- 完整产品与SKU：
- 系统、软件、插件和外设：
- 必须满足 / 希望改善 / 可以放弃：
- 已确认事实、来源与日期：
- 待核验项、影响与责任人：
- 候选方案及各自取舍：
- 演示或试点步骤与通过标准：
- 动态价格/库存/权益核验人和时间：
- 最终答复与下一步：

## 发布或交付前检查

- □ 型号、SKU、系统路线和版本没有混用。
- □ 每个数字都能回到当前适用的官方页面，并保留限定词。
- □ 第三方案例只用于研究问题与结构，没有当成产品事实。
- □ 体验来自真实、获授权的测试，没有伪造人物或使用时长。
- □ 价格、库存、活动、交期和服务权益带有日期与责任人。
- □ 已说明限制、不适用情形、待核验项和转人工路径。
