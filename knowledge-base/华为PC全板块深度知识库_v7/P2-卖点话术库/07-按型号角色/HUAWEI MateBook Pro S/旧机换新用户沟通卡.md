# HUAWEI MateBook Pro S｜旧机换新用户沟通卡

## 换机前先盘旧资产

1. 旧机是什么系统？必须保留的软件版本、许可证、浏览器证书、加密盘和本地数据库有哪些？
2. 列出必须使用的业务软件、教学插件或创作工具，核验其鸿蒙版本与文件互通，而非只问“能不能办公”。
3. 外设清单包括打印机、扫描仪、U 盾、显示器、硬盘和旧接口设备吗？现场只用左右两个 USB-C 同时模拟充电与投屏；如还要接存储或鼠标，需验证扩展坞。
4. 哪些资料只在本地、哪些已同步云端；是否已有至少一份可恢复备份？

## 换新的证据与迁移话术

- 新旧系统差异：这是 HarmonyOS 6.1 的超轻薄款，处理器为麒麟 XE90；标准屏、防窥屏、柔光屏和典藏版不能混为一个配置。
- 容量选择：麒麟 XE90，内存有 16/24/32 GB，存储有 512 GB/1 TB。
- 接口变化：只有左右各 1 个 USB-C；规格只明确右侧 USB-C 支持 DisplayPort 1.2、最高 4K@60 Hz。
- 型号锚点：约 798 g 的标准/防窥版本、54 Wh、前后双 1080P 摄像头与双 USB-C，是 Pro S 的独有组合。

建议说：“先做可回退迁移：保留旧机和授权，抽样复制文档、照片、邮件与项目文件，在新机上验证打开、编辑、保存、打印；确认完整后再决定旧机处置。”

## 反问决定节奏

- 如果一个关键软件或外设只能留在旧环境，你接受双机过渡、虚拟/远程方案，还是应改选兼容性更直接的机型？
- 你换机主要为重量、屏幕、速度、接口还是系统生态？只选最痛的一项，再看这台机是否真正解决。先问客户要标准、防窥、柔光还是典藏版，再对应确认重量、屏幕和隐私开关。

## 适合与风险点

- 适用：适合把极致轻便、3.1K 级 OLED、手写或后置取景放在接口数量之前的鸿蒙用户。
- 先暂停：如需多路原生接口、特定 Windows 专业软件，或以大电池容量为首要指标，应先比较其他方案。
- 容量/版本：16/24/32 GB、512 GB/1 TB 和多种屏幕版本均需逐项写入订单。

## 迁移合规与安全

未验证备份可恢复前，不删除、格式化或回收旧机；软件授权、企业数据、加密密钥与账号解绑按原厂和单位流程处理。不得承诺“一键无损迁移全部应用”，也不能把云同步等同于完整备份。隐私开关及防窥能力要按具体版本确认；不能把防窥屏的体验说成标准屏或柔光屏共有。
