# HUAWEI MateBook Pro S｜门店顾客沟通卡

## 到店先锁定三件事

1. 必须用的系统、软件和外设是什么？列出必须使用的业务软件、教学插件或创作工具，核验其鸿蒙版本与文件互通，而非只问“能不能办公”。
2. 每天是否携带，最常在什么光线与桌面空间使用？以目标版本而不是“最低 798 g”统称全系，并把转接器、充电器加入差旅重量。
3. 先问客户要标准、防窥、柔光还是典藏版，再对应确认重量、屏幕和隐私开关。
4. 现场希望优先验证屏幕、键盘、会议，还是接口？现场只用左右两个 USB-C 同时模拟充电与投屏；如还要接存储或鼠标，需验证扩展坞。

## 店员可直接使用的证据话术

- 一句话定位：这是 HarmonyOS 6.1 的超轻薄款，处理器为麒麟 XE90；标准屏、防窥屏、柔光屏和典藏版不能混为一个配置。
- 本型号独有锚点：约 798 g 的标准/防窥版本、54 Wh、前后双 1080P 摄像头与双 USB-C，是 Pro S 的独有组合。
- 屏幕事实：14.2 英寸 3:2 柔性 OLED，3120 × 2080、120 Hz；官网规格区分标准屏、防窥屏和柔光屏版本。
- 配置事实：麒麟 XE90，内存有 16/24/32 GB，存储有 512 GB/1 TB。
- 接口事实：只有左右各 1 个 USB-C；规格只明确右侧 USB-C 支持 DisplayPort 1.2、最高 4K@60 Hz。

不要说“全面无短板”，可以说：“按您的三项硬需求，我们现在各做一次实机验证；任何一项过不了，就换方案，不靠形容词成交。”

## 现场反问与演示

- “如果只能在更轻、更大屏、更多接口中保留两项，您怎么排？”用答案决定比较方向。
- 若看重侧视隐私，必须用防窥屏实机验证；若看重反光控制，则核对柔光屏 SKU。
- 让顾客打开自带文件、连接自带设备，再按目标 SKU 拍下系统、内存、硬盘与接口信息。

## 适用 / 不适用

- 更适合：适合把极致轻便、3.1K 级 OLED、手写或后置取景放在接口数量之前的鸿蒙用户。
- 不建议直接成交：如需多路原生接口、特定 Windows 专业软件，或以大电池容量为首要指标，应先比较其他方案。
- 版本警戒线：16/24/32 GB、512 GB/1 TB 和多种屏幕版本均需逐项写入订单。

## 销售合规边界

不把最高配、某一系统或某一屏幕版本说成全系；不承诺未验证软件与外设；不引用无日期价格，也不使用无同期证据的竞品贬低。AI、续航、刷新率、重量和网络能力保留官网条件。隐私开关及防窥能力要按具体版本确认；不能把防窥屏的体验说成标准屏或柔光屏共有。
