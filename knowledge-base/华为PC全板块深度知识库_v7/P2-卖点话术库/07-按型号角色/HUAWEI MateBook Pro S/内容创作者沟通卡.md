# HUAWEI MateBook Pro S｜内容创作者沟通卡

## 从创作链路发问

1. 主软件、插件和版本是什么？素材分辨率、编码、单项目体量以及最终交付时限分别是多少？
2. 列出必须使用的业务软件、教学插件或创作工具，核验其鸿蒙版本与文件互通，而非只问“能不能办公”。
3. 若看重侧视隐私，必须用防窥屏实机验证；若看重反光控制，则核对柔光屏 SKU。
4. 是否常接相机卡、校色仪、数位板、外置盘或两块显示器？现场只用左右两个 USB-C 同时模拟充电与投屏；如还要接存储或鼠标，需验证扩展坞。

## 面向创作者的证据话术

- 画面依据：14.2 英寸 3:2 柔性 OLED，3120 × 2080、120 Hz；官网规格区分标准屏、防窥屏和柔光屏版本。
- 运算与容量：麒麟 XE90，内存有 16/24/32 GB，存储有 512 GB/1 TB。
- 导入/输出：只有左右各 1 个 USB-C；规格只明确右侧 USB-C 支持 DisplayPort 1.2、最高 4K@60 Hz。
- 本型号独有证据：约 798 g 的标准/防窥版本、54 Wh、前后双 1080P 摄像头与双 USB-C，是 Pro S 的独有组合。

可以这样收束：“屏幕和配置只说明硬件起点，不替代你的软件与项目实测。请带一段常用素材，完成导入、预览、套插件、导出和外接显示这一整圈，再判断是否合拍。”

## 反问与取舍

- 你更怕等待导出、屏幕不合手、素材导入麻烦，还是移动负担？请只选最不能妥协的一项。
- 若核心插件或 GPU 要求未通过，是否接受把这台机定位为审片、轻剪、文案或移动副机，而不是主渲染机？

## 适合谁，暂不适合谁

- 适用：适合把极致轻便、3.1K 级 OLED、手写或后置取景放在接口数量之前的鸿蒙用户。
- 需另选/先测：如需多路原生接口、特定 Windows 专业软件，或以大电池容量为首要指标，应先比较其他方案。
- 特别提醒：16/24/32 GB、512 GB/1 TB 和多种屏幕版本均需逐项写入订单。

## 创作场景合规线

不承诺未给出依据的色域覆盖、渲染倍数、无色差或“专业级”；不由处理器名称推导独立显卡能力。刷新率、HDR、AI、快充和续航均保留设置、内容源、版本或实验条件。隐私开关及防窥能力要按具体版本确认；不能把防窥屏的体验说成标准屏或柔光屏共有。
