# MateBook GT 系列｜商务差旅用户沟通卡

## 差旅画像要问具体

1. 一周出差几天？单肩包还是登机箱？把约 1.49 kg 机身、140 W 充电套装及读卡/存储附件一起装包评估。
2. 单次会议多久，摄像头是否常开，途中能否补电？客户现场常见 HDMI、USB-A 还是 Type-C？
3. 摄影用户现场插 SD 卡；同时核对 Windows 与 Linux 版的 Thunderbolt、SD 卡槽和 USB-C 差异。
4. 是否处理敏感资料，会议收音、摄像头遮蔽、酒店网络或离线工作哪项最重要？

## 差旅证据，不说空话

- 携带：机身厚约 15.3 mm、重约 1.49 kg。
- 供电：额定电池容量为 70 Wh；官网快充话术有原装 140 W 套装、睡眠状态、Turbo 模式等条件。
- 会场连接：Windows 版有全功能 USB-C、Thunderbolt 4、后侧双 USB-A、后侧 HDMI、3.5 mm 和 SD 卡槽；Linux 版接口表述不同，未列 Thunderbolt 4 与 SD 卡槽。
- 远程会议：1080P 摄像头、2 个扬声器、2 个麦克风。
- 识别锚点：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。

建议话术：“先按你的最差一天来算：主机、充电器、转接器一起背，连续会议按真实亮度和联网方式跑。能完成这一天，才叫适合差旅。”

## 让客户做选择

- 如果现场只给传统投影接口，你愿意常备转接器，还是必须原生直连？
- 你会用更低重量换接口，还是接受更重机身换连接便利？答案比笼统的‘轻薄长续航’更有用。

## 适用边界

- 适用：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户。
- 不适用/需验证：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。
- SKU 核对：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

## 合规提醒

续航与充电不换算成保证值；重量必须说明是否含键盘、适配器或对应电池版本。网络远距、降噪、隐私、AI 会议功能都不能升级成安全或效果保证。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
