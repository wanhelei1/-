# MateBook GT 系列｜门店顾客沟通卡

## 到店先锁定三件事

1. 必须用的系统、软件和外设是什么？列出剪辑、调色、建模或开发软件版本、插件及 GPU 要求，并在目标 Windows/Linux SKU 上跑真实素材。
2. 每天是否携带，最常在什么光线与桌面空间使用？把约 1.49 kg 机身、140 W 充电套装及读卡/存储附件一起装包评估。
3. 核实 Ultra 5/9、1/2 TB 与操作系统；高能模式或 140 W 充电条件不能泛化。
4. 现场希望优先验证屏幕、键盘、会议，还是接口？摄影用户现场插 SD 卡；同时核对 Windows 与 Linux 版的 Thunderbolt、SD 卡槽和 USB-C 差异。

## 店员可直接使用的证据话术

- 一句话定位：本卡以官网 MateBook GT 14 为事实基线：Ultra 9 185H/Ultra 5 125H、32 GB，系统有 Windows 与 Linux 版本。
- 本型号独有锚点：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。
- 屏幕事实：14.2 英寸 3:2 OLED，2880 × 1920，最高 144 Hz；出厂最高 120 Hz，需切换至最高 144 Hz且应用表现可能不同。
- 配置事实：处理器有 Ultra 9 185H、Ultra 5 125H，内存 32 GB，存储 1 TB/2 TB。
- 接口事实：Windows 版有全功能 USB-C、Thunderbolt 4、后侧双 USB-A、后侧 HDMI、3.5 mm 和 SD 卡槽；Linux 版接口表述不同，未列 Thunderbolt 4 与 SD 卡槽。

不要说“全面无短板”，可以说：“按您的三项硬需求，我们现在各做一次实机验证；任何一项过不了，就换方案，不靠形容词成交。”

## 现场反问与演示

- “如果只能在更轻、更大屏、更多接口中保留两项，您怎么排？”用答案决定比较方向。
- 用时间轴或运动画面从出厂 120 Hz 切到最高 144 Hz，说明应用与设置会影响实际刷新率。
- 让顾客打开自带文件、连接自带设备，再按目标 SKU 拍下系统、内存、硬盘与接口信息。

## 适用 / 不适用

- 更适合：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户。
- 不建议直接成交：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。
- 版本警戒线：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

## 销售合规边界

不把最高配、某一系统或某一屏幕版本说成全系；不承诺未验证软件与外设；不引用无日期价格，也不使用无同期证据的竞品贬低。AI、续航、刷新率、重量和网络能力保留官网条件。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
