# MateBook GT 系列｜教师用户沟通卡

## 按一节真实课追问

1. 备课和授课依赖哪些课件格式、字体、宏、题库、白板或录播插件？列出剪辑、调色、建模或开发软件版本、插件及 GPU 要求，并在目标 Windows/Linux SKU 上跑真实素材。
2. 教室投影是 HDMI、Type-C 还是无线？网络中断时是否仍要完成授课？摄影用户现场插 SD 卡；同时核对 Windows 与 Linux 版的 Thunderbolt、SD 卡槽和 USB-C 差异。
3. 是否需要手写批注、展示实物、播放音视频或采集学生发言？
4. 一天跨几间教室，电脑与适配器要随身多久？把约 1.49 kg 机身、140 W 充电套装及读卡/存储附件一起装包评估。

## 教学证据话术

- 课件画布：14.2 英寸 3:2 OLED，2880 × 1920，最高 144 Hz；出厂最高 120 Hz，需切换至最高 144 Hz且应用表现可能不同。
- 教室连接：Windows 版有全功能 USB-C、Thunderbolt 4、后侧双 USB-A、后侧 HDMI、3.5 mm 和 SD 卡槽；Linux 版接口表述不同，未列 Thunderbolt 4 与 SD 卡槽。
- 录课/网课：1080P 摄像头、2 个扬声器、2 个麦克风。
- 输入方式：1.5 mm 全尺寸背光键盘、多点触控板、华为分享感应区和指纹电源键。
- 本型号识别点：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。

推荐表达：“不要只打开一页 PPT。请用您最复杂的课件，从字体、动画、视频声音到投影比例完整走一遍，再断网测试必须离线完成的环节。”

## 反问化解

- 学校设备若只能用旧接口，您更愿意固定放转接器，还是优先选原生接口更多的机型？
- 若某个教学插件没有对应系统版本，是否有经过学校认可的替代工具？没有就先不推荐。

## 适用与不适用

- 适用：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户。
- 不适用/需校内验证：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。
- 配置提醒：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

## 教学场景合规线

不承诺对所有校园系统、考试平台、投影仪或字体完全兼容；AI 纪要、字幕和降噪受版本、网络、语速与环境影响，不能替代正式录课或无障碍服务。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
