# MateBook GT 系列｜旧机换新用户沟通卡

## 换机前先盘旧资产

1. 旧机是什么系统？必须保留的软件版本、许可证、浏览器证书、加密盘和本地数据库有哪些？
2. 列出剪辑、调色、建模或开发软件版本、插件及 GPU 要求，并在目标 Windows/Linux SKU 上跑真实素材。
3. 外设清单包括打印机、扫描仪、U 盾、显示器、硬盘和旧接口设备吗？摄影用户现场插 SD 卡；同时核对 Windows 与 Linux 版的 Thunderbolt、SD 卡槽和 USB-C 差异。
4. 哪些资料只在本地、哪些已同步云端；是否已有至少一份可恢复备份？

## 换新的证据与迁移话术

- 新旧系统差异：本卡以官网 MateBook GT 14 为事实基线：Ultra 9 185H/Ultra 5 125H、32 GB，系统有 Windows 与 Linux 版本。
- 容量选择：处理器有 Ultra 9 185H、Ultra 5 125H，内存 32 GB，存储 1 TB/2 TB。
- 接口变化：Windows 版有全功能 USB-C、Thunderbolt 4、后侧双 USB-A、后侧 HDMI、3.5 mm 和 SD 卡槽；Linux 版接口表述不同，未列 Thunderbolt 4 与 SD 卡槽。
- 型号锚点：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。

建议说：“先做可回退迁移：保留旧机和授权，抽样复制文档、照片、邮件与项目文件，在新机上验证打开、编辑、保存、打印；确认完整后再决定旧机处置。”

## 反问决定节奏

- 如果一个关键软件或外设只能留在旧环境，你接受双机过渡、虚拟/远程方案，还是应改选兼容性更直接的机型？
- 你换机主要为重量、屏幕、速度、接口还是系统生态？只选最痛的一项，再看这台机是否真正解决。核实 Ultra 5/9、1/2 TB 与操作系统；高能模式或 140 W 充电条件不能泛化。

## 适合与风险点

- 适用：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户。
- 先暂停：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。
- 容量/版本：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

## 迁移合规与安全

未验证备份可恢复前，不删除、格式化或回收旧机；软件授权、企业数据、加密密钥与账号解绑按原厂和单位流程处理。不得承诺“一键无损迁移全部应用”，也不能把云同步等同于完整备份。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
