# MateBook GT 系列｜内容创作者沟通卡

## 从创作链路发问

1. 主软件、插件和版本是什么？素材分辨率、编码、单项目体量以及最终交付时限分别是多少？
2. 列出剪辑、调色、建模或开发软件版本、插件及 GPU 要求，并在目标 Windows/Linux SKU 上跑真实素材。
3. 用时间轴或运动画面从出厂 120 Hz 切到最高 144 Hz，说明应用与设置会影响实际刷新率。
4. 是否常接相机卡、校色仪、数位板、外置盘或两块显示器？摄影用户现场插 SD 卡；同时核对 Windows 与 Linux 版的 Thunderbolt、SD 卡槽和 USB-C 差异。

## 面向创作者的证据话术

- 画面依据：14.2 英寸 3:2 OLED，2880 × 1920，最高 144 Hz；出厂最高 120 Hz，需切换至最高 144 Hz且应用表现可能不同。
- 运算与容量：处理器有 Ultra 9 185H、Ultra 5 125H，内存 32 GB，存储 1 TB/2 TB。
- 导入/输出：Windows 版有全功能 USB-C、Thunderbolt 4、后侧双 USB-A、后侧 HDMI、3.5 mm 和 SD 卡槽；Linux 版接口表述不同，未列 Thunderbolt 4 与 SD 卡槽。
- 本型号独有证据：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。

可以这样收束：“屏幕和配置只说明硬件起点，不替代你的软件与项目实测。请带一段常用素材，完成导入、预览、套插件、导出和外接显示这一整圈，再判断是否合拍。”

## 反问与取舍

- 你更怕等待导出、屏幕不合手、素材导入麻烦，还是移动负担？请只选最不能妥协的一项。
- 若核心插件或 GPU 要求未通过，是否接受把这台机定位为审片、轻剪、文案或移动副机，而不是主渲染机？

## 适合谁，暂不适合谁

- 适用：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户。
- 需另选/先测：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。
- 特别提醒：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

## 创作场景合规线

不承诺未给出依据的色域覆盖、渲染倍数、无色差或“专业级”；不由处理器名称推导独立显卡能力。刷新率、HDR、AI、快充和续航均保留设置、内容源、版本或实验条件。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
