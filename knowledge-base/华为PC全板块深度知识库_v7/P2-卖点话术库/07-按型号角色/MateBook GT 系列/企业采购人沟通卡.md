# MateBook GT 系列｜企业采购人沟通卡

## 采购/IT 先问

1. 本次是试点还是批量部署？要统一镜像、域、终端管理、VPN、证书、打印机或安全软件吗？
2. 列出剪辑、调色、建模或开发软件版本、插件及 GPU 要求，并在目标 Windows/Linux SKU 上跑真实素材。
3. 验收按哪一份完整 SKU、接口清单、系统版本与服务条款执行？是否允许先做样机兼容测试？
4. 数据分级、账号体系、补丁节奏、售后时效由谁签字确认？

## 可给采购会的证据话术

- 型号锚点：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。
- 系统与配置：本卡以官网 MateBook GT 14 为事实基线：Ultra 9 185H/Ultra 5 125H、32 GB，系统有 Windows 与 Linux 版本。处理器有 Ultra 9 185H、Ultra 5 125H，内存 32 GB，存储 1 TB/2 TB。
- 工位接入：Windows 版有全功能 USB-C、Thunderbolt 4、后侧双 USB-A、后侧 HDMI、3.5 mm 和 SD 卡槽；Linux 版接口表述不同，未列 Thunderbolt 4 与 SD 卡槽。
- 版本控制：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

建议说：“这台机能否进入目录，不由单一参数决定。先把贵司镜像、关键客户端、会议外设和安全策略装到目标 SKU 上验收，再讨论规模化交付。”

## 反问推进

- 如果 Windows 11 家庭版或 Linux V20 版无法通过一项核心业务或管理策略，是否同意把该项设为试点否决条件？
- 采购评价更重视单机体验，还是三年内的部署、转接、培训与维护成本？两套口径应分开打分。

## 适用与不适用

- 适用：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户，且企业愿意以目标料号完成兼容、外设和安全验收。
- 不适用/需暂停：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。任何关键系统、驱动或管理能力未验证前，都不应直接承诺批量落地。

## 合规边界

不把消费级特色功能表述成企业管理、安全认证或 SLA；不把最高配、Windows 能力或特定屏幕版本写成全系。价格、保修、交付期与服务响应以当期合同和官方政策为准。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
