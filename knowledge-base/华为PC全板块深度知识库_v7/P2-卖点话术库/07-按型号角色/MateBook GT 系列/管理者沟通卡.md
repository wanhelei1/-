# MateBook GT 系列｜管理者沟通卡

## 先问管理工作流

1. 一天有多少移动会议、批注审阅和跨设备接续？把约 1.49 kg 机身、140 W 充电套装及读卡/存储附件一起装包评估。
2. 更重视随身重量、屏幕信息密度、会议收音、隐私，还是原生接口？请排前三位。
3. 列出剪辑、调色、建模或开发软件版本、插件及 GPU 要求，并在目标 Windows/Linux SKU 上跑真实素材。
4. 需要在客户现场直接投屏，还是主要在固定会议室与华为设备协同？摄影用户现场插 SD 卡；同时核对 Windows 与 Linux 版的 Thunderbolt、SD 卡槽和 USB-C 差异。

## 决策者可用的证据话术

- 移动成本：机身厚约 15.3 mm、重约 1.49 kg。
- 审阅体验：14.2 英寸 3:2 OLED，2880 × 1920，最高 144 Hz；出厂最高 120 Hz，需切换至最高 144 Hz且应用表现可能不同。
- 会议基础：1080P 摄像头、2 个扬声器、2 个麦克风。
- 协同/工具：Windows 版可使用 AI 空间、AI 概要、AI 慧眼、超级终端等；AI 功能受电脑管家版本、网络与服务条件限制。
- 型号专属证据：最高 144 Hz OLED、Windows 版 SD 卡槽与后置双 USB-A/HDMI、32 GB 内存，是 GT 14 的独有组合。

可以说：“这台机的价值要落到少带多少、少转几次文件、少等几次会议准备。先做一日工作流演练，再用节省的步骤和新增的转接成本一起判断。”

## 反问取舍

- 若更轻的机身意味着要随身带扩展坞，这个交换对你仍成立吗？
- 如果关键审批或 BI 客户端不支持目标系统，你更愿意保留远程桌面，还是选择原生兼容机型？

## 适用与不适用

- 适用：适合需要高刷 3:2 OLED、SD 卡导入、丰富桌面接口和 32 GB 内存的创作或高负载办公用户。
- 不适用/需核验：如项目硬性要求某款独立 GPU、极低整机重量或 Linux 下完整 Windows 接口能力，应先验证而非凭系列名判断。
- 决策前锁定：Ultra 9、2 TB、Thunderbolt 4、SD 卡槽与 Windows AI 能力均不得默认到所有版本。

## 管理者话术边界

不把外观、品牌或 AI 功能包装为生产率保证；不宣称绝对隐私、安全或零学习成本。会议、协同、投屏和智能功能均受应用、系统、网络、账号与配套设备影响。Ultra 9 为可选高配；高能模式和散热宣传来自特定配置/实验条件。不能由 32 GB、OLED 或“GT”推导出独立显卡。
