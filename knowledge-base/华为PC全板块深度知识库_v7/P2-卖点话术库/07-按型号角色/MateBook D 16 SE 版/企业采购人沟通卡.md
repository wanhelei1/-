# MateBook D 16 SE 版｜企业采购人沟通卡

## 先把 SE 版采购边界画清

1. 岗位是否长期处理表格、票据或录入任务，确实需要 16 英寸画面和独立数字键盘吗？
2. 企业标准环境接受 Windows 11 64 位家庭中文版还是 Linux V20？域、VPN、证书、终端管理和安全软件分别由谁验证？
3. 本批次是否允许 13 代 i5-13420H 与 12 代 i5-12450H 混配？512 GB 与 1 TB 能否混配？
4. 打印机、扫描仪、U 盾、会议屏和扩展坞的型号是否已经列入验收表？

## 给采购方的四栏事实

- 固定项：16 英寸 IPS、16:10、1920 × 1200、300 尼特；内存 16 GB；额定电池 56 Wh。
- 可变项：处理器为 i5-13420H 或 i5-12450H，存储为 512 GB 或 1 TB，系统分 Windows 与 Linux。
- 工位接口：USB-C 3.2 Gen 1 支持数据、DisplayPort 1.2 和最高 10 W 对外供电；另有 USB-A 3.2、USB-A 2.0、HDMI、3.5 mm。
- 型号独有锚点：约 1.70 kg、56 Wh、独立数字键盘和“12/13 代 i5 双版本”。这四项可防止验收时误套非 SE D 16 的 i9 或 70 Wh 参数。

## 采购会上可以这样说

“SE 版的价值点是大屏、数字键盘和实用接口。若要批量采购，请先把处理器代际、硬盘、系统写成唯一允许的料号组合，再用样机跑一遍业务客户端和外设；价格优势不能代替标准化验收。”

## 关键反问

- 若 IT 更看重镜像一致性，是否愿意禁止两代处理器或两种系统在同一批次混发？
- 若企业策略不接受家庭版 Windows，或 Linux 无法接入现有管理体系，这个项目是否应在报价前终止？
- 岗位若不做数字录入，是否值得承担约 1.70 kg 的大屏机身，而不是改选更轻的 14 英寸设备？

## 适用、暂停与验收

- 适用：固定工位为主，预算与实用性优先，且 16 英寸工作区、数字键盘能直接改善录入效率的岗位。
- 暂停：要求 i9、70 Wh、OLED、高分辨率创作屏、独立显卡，或需要频繁长距离背负的岗位。
- 到货验收：逐台核对系统版本、CPU 完整型号、16 GB 内存、512 GB/1 TB、56 Wh 和约 1.70 kg 对应料号；再测业务登录、打印、U 盾、投屏、睡眠唤醒与恢复流程。

## 企业话术红线

不说“D 16 都有 i9/70 Wh”，不把 Windows 的超级终端、电脑管家或 F10 能力默认到 Linux 版，也不把空旷环境下的远距离联网实验数字当成办公室覆盖保证。管理、安全认证、交付期、保修与 SLA 必须依据企业政策、合同和当期官方条款。
