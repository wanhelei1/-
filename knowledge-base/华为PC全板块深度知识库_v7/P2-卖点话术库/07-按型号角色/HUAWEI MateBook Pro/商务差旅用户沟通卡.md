# HUAWEI MateBook Pro｜商务差旅用户沟通卡

## 差旅画像要问具体

1. 一周出差几天？单肩包还是登机箱？把 970 g 机身和实际随身扩展坞、线材、充电器一起称量，得到真实出行负担。
2. 单次会议多久，摄像头是否常开，途中能否补电？客户现场常见 HDMI、USB-A 还是 Type-C？
3. 让客户同时模拟充电、投影和 U 盘/鼠标，直观看三 USB-C 是否需要扩展坞。
4. 是否处理敏感资料，会议收音、摄像头遮蔽、酒店网络或离线工作哪项最重要？

## 差旅证据，不说空话

- 携带：机身厚 13.5 mm、重 970 g；实际数据仍会受配置、工艺和测量方法影响。
- 供电：额定电池容量 70 Wh，不能仅凭容量承诺某个用户的固定续航小时数。
- 会场连接：整机原生为 3 个 USB-C，没有 USB-A 或 HDMI；右侧 USB-C 规格列明最大对外供电 66 W。
- 远程会议：1080P 摄像头、6 个扬声器、4 个麦克风，适合把会议收音与播放作为现场核验项。
- 识别锚点：970 g、70 Wh、麒麟 X90 Plus和“3 个 USB-C、无原生 USB-A/HDMI”共同构成本型号独有锚点。

建议话术：“先按你的最差一天来算：主机、充电器、转接器一起背，连续会议按真实亮度和联网方式跑。能完成这一天，才叫适合差旅。”

## 让客户做选择

- 如果现场只给传统投影接口，你愿意常备转接器，还是必须原生直连？
- 你会用更低重量换接口，还是接受更重机身换连接便利？答案比笼统的‘轻薄长续航’更有用。

## 适用边界

- 适用：适合优先考虑低携带负担、柔光 OLED、会议音频和鸿蒙协同的高频移动用户。
- 不适用/需验证：若日常离不开 USB-A/HDMI 直连，或核心工作依赖未验证的 Windows 专用生态，应先算清转接与兼容成本。
- SKU 核对：24/32 GB 和 512 GB/1 TB 是可选项；AI、协同及投屏功能须按系统版本和兼容设备表述。

## 合规提醒

续航与充电不换算成保证值；重量必须说明是否含键盘、适配器或对应电池版本。网络远距、降噪、隐私、AI 会议功能都不能升级成安全或效果保证。鸿蒙专业软件兼容、外设驱动与企业管理能力需要独立验证；三个 USB-C 不等于无需转接器。
