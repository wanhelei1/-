# HUAWEI MateBook Pro｜门店顾客沟通卡

## 到店先锁定三件事

1. 必须用的系统、软件和外设是什么？把客户的关键软件、文件格式、外设驱动和协同设备列成清单，在 HarmonyOS 6.1 上逐项验证。
2. 每天是否携带，最常在什么光线与桌面空间使用？把 970 g 机身和实际随身扩展坞、线材、充电器一起称量，得到真实出行负担。
3. 核实 24/32 GB 与 512 GB/1 TB 的实际 SKU，不用顶配能力代表全部在售版本。
4. 现场希望优先验证屏幕、键盘、会议，还是接口？让客户同时模拟充电、投影和 U 盘/鼠标，直观看三 USB-C 是否需要扩展坞。

## 店员可直接使用的证据话术

- 一句话定位：这是一台 HarmonyOS 6.1、麒麟 X90 Plus 的轻量旗舰，官方规格重量为 970 g。
- 本型号独有锚点：970 g、70 Wh、麒麟 X90 Plus和“3 个 USB-C、无原生 USB-A/HDMI”共同构成本型号独有锚点。
- 屏幕事实：14.2 英寸 3:2 OLED 云晰柔光屏，3120 × 2080，典型亮度 600 nits，屏占比 93%。
- 配置事实：麒麟 X90 Plus，内存 24/32 GB，存储 512 GB/1 TB NVMe PCIe SSD。
- 接口事实：整机原生为 3 个 USB-C，没有 USB-A 或 HDMI；右侧 USB-C 规格列明最大对外供电 66 W。

不要说“全面无短板”，可以说：“按您的三项硬需求，我们现在各做一次实机验证；任何一项过不了，就换方案，不靠形容词成交。”

## 现场反问与演示

- “如果只能在更轻、更大屏、更多接口中保留两项，您怎么排？”用答案决定比较方向。
- 用顾客自己的长文档或表格测试 3:2 屏，并在店内光源下体验柔光效果。
- 让顾客打开自带文件、连接自带设备，再按目标 SKU 拍下系统、内存、硬盘与接口信息。

## 适用 / 不适用

- 更适合：适合优先考虑低携带负担、柔光 OLED、会议音频和鸿蒙协同的高频移动用户。
- 不建议直接成交：若日常离不开 USB-A/HDMI 直连，或核心工作依赖未验证的 Windows 专用生态，应先算清转接与兼容成本。
- 版本警戒线：24/32 GB 和 512 GB/1 TB 是可选项；AI、协同及投屏功能须按系统版本和兼容设备表述。

## 销售合规边界

不把最高配、某一系统或某一屏幕版本说成全系；不承诺未验证软件与外设；不引用无日期价格，也不使用无同期证据的竞品贬低。AI、续航、刷新率、重量和网络能力保留官网条件。鸿蒙专业软件兼容、外设驱动与企业管理能力需要独立验证；三个 USB-C 不等于无需转接器。
