# HUAWEI MateBook Pro｜旧机换新用户沟通卡

## 换机前先盘旧资产

1. 旧机是什么系统？必须保留的软件版本、许可证、浏览器证书、加密盘和本地数据库有哪些？
2. 把客户的关键软件、文件格式、外设驱动和协同设备列成清单，在 HarmonyOS 6.1 上逐项验证。
3. 外设清单包括打印机、扫描仪、U 盾、显示器、硬盘和旧接口设备吗？让客户同时模拟充电、投影和 U 盘/鼠标，直观看三 USB-C 是否需要扩展坞。
4. 哪些资料只在本地、哪些已同步云端；是否已有至少一份可恢复备份？

## 换新的证据与迁移话术

- 新旧系统差异：这是一台 HarmonyOS 6.1、麒麟 X90 Plus 的轻量旗舰，官方规格重量为 970 g。
- 容量选择：麒麟 X90 Plus，内存 24/32 GB，存储 512 GB/1 TB NVMe PCIe SSD。
- 接口变化：整机原生为 3 个 USB-C，没有 USB-A 或 HDMI；右侧 USB-C 规格列明最大对外供电 66 W。
- 型号锚点：970 g、70 Wh、麒麟 X90 Plus和“3 个 USB-C、无原生 USB-A/HDMI”共同构成本型号独有锚点。

建议说：“先做可回退迁移：保留旧机和授权，抽样复制文档、照片、邮件与项目文件，在新机上验证打开、编辑、保存、打印；确认完整后再决定旧机处置。”

## 反问决定节奏

- 如果一个关键软件或外设只能留在旧环境，你接受双机过渡、虚拟/远程方案，还是应改选兼容性更直接的机型？
- 你换机主要为重量、屏幕、速度、接口还是系统生态？只选最痛的一项，再看这台机是否真正解决。核实 24/32 GB 与 512 GB/1 TB 的实际 SKU，不用顶配能力代表全部在售版本。

## 适合与风险点

- 适用：适合优先考虑低携带负担、柔光 OLED、会议音频和鸿蒙协同的高频移动用户。
- 先暂停：若日常离不开 USB-A/HDMI 直连，或核心工作依赖未验证的 Windows 专用生态，应先算清转接与兼容成本。
- 容量/版本：24/32 GB 和 512 GB/1 TB 是可选项；AI、协同及投屏功能须按系统版本和兼容设备表述。

## 迁移合规与安全

未验证备份可恢复前，不删除、格式化或回收旧机；软件授权、企业数据、加密密钥与账号解绑按原厂和单位流程处理。不得承诺“一键无损迁移全部应用”，也不能把云同步等同于完整备份。鸿蒙专业软件兼容、外设驱动与企业管理能力需要独立验证；三个 USB-C 不等于无需转接器。
