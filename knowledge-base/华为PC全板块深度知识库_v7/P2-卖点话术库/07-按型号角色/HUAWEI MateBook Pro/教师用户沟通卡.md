# HUAWEI MateBook Pro｜教师用户沟通卡

## 按一节真实课追问

1. 备课和授课依赖哪些课件格式、字体、宏、题库、白板或录播插件？把客户的关键软件、文件格式、外设驱动和协同设备列成清单，在 HarmonyOS 6.1 上逐项验证。
2. 教室投影是 HDMI、Type-C 还是无线？网络中断时是否仍要完成授课？让客户同时模拟充电、投影和 U 盘/鼠标，直观看三 USB-C 是否需要扩展坞。
3. 是否需要手写批注、展示实物、播放音视频或采集学生发言？
4. 一天跨几间教室，电脑与适配器要随身多久？把 970 g 机身和实际随身扩展坞、线材、充电器一起称量，得到真实出行负担。

## 教学证据话术

- 课件画布：14.2 英寸 3:2 OLED 云晰柔光屏，3120 × 2080，典型亮度 600 nits，屏占比 93%。
- 教室连接：整机原生为 3 个 USB-C，没有 USB-A 或 HDMI；右侧 USB-C 规格列明最大对外供电 66 W。
- 录课/网课：1080P 摄像头、6 个扬声器、4 个麦克风，适合把会议收音与播放作为现场核验项。
- 输入方式：1.8 mm 键程全尺寸背光键盘、大尺寸多点触控板和指纹电源键。
- 本型号识别点：970 g、70 Wh、麒麟 X90 Plus和“3 个 USB-C、无原生 USB-A/HDMI”共同构成本型号独有锚点。

推荐表达：“不要只打开一页 PPT。请用您最复杂的课件，从字体、动画、视频声音到投影比例完整走一遍，再断网测试必须离线完成的环节。”

## 反问化解

- 学校设备若只能用旧接口，您更愿意固定放转接器，还是优先选原生接口更多的机型？
- 若某个教学插件没有对应系统版本，是否有经过学校认可的替代工具？没有就先不推荐。

## 适用与不适用

- 适用：适合优先考虑低携带负担、柔光 OLED、会议音频和鸿蒙协同的高频移动用户。
- 不适用/需校内验证：若日常离不开 USB-A/HDMI 直连，或核心工作依赖未验证的 Windows 专用生态，应先算清转接与兼容成本。
- 配置提醒：24/32 GB 和 512 GB/1 TB 是可选项；AI、协同及投屏功能须按系统版本和兼容设备表述。

## 教学场景合规线

不承诺对所有校园系统、考试平台、投影仪或字体完全兼容；AI 纪要、字幕和降噪受版本、网络、语速与环境影响，不能替代正式录课或无障碍服务。鸿蒙专业软件兼容、外设驱动与企业管理能力需要独立验证；三个 USB-C 不等于无需转接器。
