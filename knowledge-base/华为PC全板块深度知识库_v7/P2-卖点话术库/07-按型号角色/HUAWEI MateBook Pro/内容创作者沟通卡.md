# HUAWEI MateBook Pro｜内容创作者沟通卡

## 从创作链路发问

1. 主软件、插件和版本是什么？素材分辨率、编码、单项目体量以及最终交付时限分别是多少？
2. 把客户的关键软件、文件格式、外设驱动和协同设备列成清单，在 HarmonyOS 6.1 上逐项验证。
3. 用顾客自己的长文档或表格测试 3:2 屏，并在店内光源下体验柔光效果。
4. 是否常接相机卡、校色仪、数位板、外置盘或两块显示器？让客户同时模拟充电、投影和 U 盘/鼠标，直观看三 USB-C 是否需要扩展坞。

## 面向创作者的证据话术

- 画面依据：14.2 英寸 3:2 OLED 云晰柔光屏，3120 × 2080，典型亮度 600 nits，屏占比 93%。
- 运算与容量：麒麟 X90 Plus，内存 24/32 GB，存储 512 GB/1 TB NVMe PCIe SSD。
- 导入/输出：整机原生为 3 个 USB-C，没有 USB-A 或 HDMI；右侧 USB-C 规格列明最大对外供电 66 W。
- 本型号独有证据：970 g、70 Wh、麒麟 X90 Plus和“3 个 USB-C、无原生 USB-A/HDMI”共同构成本型号独有锚点。

可以这样收束：“屏幕和配置只说明硬件起点，不替代你的软件与项目实测。请带一段常用素材，完成导入、预览、套插件、导出和外接显示这一整圈，再判断是否合拍。”

## 反问与取舍

- 你更怕等待导出、屏幕不合手、素材导入麻烦，还是移动负担？请只选最不能妥协的一项。
- 若核心插件或 GPU 要求未通过，是否接受把这台机定位为审片、轻剪、文案或移动副机，而不是主渲染机？

## 适合谁，暂不适合谁

- 适用：适合优先考虑低携带负担、柔光 OLED、会议音频和鸿蒙协同的高频移动用户。
- 需另选/先测：若日常离不开 USB-A/HDMI 直连，或核心工作依赖未验证的 Windows 专用生态，应先算清转接与兼容成本。
- 特别提醒：24/32 GB 和 512 GB/1 TB 是可选项；AI、协同及投屏功能须按系统版本和兼容设备表述。

## 创作场景合规线

不承诺未给出依据的色域覆盖、渲染倍数、无色差或“专业级”；不由处理器名称推导独立显卡能力。刷新率、HDR、AI、快充和续航均保留设置、内容源、版本或实验条件。鸿蒙专业软件兼容、外设驱动与企业管理能力需要独立验证；三个 USB-C 不等于无需转接器。
