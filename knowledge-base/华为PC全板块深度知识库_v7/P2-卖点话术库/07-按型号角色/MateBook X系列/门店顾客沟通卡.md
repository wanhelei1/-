# MateBook X系列｜门店顾客沟通卡

## 到店先锁定三件事

1. 必须用的系统、软件和外设是什么？确认 Windows 或 Linux，再核验业务软件、驱动、AI 功能与多设备协同的版本要求。
2. 每天是否携带，最常在什么光线与桌面空间使用？把约 980 g 主机与必需扩展坞、线材、充电器一起称量，避免忽略 Type-C 转接负担。
3. 订单中写明 Ultra 7/9、16/32 GB、1/2 TB 和系统；980 g 仍应以目标配置实物为准。
4. 现场希望优先验证屏幕、键盘、会议，还是接口？用三个 Type-C 口模拟充电、显示与存储，明确 Windows 的 Thunderbolt 4 能力不等同于 Linux 规格。

## 店员可直接使用的证据话术

- 一句话定位：本卡基于 MateBook X Pro 酷睿 Ultra 微绒典藏版官网事实，系统有 Windows 11 与 Linux 版。
- 本型号独有锚点：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。
- 屏幕事实：14.2 英寸 3:2 OLED，3120 × 2080、屏占比 93%；Windows 版支持最高 120 Hz，出厂设置与应用会影响刷新率。
- 配置事实：处理器有 Ultra 9 185H/Ultra 7 155H，内存 16/32 GB，存储 1/2 TB。
- 接口事实：Windows 版为 2 个 Thunderbolt 4 加 1 个 USB-C，并有摄像头隐私开关；Linux 版规格为 3 个 USB-C，接口能力不可互套。

不要说“全面无短板”，可以说：“按您的三项硬需求，我们现在各做一次实机验证；任何一项过不了，就换方案，不靠形容词成交。”

## 现场反问与演示

- “如果只能在更轻、更大屏、更多接口中保留两项，您怎么排？”用答案决定比较方向。
- 用高密度文字、图片和滚动页面体验 3120 × 2080 OLED，并现场确认 60/120 Hz 设置。
- 让顾客打开自带文件、连接自带设备，再按目标 SKU 拍下系统、内存、硬盘与接口信息。

## 适用 / 不适用

- 更适合：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人。
- 不建议直接成交：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。
- 版本警戒线：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

## 销售合规边界

不把最高配、某一系统或某一屏幕版本说成全系；不承诺未验证软件与外设；不引用无日期价格，也不使用无同期证据的竞品贬低。AI、续航、刷新率、重量和网络能力保留官网条件。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
