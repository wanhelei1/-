# MateBook X系列｜教师用户沟通卡

## 按一节真实课追问

1. 备课和授课依赖哪些课件格式、字体、宏、题库、白板或录播插件？确认 Windows 或 Linux，再核验业务软件、驱动、AI 功能与多设备协同的版本要求。
2. 教室投影是 HDMI、Type-C 还是无线？网络中断时是否仍要完成授课？用三个 Type-C 口模拟充电、显示与存储，明确 Windows 的 Thunderbolt 4 能力不等同于 Linux 规格。
3. 是否需要手写批注、展示实物、播放音视频或采集学生发言？
4. 一天跨几间教室，电脑与适配器要随身多久？把约 980 g 主机与必需扩展坞、线材、充电器一起称量，避免忽略 Type-C 转接负担。

## 教学证据话术

- 课件画布：14.2 英寸 3:2 OLED，3120 × 2080、屏占比 93%；Windows 版支持最高 120 Hz，出厂设置与应用会影响刷新率。
- 教室连接：Windows 版为 2 个 Thunderbolt 4 加 1 个 USB-C，并有摄像头隐私开关；Linux 版规格为 3 个 USB-C，接口能力不可互套。
- 录课/网课：1080P 摄像头、6 个扬声器、4 个麦克风。
- 输入方式：压力触控板、1.5 mm 全尺寸背光键盘、华为分享感应区和指纹电源键；Linux 版相关功能需按规格核实。
- 本型号识别点：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。

推荐表达：“不要只打开一页 PPT。请用您最复杂的课件，从字体、动画、视频声音到投影比例完整走一遍，再断网测试必须离线完成的环节。”

## 反问化解

- 学校设备若只能用旧接口，您更愿意固定放转接器，还是优先选原生接口更多的机型？
- 若某个教学插件没有对应系统版本，是否有经过学校认可的替代工具？没有就先不推荐。

## 适用与不适用

- 适用：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人。
- 不适用/需校内验证：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。
- 配置提醒：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

## 教学场景合规线

不承诺对所有校园系统、考试平台、投影仪或字体完全兼容；AI 纪要、字幕和降噪受版本、网络、语速与环境影响，不能替代正式录课或无障碍服务。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
