# MateBook X系列｜旧机换新用户沟通卡

## 换机前先盘旧资产

1. 旧机是什么系统？必须保留的软件版本、许可证、浏览器证书、加密盘和本地数据库有哪些？
2. 确认 Windows 或 Linux，再核验业务软件、驱动、AI 功能与多设备协同的版本要求。
3. 外设清单包括打印机、扫描仪、U 盾、显示器、硬盘和旧接口设备吗？用三个 Type-C 口模拟充电、显示与存储，明确 Windows 的 Thunderbolt 4 能力不等同于 Linux 规格。
4. 哪些资料只在本地、哪些已同步云端；是否已有至少一份可恢复备份？

## 换新的证据与迁移话术

- 新旧系统差异：本卡基于 MateBook X Pro 酷睿 Ultra 微绒典藏版官网事实，系统有 Windows 11 与 Linux 版。
- 容量选择：处理器有 Ultra 9 185H/Ultra 7 155H，内存 16/32 GB，存储 1/2 TB。
- 接口变化：Windows 版为 2 个 Thunderbolt 4 加 1 个 USB-C，并有摄像头隐私开关；Linux 版规格为 3 个 USB-C，接口能力不可互套。
- 型号锚点：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。

建议说：“先做可回退迁移：保留旧机和授权，抽样复制文档、照片、邮件与项目文件，在新机上验证打开、编辑、保存、打印；确认完整后再决定旧机处置。”

## 反问决定节奏

- 如果一个关键软件或外设只能留在旧环境，你接受双机过渡、虚拟/远程方案，还是应改选兼容性更直接的机型？
- 你换机主要为重量、屏幕、速度、接口还是系统生态？只选最痛的一项，再看这台机是否真正解决。订单中写明 Ultra 7/9、16/32 GB、1/2 TB 和系统；980 g 仍应以目标配置实物为准。

## 适合与风险点

- 适用：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人。
- 先暂停：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。
- 容量/版本：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

## 迁移合规与安全

未验证备份可恢复前，不删除、格式化或回收旧机；软件授权、企业数据、加密密钥与账号解绑按原厂和单位流程处理。不得承诺“一键无损迁移全部应用”，也不能把云同步等同于完整备份。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
