# MateBook X系列｜企业采购人沟通卡

## 采购/IT 先问

1. 本次是试点还是批量部署？要统一镜像、域、终端管理、VPN、证书、打印机或安全软件吗？
2. 确认 Windows 或 Linux，再核验业务软件、驱动、AI 功能与多设备协同的版本要求。
3. 验收按哪一份完整 SKU、接口清单、系统版本与服务条款执行？是否允许先做样机兼容测试？
4. 数据分级、账号体系、补丁节奏、售后时效由谁签字确认？

## 可给采购会的证据话术

- 型号锚点：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。
- 系统与配置：本卡基于 MateBook X Pro 酷睿 Ultra 微绒典藏版官网事实，系统有 Windows 11 与 Linux 版。处理器有 Ultra 9 185H/Ultra 7 155H，内存 16/32 GB，存储 1/2 TB。
- 工位接入：Windows 版为 2 个 Thunderbolt 4 加 1 个 USB-C，并有摄像头隐私开关；Linux 版规格为 3 个 USB-C，接口能力不可互套。
- 版本控制：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

建议说：“这台机能否进入目录，不由单一参数决定。先把贵司镜像、关键客户端、会议外设和安全策略装到目标 SKU 上验收，再讨论规模化交付。”

## 反问推进

- 如果 Windows 11 家庭版或 Linux 版无法通过一项核心业务或管理策略，是否同意把该项设为试点否决条件？
- 采购评价更重视单机体验，还是三年内的部署、转接、培训与维护成本？两套口径应分开打分。

## 适用与不适用

- 适用：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人，且企业愿意以目标料号完成兼容、外设和安全验收。
- 不适用/需暂停：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。任何关键系统、驱动或管理能力未验证前，都不应直接承诺批量落地。

## 合规边界

不把消费级特色功能表述成企业管理、安全认证或 SLA；不把最高配、Windows 能力或特定屏幕版本写成全系。价格、保修、交付期与服务响应以当期合同和官方政策为准。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
