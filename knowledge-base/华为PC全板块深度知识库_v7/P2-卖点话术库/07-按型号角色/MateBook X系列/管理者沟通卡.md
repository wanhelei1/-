# MateBook X系列｜管理者沟通卡

## 先问管理工作流

1. 一天有多少移动会议、批注审阅和跨设备接续？把约 980 g 主机与必需扩展坞、线材、充电器一起称量，避免忽略 Type-C 转接负担。
2. 更重视随身重量、屏幕信息密度、会议收音、隐私，还是原生接口？请排前三位。
3. 确认 Windows 或 Linux，再核验业务软件、驱动、AI 功能与多设备协同的版本要求。
4. 需要在客户现场直接投屏，还是主要在固定会议室与华为设备协同？用三个 Type-C 口模拟充电、显示与存储，明确 Windows 的 Thunderbolt 4 能力不等同于 Linux 规格。

## 决策者可用的证据话术

- 移动成本：机身厚约 13.5 mm、重约 980 g；重量会随配置、工艺和测量方式变化。
- 审阅体验：14.2 英寸 3:2 OLED，3120 × 2080、屏占比 93%；Windows 版支持最高 120 Hz，出厂设置与应用会影响刷新率。
- 会议基础：1080P 摄像头、6 个扬声器、4 个麦克风。
- 协同/工具：Windows 版列有 AI 概要、AI 慧眼、超级终端等，部分功能要求指定电脑管家版本、联网或手动开启。
- 型号专属证据：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。

可以说：“这台机的价值要落到少带多少、少转几次文件、少等几次会议准备。先做一日工作流演练，再用节省的步骤和新增的转接成本一起判断。”

## 反问取舍

- 若更轻的机身意味着要随身带扩展坞，这个交换对你仍成立吗？
- 如果关键审批或 BI 客户端不支持目标系统，你更愿意保留远程桌面，还是选择原生兼容机型？

## 适用与不适用

- 适用：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人。
- 不适用/需核验：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。
- 决策前锁定：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

## 管理者话术边界

不把外观、品牌或 AI 功能包装为生产率保证；不宣称绝对隐私、安全或零学习成本。会议、协同、投屏和智能功能均受应用、系统、网络、账号与配套设备影响。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
