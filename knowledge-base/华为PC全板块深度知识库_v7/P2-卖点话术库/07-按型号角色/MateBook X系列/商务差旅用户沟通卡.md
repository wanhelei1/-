# MateBook X系列｜商务差旅用户沟通卡

## 差旅画像要问具体

1. 一周出差几天？单肩包还是登机箱？把约 980 g 主机与必需扩展坞、线材、充电器一起称量，避免忽略 Type-C 转接负担。
2. 单次会议多久，摄像头是否常开，途中能否补电？客户现场常见 HDMI、USB-A 还是 Type-C？
3. 用三个 Type-C 口模拟充电、显示与存储，明确 Windows 的 Thunderbolt 4 能力不等同于 Linux 规格。
4. 是否处理敏感资料，会议收音、摄像头遮蔽、酒店网络或离线工作哪项最重要？

## 差旅证据，不说空话

- 携带：机身厚约 13.5 mm、重约 980 g；重量会随配置、工艺和测量方式变化。
- 供电：额定电池容量为 70 Wh；快充与续航宣传均有指定充电器、模式、亮度或负载条件。
- 会场连接：Windows 版为 2 个 Thunderbolt 4 加 1 个 USB-C，并有摄像头隐私开关；Linux 版规格为 3 个 USB-C，接口能力不可互套。
- 远程会议：1080P 摄像头、6 个扬声器、4 个麦克风。
- 识别锚点：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。

建议话术：“先按你的最差一天来算：主机、充电器、转接器一起背，连续会议按真实亮度和联网方式跑。能完成这一天，才叫适合差旅。”

## 让客户做选择

- 如果现场只给传统投影接口，你愿意常备转接器，还是必须原生直连？
- 你会用更低重量换接口，还是接受更重机身换连接便利？答案比笼统的‘轻薄长续航’更有用。

## 适用边界

- 适用：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人。
- 不适用/需验证：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。
- SKU 核对：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

## 合规提醒

续航与充电不换算成保证值；重量必须说明是否含键盘、适配器或对应电池版本。网络远距、降噪、隐私、AI 会议功能都不能升级成安全或效果保证。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
