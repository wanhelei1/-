# MateBook X系列｜内容创作者沟通卡

## 从创作链路发问

1. 主软件、插件和版本是什么？素材分辨率、编码、单项目体量以及最终交付时限分别是多少？
2. 确认 Windows 或 Linux，再核验业务软件、驱动、AI 功能与多设备协同的版本要求。
3. 用高密度文字、图片和滚动页面体验 3120 × 2080 OLED，并现场确认 60/120 Hz 设置。
4. 是否常接相机卡、校色仪、数位板、外置盘或两块显示器？用三个 Type-C 口模拟充电、显示与存储，明确 Windows 的 Thunderbolt 4 能力不等同于 Linux 规格。

## 面向创作者的证据话术

- 画面依据：14.2 英寸 3:2 OLED，3120 × 2080、屏占比 93%；Windows 版支持最高 120 Hz，出厂设置与应用会影响刷新率。
- 运算与容量：处理器有 Ultra 9 185H/Ultra 7 155H，内存 16/32 GB，存储 1/2 TB。
- 导入/输出：Windows 版为 2 个 Thunderbolt 4 加 1 个 USB-C，并有摄像头隐私开关；Linux 版规格为 3 个 USB-C，接口能力不可互套。
- 本型号独有证据：约 980 g、3.1K OLED、70 Wh，以及 Windows 版双 Thunderbolt 4 + 单 USB-C，是 X Pro 微绒典藏版的独有锚点。

可以这样收束：“屏幕和配置只说明硬件起点，不替代你的软件与项目实测。请带一段常用素材，完成导入、预览、套插件、导出和外接显示这一整圈，再判断是否合拍。”

## 反问与取舍

- 你更怕等待导出、屏幕不合手、素材导入麻烦，还是移动负担？请只选最不能妥协的一项。
- 若核心插件或 GPU 要求未通过，是否接受把这台机定位为审片、轻剪、文案或移动副机，而不是主渲染机？

## 适合谁，暂不适合谁

- 适用：适合把低重量、高分辨率 OLED、会议音频和 Windows 高端移动办公放在接口数量之前的人。
- 需另选/先测：若要求 USB-A/HDMI 免转接、固定预算下追求高性价比，或依赖 Linux/Windows 某一侧专属功能，应先比较。
- 特别提醒：AI、协同、指纹与雷电能力必须按系统和电脑管家版本说明，不把高配处理器/容量说成全系。

## 创作场景合规线

不承诺未给出依据的色域覆盖、渲染倍数、无色差或“专业级”；不由处理器名称推导独立显卡能力。刷新率、HDR、AI、快充和续航均保留设置、内容源、版本或实验条件。Ultra 7/9、16/32 GB、1/2 TB 以及 Windows/Linux 有明显差异；没有原生 USB-A 与 HDMI。
