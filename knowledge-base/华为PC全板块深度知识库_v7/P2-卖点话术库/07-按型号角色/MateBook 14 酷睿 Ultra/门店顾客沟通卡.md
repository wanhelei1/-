# MateBook 14 酷睿 Ultra｜门店顾客沟通卡

## 到店先锁定三件事

1. 必须用的系统、软件和外设是什么？明确客户买 Windows 还是 Linux，并记录软件版本、插件、许可证和外设驱动要求。
2. 每天是否携带，最常在什么光线与桌面空间使用？让用户把约 1.31 kg 机身和充电器装进日常背包，再判断通勤是否合适。
3. 订单写清 Ultra 5/7 与 16/24/32 GB；不得用 Ultra 7 或 32 GB 的体验替代低配说明。
4. 现场希望优先验证屏幕、键盘、会议，还是接口？用全功能 USB-C、HDMI 和双 USB-A 按真实投屏、存储、鼠标场景逐一连接。

## 店员可直接使用的证据话术

- 一句话定位：这是酷睿 Ultra 平台的 MateBook 14，操作系统有 Windows 11 家庭版与 Linux V20 版，不能把 Windows 软件能力套到 Linux SKU。
- 本型号独有锚点：约 1.31 kg、2.8K OLED、1 TB 存储与“全功能 USB-C + 双 USB-A + HDMI”是酷睿 Ultra 款的辨识组合。
- 屏幕事实：14.2 英寸 3:2 OLED，2880 × 1920、450 尼特；出厂 60 Hz，可切换至最高 120 Hz，应用中可能不同。
- 配置事实：处理器有 Ultra 7 155H、Ultra 5 125H；内存 16/24/32 GB，固态硬盘为 1 TB。
- 接口事实：有 1 个全功能 USB-C、2 个 USB 3.2 Gen 1、HDMI 和 3.5 mm 耳麦口。

不要说“全面无短板”，可以说：“按您的三项硬需求，我们现在各做一次实机验证；任何一项过不了，就换方案，不靠形容词成交。”

## 现场反问与演示

- “如果只能在更轻、更大屏、更多接口中保留两项，您怎么排？”用答案决定比较方向。
- 用客户自己的文档、照片或时间轴体验 3:2 OLED；需要高刷时现场切换并确认目标应用表现。
- 让顾客打开自带文件、连接自带设备，再按目标 SKU 拍下系统、内存、硬盘与接口信息。

## 适用 / 不适用

- 更适合：适合需要 Windows 常用软件、3:2 OLED 触控和较完整原生接口的学习办公与轻创作用户。
- 不建议直接成交：如果工作依赖独立显卡级渲染、特定 Linux/Windows 驱动或高负载持续性能，应拿真实项目先测。
- 版本警戒线：Windows 功能、AI 体验和协同能力不得默认到 Linux 版；触控笔也不应说成标配。

## 销售合规边界

不把最高配、某一系统或某一屏幕版本说成全系；不承诺未验证软件与外设；不引用无日期价格，也不使用无同期证据的竞品贬低。AI、续航、刷新率、重量和网络能力保留官网条件。Ultra 5/7、16/24/32 GB 以及 Windows/Linux 都是版本差异；HUAWEI M-Pencil 适配需另核套装与支持条件。
