# MateBook 14 酷睿 Ultra｜旧机换新用户沟通卡

## 换机前先盘旧资产

1. 旧机是什么系统？必须保留的软件版本、许可证、浏览器证书、加密盘和本地数据库有哪些？
2. 明确客户买 Windows 还是 Linux，并记录软件版本、插件、许可证和外设驱动要求。
3. 外设清单包括打印机、扫描仪、U 盾、显示器、硬盘和旧接口设备吗？用全功能 USB-C、HDMI 和双 USB-A 按真实投屏、存储、鼠标场景逐一连接。
4. 哪些资料只在本地、哪些已同步云端；是否已有至少一份可恢复备份？

## 换新的证据与迁移话术

- 新旧系统差异：这是酷睿 Ultra 平台的 MateBook 14，操作系统有 Windows 11 家庭版与 Linux V20 版，不能把 Windows 软件能力套到 Linux SKU。
- 容量选择：处理器有 Ultra 7 155H、Ultra 5 125H；内存 16/24/32 GB，固态硬盘为 1 TB。
- 接口变化：有 1 个全功能 USB-C、2 个 USB 3.2 Gen 1、HDMI 和 3.5 mm 耳麦口。
- 型号锚点：约 1.31 kg、2.8K OLED、1 TB 存储与“全功能 USB-C + 双 USB-A + HDMI”是酷睿 Ultra 款的辨识组合。

建议说：“先做可回退迁移：保留旧机和授权，抽样复制文档、照片、邮件与项目文件，在新机上验证打开、编辑、保存、打印；确认完整后再决定旧机处置。”

## 反问决定节奏

- 如果一个关键软件或外设只能留在旧环境，你接受双机过渡、虚拟/远程方案，还是应改选兼容性更直接的机型？
- 你换机主要为重量、屏幕、速度、接口还是系统生态？只选最痛的一项，再看这台机是否真正解决。订单写清 Ultra 5/7 与 16/24/32 GB；不得用 Ultra 7 或 32 GB 的体验替代低配说明。

## 适合与风险点

- 适用：适合需要 Windows 常用软件、3:2 OLED 触控和较完整原生接口的学习办公与轻创作用户。
- 先暂停：如果工作依赖独立显卡级渲染、特定 Linux/Windows 驱动或高负载持续性能，应拿真实项目先测。
- 容量/版本：Windows 功能、AI 体验和协同能力不得默认到 Linux 版；触控笔也不应说成标配。

## 迁移合规与安全

未验证备份可恢复前，不删除、格式化或回收旧机；软件授权、企业数据、加密密钥与账号解绑按原厂和单位流程处理。不得承诺“一键无损迁移全部应用”，也不能把云同步等同于完整备份。Ultra 5/7、16/24/32 GB 以及 Windows/Linux 都是版本差异；HUAWEI M-Pencil 适配需另核套装与支持条件。
