# MateBook D 14｜门店顾客沟通卡

## 到店先锁定三件事

1. 必须用的系统、软件和外设是什么？先确认 Windows 或 Linux，再列出课程/单位软件与驱动；Linux 版不能默认具备电脑管家能力。
2. 每天是否携带，最常在什么光线与桌面空间使用？把约 1.39 kg 机身、充电器和常用鼠标一起试背，避免只凭单机重量。
3. 核对是否为标准版还是 SE 版，并写清 i5/i7、512 GB/1 TB 与键盘配置。
4. 现场希望优先验证屏幕、键盘、会议，还是接口？区分两个 USB-A 的代际，并现场验证 USB-C 显示输出和客户的 HDMI 投影设备。

## 店员可直接使用的证据话术

- 一句话定位：本卡基于 MateBook D 14 2024 13 代酷睿版事实，系统有 Windows 11 家庭版与 Linux V20 版。
- 本型号独有锚点：14 英寸 16:10 IPS、约 1.39 kg、56 Wh，以及 i5-13420H/i7-1360P 双处理器选项，是 D 14 的型号锚点。
- 屏幕事实：14 英寸 IPS，16:10、1920 × 1200，屏占比 90%；它不是 OLED 或高分辨率创作屏。
- 配置事实：处理器有 i5-13420H 与 i7-1360P，内存 16 GB，存储 512 GB/1 TB。
- 接口事实：USB-C 3.2 Gen 1 支持数据、显示和最高 10 W 对外供电；另有 USB-A 3.2、USB-A 2.0、HDMI、3.5 mm。

不要说“全面无短板”，可以说：“按您的三项硬需求，我们现在各做一次实机验证；任何一项过不了，就换方案，不靠形容词成交。”

## 现场反问与演示

- “如果只能在更轻、更大屏、更多接口中保留两项，您怎么排？”用答案决定比较方向。
- 让用户用长表格或论文比较 16:10 版面；若追求 OLED 黑位或高分辨率，应直接说明不属于本机规格。
- 让顾客打开自带文件、连接自带设备，再按目标 SKU 拍下系统、内存、硬盘与接口信息。

## 适用 / 不适用

- 更适合：适合看重实用接口、14 英寸便携与常规 Windows 学习办公的人。
- 不建议直接成交：若对 OLED、专业色彩、高分辨率屏或重度图形渲染有明确要求，不应把它包装成创作旗舰。
- 版本警戒线：16 GB 为已列内存；摄像头是 100 万像素，不得口头升级成 1080P。

## 销售合规边界

不把最高配、某一系统或某一屏幕版本说成全系；不承诺未验证软件与外设；不引用无日期价格，也不使用无同期证据的竞品贬低。AI、续航、刷新率、重量和网络能力保留官网条件。D 14 与 D 14 SE、i5 与 i7、512 GB 与 1 TB、Windows 与 Linux 都要分开确认。
