# MateBook D 14｜旧机换新用户沟通卡

## 换机前先盘旧资产

1. 旧机是什么系统？必须保留的软件版本、许可证、浏览器证书、加密盘和本地数据库有哪些？
2. 先确认 Windows 或 Linux，再列出课程/单位软件与驱动；Linux 版不能默认具备电脑管家能力。
3. 外设清单包括打印机、扫描仪、U 盾、显示器、硬盘和旧接口设备吗？区分两个 USB-A 的代际，并现场验证 USB-C 显示输出和客户的 HDMI 投影设备。
4. 哪些资料只在本地、哪些已同步云端；是否已有至少一份可恢复备份？

## 换新的证据与迁移话术

- 新旧系统差异：本卡基于 MateBook D 14 2024 13 代酷睿版事实，系统有 Windows 11 家庭版与 Linux V20 版。
- 容量选择：处理器有 i5-13420H 与 i7-1360P，内存 16 GB，存储 512 GB/1 TB。
- 接口变化：USB-C 3.2 Gen 1 支持数据、显示和最高 10 W 对外供电；另有 USB-A 3.2、USB-A 2.0、HDMI、3.5 mm。
- 型号锚点：14 英寸 16:10 IPS、约 1.39 kg、56 Wh，以及 i5-13420H/i7-1360P 双处理器选项，是 D 14 的型号锚点。

建议说：“先做可回退迁移：保留旧机和授权，抽样复制文档、照片、邮件与项目文件，在新机上验证打开、编辑、保存、打印；确认完整后再决定旧机处置。”

## 反问决定节奏

- 如果一个关键软件或外设只能留在旧环境，你接受双机过渡、虚拟/远程方案，还是应改选兼容性更直接的机型？
- 你换机主要为重量、屏幕、速度、接口还是系统生态？只选最痛的一项，再看这台机是否真正解决。核对是否为标准版还是 SE 版，并写清 i5/i7、512 GB/1 TB 与键盘配置。

## 适合与风险点

- 适用：适合看重实用接口、14 英寸便携与常规 Windows 学习办公的人。
- 先暂停：若对 OLED、专业色彩、高分辨率屏或重度图形渲染有明确要求，不应把它包装成创作旗舰。
- 容量/版本：16 GB 为已列内存；摄像头是 100 万像素，不得口头升级成 1080P。

## 迁移合规与安全

未验证备份可恢复前，不删除、格式化或回收旧机；软件授权、企业数据、加密密钥与账号解绑按原厂和单位流程处理。不得承诺“一键无损迁移全部应用”，也不能把云同步等同于完整备份。D 14 与 D 14 SE、i5 与 i7、512 GB 与 1 TB、Windows 与 Linux 都要分开确认。
