# MateBook D 14｜企业采购人沟通卡

## 采购/IT 先问

1. 本次是试点还是批量部署？要统一镜像、域、终端管理、VPN、证书、打印机或安全软件吗？
2. 先确认 Windows 或 Linux，再列出课程/单位软件与驱动；Linux 版不能默认具备电脑管家能力。
3. 验收按哪一份完整 SKU、接口清单、系统版本与服务条款执行？是否允许先做样机兼容测试？
4. 数据分级、账号体系、补丁节奏、售后时效由谁签字确认？

## 可给采购会的证据话术

- 型号锚点：14 英寸 16:10 IPS、约 1.39 kg、56 Wh，以及 i5-13420H/i7-1360P 双处理器选项，是 D 14 的型号锚点。
- 系统与配置：本卡基于 MateBook D 14 2024 13 代酷睿版事实，系统有 Windows 11 家庭版与 Linux V20 版。处理器有 i5-13420H 与 i7-1360P，内存 16 GB，存储 512 GB/1 TB。
- 工位接入：USB-C 3.2 Gen 1 支持数据、显示和最高 10 W 对外供电；另有 USB-A 3.2、USB-A 2.0、HDMI、3.5 mm。
- 版本控制：16 GB 为已列内存；摄像头是 100 万像素，不得口头升级成 1080P。

建议说：“这台机能否进入目录，不由单一参数决定。先把贵司镜像、关键客户端、会议外设和安全策略装到目标 SKU 上验收，再讨论规模化交付。”

## 反问推进

- 如果 Windows 11 家庭版或 Linux V20 版无法通过一项核心业务或管理策略，是否同意把该项设为试点否决条件？
- 采购评价更重视单机体验，还是三年内的部署、转接、培训与维护成本？两套口径应分开打分。

## 适用与不适用

- 适用：适合看重实用接口、14 英寸便携与常规 Windows 学习办公的人，且企业愿意以目标料号完成兼容、外设和安全验收。
- 不适用/需暂停：若对 OLED、专业色彩、高分辨率屏或重度图形渲染有明确要求，不应把它包装成创作旗舰。任何关键系统、驱动或管理能力未验证前，都不应直接承诺批量落地。

## 合规边界

不把消费级特色功能表述成企业管理、安全认证或 SLA；不把最高配、Windows 能力或特定屏幕版本写成全系。价格、保修、交付期与服务响应以当期合同和官方政策为准。D 14 与 D 14 SE、i5 与 i7、512 GB 与 1 TB、Windows 与 Linux 都要分开确认。
