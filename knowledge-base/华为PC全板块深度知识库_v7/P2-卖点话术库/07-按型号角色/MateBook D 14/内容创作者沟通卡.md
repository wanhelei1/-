# MateBook D 14｜内容创作者沟通卡

## 从创作链路发问

1. 主软件、插件和版本是什么？素材分辨率、编码、单项目体量以及最终交付时限分别是多少？
2. 先确认 Windows 或 Linux，再列出课程/单位软件与驱动；Linux 版不能默认具备电脑管家能力。
3. 让用户用长表格或论文比较 16:10 版面；若追求 OLED 黑位或高分辨率，应直接说明不属于本机规格。
4. 是否常接相机卡、校色仪、数位板、外置盘或两块显示器？区分两个 USB-A 的代际，并现场验证 USB-C 显示输出和客户的 HDMI 投影设备。

## 面向创作者的证据话术

- 画面依据：14 英寸 IPS，16:10、1920 × 1200，屏占比 90%；它不是 OLED 或高分辨率创作屏。
- 运算与容量：处理器有 i5-13420H 与 i7-1360P，内存 16 GB，存储 512 GB/1 TB。
- 导入/输出：USB-C 3.2 Gen 1 支持数据、显示和最高 10 W 对外供电；另有 USB-A 3.2、USB-A 2.0、HDMI、3.5 mm。
- 本型号独有证据：14 英寸 16:10 IPS、约 1.39 kg、56 Wh，以及 i5-13420H/i7-1360P 双处理器选项，是 D 14 的型号锚点。

可以这样收束：“屏幕和配置只说明硬件起点，不替代你的软件与项目实测。请带一段常用素材，完成导入、预览、套插件、导出和外接显示这一整圈，再判断是否合拍。”

## 反问与取舍

- 你更怕等待导出、屏幕不合手、素材导入麻烦，还是移动负担？请只选最不能妥协的一项。
- 若核心插件或 GPU 要求未通过，是否接受把这台机定位为审片、轻剪、文案或移动副机，而不是主渲染机？

## 适合谁，暂不适合谁

- 适用：适合看重实用接口、14 英寸便携与常规 Windows 学习办公的人。
- 需另选/先测：若对 OLED、专业色彩、高分辨率屏或重度图形渲染有明确要求，不应把它包装成创作旗舰。
- 特别提醒：16 GB 为已列内存；摄像头是 100 万像素，不得口头升级成 1080P。

## 创作场景合规线

不承诺未给出依据的色域覆盖、渲染倍数、无色差或“专业级”；不由处理器名称推导独立显卡能力。刷新率、HDR、AI、快充和续航均保留设置、内容源、版本或实验条件。D 14 与 D 14 SE、i5 与 i7、512 GB 与 1 TB、Windows 与 Linux 都要分开确认。
