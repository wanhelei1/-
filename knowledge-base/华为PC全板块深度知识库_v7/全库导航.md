# 华为 PC 全板块知识库导航

## 先判断任务，再选资料

本库不是把所有文件当成同一种“答案”。使用前先判断当前任务属于事实核验、场景分析、内容创作、培训、售后还是竞品对比，再进入对应板块。智能体生成内容时，应先读取治理规则和事实底座，再调用方法、案例或模板；案例不能反过来覆盖产品事实。

| 任务 | 首选板块 | 配合板块 | 主要产出 |
|---|---|---|---|
| 查询型号、规格、接口、系统、图片或公开价格 | P1 | 00、P4 | 带来源、版本、价格口径和日期限制的产品事实 |
| 把事实讲给不同客户角色 | P2 | P1、P8 | 证据话术、反问、适用与不适用条件 |
| 做竞品研究或对比 | P3 | P1、00 | 同期、同维度、带来源的条件化比较 |
| 使用价格、库存、政策或内部授权信息 | P4 | 00 | 受控字段和审批记录；本公开库不含真实内部数据 |
| 培训新人、销售、内容或服务人员 | P5 | P1、P2、P7 | 学习路径、讲义、演练、测验和判分 |
| 写公众号、小红书、知乎、新闻稿、短视频、直播或门店物料 | P6 | P1、P2、P8 | 平台任务卡、完整成稿、图文方案和合规自检 |
| 处理安装、迁移、兼容或故障 | P7 | P1、00 | 官方支持卡、FAQ、分步排障和升级路径 |
| 分析行业、岗位或客户业务场景 | P8 | P1、P2、P7 | 画像、问题清单、方案、验收与完整参考案例 |

## 各板块怎么读

### 00｜治理与来源

这里定义分类、命名、元数据、事实分级、审核、版本、智能体规则和质量检查。`09-来源研究底稿`保存产品、支持、竞品与传播案例的研究过程。第三方案例只研究结构与平台习惯，不作为产品参数证据。

### P1｜产品参数与图片

重点型号目录包含产品事实、卖点与限制、图片索引和官方来源；扩展产品目录覆盖更多消费级与商用电脑、显示器、打印机、耗材和配件。`06-型号检索卡`把重点型号按任务、角色和限制拆开；`07-扩展产品目录`属于产品发现卡，若需要完整参数，应继续打开官方规格页核验；`08-官方公开价格快照`保存具体 SKU 页面价、官网参考价、活动条件、下架状态和企业询价状态。

使用 P1 时必须区分系列与具体 SKU、Windows 与 HarmonyOS、标准屏与柔光/防窥版本、当前款与历史款。图片文件名含产品和画面主题，仍须通过相邻的 `图片索引.csv`核对来源、内容与使用边界。

询价时先查 `08-官方公开价格快照/00-总索引.md`，再打开对应价格卡。回答必须保留具体配置、价格类型、核验时间、库存/优惠条件和官方 URL。旧款官网参考起价不能写成当前在售价；缺货价不能写成可购买价；商用品没有公开金额时只能回答“需官方询价”，不得用相近型号、第三方平台或搜索摘要代填。

### P2｜卖点与证据话术

先选择客户角色，再选择型号或方法。话术文件的作用是把已确认事实放进客户任务，不是增加新参数。回答应包含：客户问题、可核验事实、适用条件、限制、追问和下一步验证。任何“更快、更省、更安全”的结论都要说明与谁比、在什么环境、依据是什么；没有证据就改成待验证问题。

### P3｜竞品资料

品牌事实卡记录官方页面当时公开的定位与卖点；来源登记说明每个品牌官网的产品主键、系列规则和动态字段；维度文件提供取证框架；已填充对比案例展示如何在同一任务下做条件化比较。不得用不同日期、不同价位、不同系统定位的产品拼成“绝对胜负”，也不得把缺失字段解释为对方不具备。

### P4｜价格与政策

该板块只保留内部价格政策的字段、权限、审核、版本和失效机制。P1/08 的公开商城页面价与本板块严格分离；公开网页中的历史促销不能进入内部报价结论。真实返点、项目报价、库存、补贴、交期和客户政策必须由获授权人员在受控环境填写，并标明生效与失效日期。

### P5｜培训赋能

从学习路径进入，再按角色选择快速入门、产品体系、系统能力、配置解析、销售或售后课程。系统课程按“讲义—情景演练—测验”成套组织，测验不是背参数，而是检查能否找到证据、说明边界、处理冲突和给出下一步。学习结果应保留作业、评分、错题和补救记录。

### P6｜营销素材与软文案例

P6 分成四个层次：

1. **平台指南与任务卡**：说明受众、结构、图文节奏、交付格式和合规规则。
2. **完整软文成稿**：10 个重点型号分别适配 8 类平台，共 80 份完整参考文本；每份含选题、正文、图片方案、事实脚注和发布自检。
3. **华为官方传播案例研究**：按官网、商用解决方案、新闻活动、商城和支持内容拆解 113 个传播单元，研究信息结构，不转载原文。
4. **多平台公开案例研究**：13 类平台各 5 个案例，共 65 个；同时标明来源类型、可借鉴机制、不能照搬的内容和版权风险。

写作时先选“平台—受众—场景—型号”，再读取对应成稿和案例。完整成稿是参考底稿，不是自动可发布的广告；发布前仍要核验 SKU、来源日期、图片授权和动态信息。不同平台必须重新安排标题、篇幅、视觉、互动和 CTA，不能只换标题。

### P7｜官方支持与常见问题

FAQ用于快速定位，官方支持条目用于回到文章级来源，综合排障指南用于执行一整条诊断流程。遇到数据丢失、进液跌落、异常发热、反复蓝屏、无法开机或企业安全策略时，应先停止可能扩大风险的操作，再转官方或授权人员处理。任何第三方软件和外设兼容问题都要同时核对其厂商文档。

### P8｜客户与行业场景

通用场景卡用于快速识别方向；`12-行业场景`覆盖 30 类行业/岗位，每类包含画像、问题清单、方案模板、验收清单和完整参考案例。完整案例明确为教学用虚构情景，不得改写成真实客户业绩。正式项目必须使用客户授权的脱敏样例、实际应用、网络和外设完成试点。

## 建议的智能体检索顺序

1. 读取 `00-建库规范/06-智能体规则`与当前任务相关的规则。
2. 从 P1 或 P7 找到可核验事实，记录型号、版本、日期和来源。
3. 从 P8 判断用户场景与必须追问的问题。
4. 根据任务调用 P2、P5 或 P6 的方法、案例和成稿。
5. 输出前检查事实是否越过来源边界、图片是否有索引、动态信息是否过期、是否把演练写成真实结果。

## 三个检索示例

### 例一：为某型号写小红书图文

先读取 P1 的产品事实、卖点限制和图片索引；再读取 P6 的小红书平台指南、该型号小红书任务卡及完整成稿；最后从 P6 多平台案例中学习标题和图文节奏。不得直接复制案例正文，也不得把其他型号图片或参数移入目标内容。

### 例二：回答企业是否适合换机

先用 P8 对应行业问题清单确认应用、系统、账号、网络、外设和管理要求；再从 P1 建候选范围，从 P7 查迁移和支持路径。输出 2—3 个条件化候选和试点计划，不在信息不足时给唯一结论。

### 例三：比较华为与竞品

先固定用户任务、日期、配置和对比字段，再读取 P1 与 P3 的同期官方证据。结论写成“在这些条件下，哪一项更符合当前任务”，同时列出未知项和需实测项；不用贬损性词语，也不把官网未写的字段判为不具备。

## 短文件为什么仍然存在

索引、目录说明、字段模板和文章级来源卡承担定位与回溯职责，应该简洁；完整回答由它们指向的事实、指南、成稿、案例或课程提供。本库统计会把索引/来源卡、模板/任务卡和深度内容分开列示，不用“文件总数”冒充实质内容量。
