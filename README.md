# 门店增长工作台（Store Growth Workbench）

浙客松·AI+X 破界黑客松 · 华为产业落地赛道参赛作品。

为华为门店顾问提供**证据可溯源**的顾客接待、营销内容与价格核验工具：每条结论都附知识库出处，说得出"为什么"；纯 Python 标准库实现，**无需 API Key、无需联网**即可完整运行。

## 🚀 评委请先看这里（30 秒演示路径）

1. 打开线上作品：https://modelscope.cn/studios/【用户名】/【空间名】
2. 在「顾客接待」选择「门店零售」→ 点击示例按钮 → 点击「生成接待方案与价格核验」
3. 看结果区：接待方案 / 价格快照与核验日期 / **每条结论的依据出处**

线上链接异常时，本地两行命令即可获得同样功能（见下）。

## 本地运行（Python ≥ 3.10，零第三方依赖）

```bash
py -3 app.py          # Windows；macOS/Linux 用 python3 app.py
```

浏览器打开 `http://127.0.0.1:7860`。托管环境可加 `--host 0.0.0.0 --port 7860`。

验收（2026-10-18 实测 16/16 通过）：

```bash
py -3 -m unittest discover -s tests -v
```

Docker：`docker build -t sgw . && docker run -p 7860:7860 sgw`

## 技术方案（四行）

- **零依赖可跑**：纯 Python 标准库 HTTP 服务 + 前端工作台 `index.html`，无第三方包、无网络依赖、无 Key 完整可运行。
- **证据驱动**：本地知识库（华为PC全板块深度知识库 v7）离线检索，答案附文件/章节来源；未知项明确标注「待追问」，不编造。
- **五段流水线**：客户洞察 → 需求推荐 → 价格核验 → 营销草稿 → 合规检查，由 `store_growth_workflow.py` 统一装配（`POST /api/insight`、`POST /api/workflow`）。
- **云端部署**：魔搭 Docker 创空间（`python:3.12-slim`，监听 `0.0.0.0:7860`）。

## 功能优先级

| 级别 | 内容 | 状态 |
|---|---|---|
| P0 | 顾客接待（门店零售/学生学习）、知识问答、价格核验、营销草稿、成交跟进 | ✅ 已实现 |
| P1 | 五段完整串联流程（洞察→推荐→价格→营销→合规） | ✅ 已实现（`/api/workflow`） |
| P2 | 真实门店成交数据接入、动态促销/库存核验 | 明确暂缓（见已知局限） |

## 核心模块

| 模块 | 职责 |
|---|---|
| `app.py` | 标准库 HTTP 服务：目录、接待、知识检索、价格/营销接口 |
| `store_growth_workflow.py` | 五段流水线装配，模块间不互相复制代码 |
| `customer_insight_agent/` | 客户洞察（第一阶段），缺失项标记待追问 |
| `3号(1)/` | 离线检索与需求推荐（`mock_retriever` / `retrieval_adapter` / `recommendation_engine`，当前明确标记 Mock） |
| `pricing_module.py` | 只展示带核验日期的官方价格快照，不能安全展示的金额直接过滤 |
| `marketing_content_module.py` | 按 P2/P6 话术与 P1 图片来源生成可审阅草稿 |
| `BLOCK-07/` | 末端合规：来源汇总、风险词、人工确认项 |
| `follow_up_module.py` | 成交跟进计划；数据仅存使用者浏览器本地 |
| `prepare_public_deploy.py` | 生成公开部署包（见下） |

> 目录名 `3号(1)`、`BLOCK-07` 为队友分工时的原始模块名，为保持代码引用与 Dockerfile 一致原样保留。

## 数据与合规治理

知识库包含 8 个公开板块（建库规范 / P1 产品参数 / P2 卖点话术 / P3 竞品资料 / P5 培训赋能 / P6 营销素材 / P7 常见问题 / P8 客户场景）。**机密的 P4 价格政策、待审核资料、历史归档与研究底稿一律不进入本仓库**：`prepare_public_deploy.py` 自动排除受限资料，并生成逐文件校验清单（`bundle-manifest.json`）。

## 已知局限与下一步

1. 价格核验只展示官方快照与核验日期，不含动态促销、库存、补贴（下一步：接入当日授权来源复核）。
2. 知识问答检索当前为精选子集（明确标记 Mock），非全库生产检索（下一步：扩展至全库并做相关性调优）。
3. 软件/外设兼容性不从参数推断，须在客户目标环境人工验证（下一步：增加兼容性核查清单）。
4. 未使用真实门店成交/转化样本，不声明销售提升、ROI 或效果指标（下一步：脱敏试点数据回灌）。

## 事实边界

- 动态价格、库存、促销、补贴、赠品、交期和门店成交条件必须以当日授权来源复核。
- 产品规格受销售 SKU、配置和版本影响，每项结论应结合页面来源核对。
- 知识库教材中的教学示例不作为真实客户案例或产品背书。
